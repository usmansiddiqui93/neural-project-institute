What is Microsoft Planner?

Microsoft has consolidated its cloud project tools into Planner. Microsoft Project for the web was retired in 2025 and its capabilities moved into Planner's premium plans, and Microsoft has also announced the retirement of Project Online. Basic Planner remains included in Microsoft 365 business plans.

Planner works inside Teams, Outlook and Loop, which makes adoption easy for organisations already living in Microsoft 365.

Key features

Tasks and boards

Simple boards and task lists in Planner and Teams.

Premium planning

Timeline (Gantt), dependencies, sprints and goals on paid plans.

Resource management

Advanced resource and portfolio features on Plan 3.

Microsoft 365 integration

Works across Teams, Outlook, Loop, To Do and Power Automate.

Copilot

AI assistance with the Microsoft 365 Copilot add-on.

Frequently asked questions

What is Microsoft Planner?

Microsoft Planner is a project and work management tool from Microsoft, launched in 2016. Microsoft Planner is the natural choice for Microsoft 365 organisations, now combining simple task boards with the advanced scheduling formerly in Project for the web. It is convenient and well integrated, but lighter than specialist platforms.

How much does Microsoft Planner cost?

Basic Planner included in Microsoft 365; Plan 1 from $10/user/month. Plans: Planner (basic): Included in Microsoft 365; Planner Plan 1: $10/user/month (annual); Planner and Project Plan 3: $30/user/month (annual); Microsoft 365 Copilot: $30/user/month add-on (annual). Prices checked 5 October 2026.

Does Microsoft Planner have a free plan?

Basic Planner included with Microsoft 365.

Does Microsoft Planner offer a free trial?

Trials available for paid plans.

Is Microsoft Planner good for small teams?

Yes. Organisations already on Microsoft 365 and Teams

Is Microsoft Planner good for large enterprises?

Yes, it offers enterprise plans with advanced security and administration.

Does Microsoft Planner have Gantt charts?

Yes, Gantt or timeline views are available (plan-dependent).

Does Microsoft Planner support Agile and Scrum?

It supports Agile boards and some sprint features, but dedicated tools like Jira go further.

Does Microsoft Planner have time tracking?

Limited, or via integrations.

What are the best Microsoft Planner alternatives?

Top alternatives include Wrike (for far deeper project, resource and approval features), Smartsheet (for enterprise spreadsheet-style planning), Asana (for richer cross-team task management), monday.com (for more customisable workflows). See our full list of Microsoft Planner alternatives.

How is Microsoft Planner rated by users?

4.2/5 on G2 from 237 reviews and 4.3/5 on Capterra from 298 reviews (checked 5 October 2026).

Who should not use Microsoft Planner?

Teams outside the Microsoft ecosystem; Organisations needing advanced proofing or creative workflows.
