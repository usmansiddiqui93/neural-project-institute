How to use the root cause analysis template

  1. Write a specific, factual problem statement.
  2. Ask 'why?' and record the answer; repeat about five times.
  3. Stop when you reach a cause you can act on.
  4. Agree corrective actions with owners and dates.
  5. Verify that the actions prevented recurrence.

Tips for getting the most from it

  • Base each answer on evidence.
  • There may be several root causes: branch the analysis.
  • Focus on processes, not people.
  • For complex problems, use a fishbone diagram.

Frequently asked questions

What is a root cause analysis template?

A root cause analysis template is a worksheet for finding the underlying cause of a problem and planning corrective actions.

Is this root cause analysis template free?

Yes. The root cause analysis template is free in Google Sheets, Excel and PDF.

What is a 5 whys template?

A 5 whys template asks 'why?' repeatedly, about five times, to trace a problem to its root cause.

Is the root cause analysis template the same as a 5 whys root cause analysis template?

Yes. This root cause analysis template uses the 5 whys technique plus a corrective action plan.

Do I always need five whys in the root cause analysis template?

No. Stop when you reach a cause you can fix; it may take three or seven whys.

When should I use a root cause analysis template?

After incidents, defects, missed deadlines or recurring problems.

What is the difference between a root cause analysis template and a fishbone diagram?

The 5 whys follows one chain; a fishbone diagram explores many possible causes by category.

Who should take part in a root cause analysis template session?

People close to the problem, with a neutral facilitator.

How do I verify actions in the root cause analysis template?

Define a measure, such as no recurrence in the next three releases, and check it.

Can I use the root cause analysis template for lessons learned?

Yes. Use it to analyse the biggest items in your lessons learned.

What is the difference between the beginner, advanced and expert root cause analysis template?

The beginner root cause analysis template keeps only the essential columns on one tab; the advanced version is the full template with every tab, dropdown and formula; the expert version adds instructions, a dashboard that summarises your data automatically, status colours and a revision history.
