What's included

  • User stories with role, need, benefit, acceptance criteria, points, priority and status
  • An epic template linking stories to goals
  • User stories: ID, Epic, As a…, I want…, So that…, Acceptance criteria (Given / When / Then), Story points, Priority, Status
  • Epics: Epic, Description, Goal, Stories, Owner, Status

How to use the user story template

  1. Identify the user role and write the story as As a… I want… so that….
  2. Add acceptance criteria, ideally in Given/When/Then form.
  3. Group stories under epics on the Epics tab.
  4. Estimate with the team in story points and set priority.
  5. Split stories that are too large to finish in one Sprint.

Tips for getting the most from it

  • Write from the user's view, not the system's.
  • Keep the 'so that' clause: it explains value.
  • Use INVEST to check quality.
  • See epics vs stories vs tasks.

Frequently asked questions

What is a user story template?

A user story template is a format for writing requirements as 'As a [user], I want [goal] so that [benefit]', with acceptance criteria.

Is this user story template free?

Yes. The user story template is free in Google Sheets, Excel and PDF.

What is the standard user story template format?

As a [type of user], I want [some goal] so that [some reason].

How do I write acceptance criteria in the user story template?

Use clear, testable statements, often Given/When/Then, that define when the story is done.

Does the user story template include an epic template?

Yes. The Epics tab is an agile epic template that groups related user stories.

What is INVEST in a user story template?

Independent, Negotiable, Valuable, Estimable, Small and Testable: a checklist for good user stories.

Who writes stories in the user story template?

Usually the Product Owner, collaborating with the team and stakeholders.

How big should a story in the user story template be?

Small enough to finish within one Sprint; split larger stories.

Can I use the user story template in Jira?

Yes. Copy the format into Jira issues, or import the user stories from the spreadsheet.

What is the difference between a user story template and a use case template?

A user story is a short statement of need; a use case describes detailed interaction steps.

What is the difference between the beginner, advanced and expert user story template?

The beginner user story template keeps only the essential columns on one tab; the advanced version is the full template with every tab, dropdown and formula; the expert version adds instructions, a dashboard that summarises your data automatically, status colours and a revision history.
