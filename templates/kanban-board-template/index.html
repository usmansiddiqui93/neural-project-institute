What's included

  • A board view with WIP-limited columns
  • A card list with owner, class of service, dates, cycle time and blocked flag
  • Board: Backlog, To do (WIP 5), In progress (WIP 3), Review (WIP 2), Done
  • Cards: Card, Owner, Class of service, Column, Started, Finished, Cycle time (days), Blocked?

How to use the Kanban board template

  1. Rename the columns to match your workflow and set a WIP limit for each.
  2. Add work items as cards in the Backlog column.
  3. Pull cards to the right only when there is capacity under the WIP limit.
  4. Record start and finish dates on the Cards tab to measure cycle time.
  5. Review the board daily and improve the process regularly.

Tips for getting the most from it

  • Lower WIP limits until work flows smoothly.
  • Make blocked work visible.
  • Use classes of service for urgent work.

Frequently asked questions

What is a Kanban board template?

A Kanban board template is a ready-made board with workflow columns and cards for visualising and limiting work in progress.

Is this Kanban board template free?

Yes. The Kanban board template is free in Google Sheets, Excel and PDF.

What columns should a Kanban board template have?

At minimum To do, In progress and Done; many teams add Backlog and Review.

How do I set WIP limits in a Kanban board template?

Write the limit in each column header and only pull new cards when the column is under its limit.

Can I use the Kanban board template in Excel?

Yes. The .xlsx Kanban board template works in Excel; move cards by cutting and pasting between columns.

Is there a Kanban card template included in the Kanban board template?

Yes. The Cards tab is a Kanban card template with owner, class of service, dates and cycle time.

Can I use the Kanban board template for personal tasks?

Yes. It works as a personal Kanban board.

How does the Kanban board template measure cycle time?

Cycle time = finish date − start date + 1, calculated on the Cards tab.

What is the difference between a Kanban board template and a Scrum board?

A Kanban board template is continuous with WIP limits; a Scrum board resets each Sprint.

When should I move from a Kanban board template to software?

When you need real-time collaboration, automation or flow metrics, use a tool such as Trello or Wrike.

What is the difference between the beginner, advanced and expert Kanban board template?

The beginner Kanban board template keeps only the essential columns on one tab; the advanced version is the full template with every tab, dropdown and formula; the expert version adds instructions, a dashboard that summarises your data automatically, status colours and a revision history.
