How to use the RFQ template

  1. Write a clear specification with quantities and delivery dates.
  2. State commercial terms and how quotes will be evaluated.
  3. Send the same RFQ to several suppliers with a deadline.
  4. Enter prices in the Quote comparison tab; totals calculate automatically.
  5. Evaluate against your criteria, not price alone, and award the order.

Tips for getting the most from it

  • Ask all suppliers the same questions.
  • Share answers to questions with every bidder.
  • Check delivery, warranty and support, not just price.
  • See procurement management.

Frequently asked questions

What is an RFQ template?

An RFQ template is a request for quotation document that asks suppliers to price specified goods or services, plus a way to compare quotes.

Is this RFQ template free?

Yes. The RFQ template is free in Google Sheets, Excel and PDF.

What does RFQ stand for in the RFQ template?

Request for quotation, also called a request for quote.

What should an RFQ template include?

Specification, quantities, delivery, terms, evaluation criteria, submission instructions and deadline.

What is the difference between an RFQ template and an RFP?

An RFQ asks for prices on a defined need; an RFP asks suppliers to propose a solution.

How many suppliers should receive the RFQ template?

Usually three to five to get competitive quotes.

How do I compare quotes with the RFQ template?

Enter unit prices per supplier; the template calculates totals for a like-for-like comparison.

Can I use the RFQ template as a request for quotation template for services?

Yes. Describe the services and deliverables in the specification.

How long should suppliers get to respond to the RFQ template?

One to three weeks, depending on complexity.

Can I download the RFQ template as a PDF?

Yes. Use the PDF button to send a printable request for quote template.

What is the difference between the beginner, advanced and expert RFQ template?

The beginner RFQ template keeps only the essential columns on one tab; the advanced version is the full template with every tab, dropdown and formula; the expert version adds instructions, a dashboard that summarises your data automatically, status colours and a revision history.
