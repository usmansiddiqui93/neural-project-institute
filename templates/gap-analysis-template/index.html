What's included

  • Current versus future state with scores, automatic gap size, actions, owners, dates and priority
  • Gap analysis: Area, Current state, Desired future state, Current (1-5), Target (1-5), Gap, Actions to close the gap, Owner, Due date, Priority

How to use the gap analysis template

  1. Choose the areas to assess.
  2. Describe the current state honestly and the desired future state clearly.
  3. Score both from 1 to 5; the gap calculates automatically.
  4. Plan actions to close the largest gaps, with owners and dates.
  5. Prioritise and track the actions as a project.

Tips for getting the most from it

  • Use evidence, not opinions, for current state.
  • Close a few big gaps rather than many small ones.
  • Re-score after six months.
  • Feed actions into an action plan.

Frequently asked questions

What is a gap analysis template?

A gap analysis template compares current performance with a desired future state and lists actions to close the gap.

Is this gap analysis template free?

Yes. The gap analysis template is free in Google Sheets, Excel and PDF.

How do I use the gap analysis template?

Describe current and future states, score them, review the gap size and plan actions.

What are the steps of a gap analysis template?

Identify areas, assess the current state, define the future state, measure the gap and plan actions.

Can I use the gap analysis template for skills?

Yes. For people skills, a skills matrix gives more detail.

Can I use the gap analysis template for business processes?

Yes. Assess each process step against best practice.

What is the difference between a gap analysis template and a SWOT?

A gap analysis measures the distance to a target; SWOT lists strengths, weaknesses, opportunities and threats.

How is the gap scored in the gap analysis template?

Gap = target score − current score on a 1-5 scale.

Can I use the gap analysis template for IT or compliance?

Yes. Use requirements or standards as the future state.

Can I download the gap analysis template as a PDF?

Yes. Use the PDF button for a printable gap analysis template.

What is the difference between the beginner, advanced and expert gap analysis template?

The beginner gap analysis template keeps only the essential columns on one tab; the advanced version is the full template with every tab, dropdown and formula; the expert version adds instructions, a dashboard that summarises your data automatically, status colours and a revision history.
