How to use the work breakdown structure template

  1. Write the project's final deliverable as level 1.
  2. Break it into major deliverables or phases at level 2, then into work packages at level 3.
  3. Give each element a unique WBS code, a short description and a single owner.
  4. Estimate effort and cost for each work package; the top row totals them.
  5. Check the 100% rule: the children of each element add up to all of its work, and nothing more.
  6. Use the work packages to build your schedule and budget.

Tips for getting the most from it

  • Name elements with nouns (deliverables), not verbs.
  • Stop decomposing when a work package can be estimated and assigned.
  • Keep a WBS dictionary for detail.
  • Do not include work that is out of scope.

Frequently asked questions

What is a work breakdown structure template?

A work breakdown structure template is a ready-made table for decomposing a project into deliverables and work packages with codes, owners, effort and cost.

How do I fill in a work breakdown structure template?

Start with the final deliverable, break it into major deliverables, then into work packages, and give each a code, owner and estimate.

Is this work breakdown structure template free?

Yes. The work breakdown structure template is free in Google Sheets, Excel and PDF.

What is the 100% rule in a work breakdown structure template?

Each level must contain 100% of the work of its parent, no more and no less, so the WBS covers the whole scope.

How many levels should a work breakdown structure template have?

Most projects need three or four levels; decompose until work packages can be estimated and assigned.

Can I use the work breakdown structure template in Excel?

Yes. The .xlsx WBS template opens in Excel, with roll-up formulas for effort and cost.

Is a work breakdown structure template the same as a project schedule?

No. The WBS shows what must be delivered; the project schedule template shows when.

Should a work breakdown structure template be deliverable-based or phase-based?

Either works; deliverable-based structures make scope clearer, phase-based ones suit sequential projects.

What is a WBS dictionary in a work breakdown structure template?

A WBS dictionary describes each element in detail: scope, acceptance criteria, owner, estimates and dependencies.

Who creates the work breakdown structure template?

The project manager leads it, with the team who will do the work, so estimates and coverage are realistic.

What is the difference between the beginner, advanced and expert work breakdown structure template?

The beginner work breakdown structure template keeps only the essential columns on one tab; the advanced version is the full template with every tab, dropdown and formula; the expert version adds instructions, a dashboard that summarises your data automatically, status colours and a revision history.
