How to use the project charter template

  1. Agree the purpose and objectives with the sponsor before writing anything else.
  2. Fill in scope and, just as importantly, what is out of scope.
  3. Add milestones, budget, top risks, assumptions and constraints.
  4. Name the sponsor and project manager and state the project manager's authority.
  5. Review it with key stakeholders, then get the sponsor's signature.
  6. Store the signed charter with the project management plan and revisit it at major milestones.

Tips for getting the most from it

  • Keep it to two pages; detail belongs in the project plan.
  • Write objectives you can measure at the end.
  • List exclusions to prevent scope creep.
  • Do not start detailed planning until it is signed.

Frequently asked questions

What is a project charter template?

A project charter template is a ready-made outline for the document that formally authorises a project and names its sponsor, project manager, objectives and scope.

What should a project charter template include?

Purpose, SMART objectives, scope and exclusions, deliverables, milestones, budget, risks, assumptions, stakeholders, roles and an approval section.

Is this project charter template free?

Yes. Download the project charter template free as a Google Sheet, Excel file or PDF.

Who fills in the project charter template?

Usually the project manager or sponsor drafts the project charter; the sponsor approves and signs it.

How long should a completed project charter template be?

One to four pages. If your project charter is longer, move the detail into the project plan.

Can I use the project charter template for Agile projects?

Yes. Agile teams often use a lightweight project charter to agree vision, goals, boundaries and roles.

What is the difference between a project charter template and a project plan template?

The project charter authorises the project at a high level; the project plan template explains how it will be delivered.

When should I use the project charter template?

Use the project charter template at the start of initiation, before detailed planning.

Does a project charter template need a signature?

Yes. A signed project charter shows formal authorisation and the sponsor's commitment.

Can I change the project charter after it is approved?

Only for major changes in purpose or scope, and the revised project charter should be re-approved by the sponsor.
