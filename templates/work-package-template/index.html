How to use the work package template

  1. Copy the WBS code and name from your WBS.
  2. Describe scope and deliverables.
  3. List tasks, then estimate effort and cost.
  4. Add dates, dependencies, risks and acceptance criteria.
  5. Agree it with the owner and approver before work starts.

Tips for getting the most from it

  • Keep work packages to a few weeks of effort.
  • One owner per package.
  • Acceptance criteria make progress objective.
  • Roll up estimates to the cost estimate.

Frequently asked questions

What is a work package template?

A work package template describes one work package in detail: scope, deliverables, tasks, owner, estimates, dates, dependencies and acceptance criteria.

Is this work package template free?

Yes. The work package template is free in Google Sheets, Excel and PDF.

How big should a work package in the work package template be?

Typically between 8 and 80 hours of effort, or small enough to estimate and finish in a few weeks.

What is the difference between a work package template and a WBS template?

The WBS template shows the whole hierarchy; a work package template details one lowest-level element.

Who owns the work package template?

A single work package owner, agreed with the project manager.

Can I use the work package template in PRINCE2?

Yes. PRINCE2 work packages authorise teams to deliver products; add tolerances and reporting arrangements.

What goes in the acceptance criteria of a work package template?

Clear, testable conditions the output must meet to be accepted.

Can I download the work package template as a PDF?

Yes. Use the PDF button for a printable work package template.

How does a work package template help with estimating?

Estimating at work package level is more accurate, and totals roll up to the project budget.

Should every work package template have dependencies listed?

Yes, list any dependencies so they can be scheduled and tracked.

What is the difference between the beginner, advanced and expert work package template?

The beginner work package template keeps only the essential columns on one tab; the advanced version is the full template with every tab, dropdown and formula; the expert version adds instructions, a dashboard that summarises your data automatically, status colours and a revision history.
