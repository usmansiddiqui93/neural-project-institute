Прогноз по завершении (EAC): формулы, примеры и советы

Прогноз по завершении (EAC) — это прогноз общей стоимости проекта на момент завершения всех работ. Он объединяет уже потраченные средства с оценкой стоимости оставшейся работы.

АвторNeural Project InstituteРедакция по управлению проектами

  • 3 мин чтения

Главное

  • EAC прогнозирует общую стоимость по завершении.
  • Выбирайте формулу, соответствующую причине отклонения.
  • ETC = EAC - AC; VAC = BAC - EAC; TCPI показывает необходимую эффективность.
  • Указывайте в отчётах диапазон EAC, а не одно значение.

Четыре формулы EAC

ФормулаКогда использовать
EAC = BAC / CPIОжидается, что текущая эффективность затрат сохранится (типичное отклонение)
EAC = AC + (BAC - EV)Прошлое отклонение было разовым; оставшаяся работа пойдёт по плану (нетипичное отклонение)
EAC = AC + (BAC - EV) / (CPI x SPI)На оставшуюся работу повлияет эффективность и по стоимости, и по срокам, например при фиксированной дате окончания
EAC = AC + ETC, оценённый снизу вверхПервоначальный план больше не действует, и оставшаяся работа оценивается заново

Связанные прогнозы

  • Прогноз до завершения (ETC) = EAC - AC: сколько денег ещё нужно.
  • Отклонение по завершении (VAC) = BAC - EAC: ожидаемая экономия или перерасход.
  • TCPI (к BAC) = (BAC - EV) / (BAC - AC): эффективность, необходимая для завершения в рамках бюджета.
  • TCPI (к EAC) = (BAC - EV) / (EAC - AC): эффективность, необходимая для достижения прогноза.

Разобранный пример

BAC = $200 000, PV = $80 000, EV = $70 000, AC = $85 000. Следовательно, CPI = 0,8235, SPI = 0,875. Оставшаяся работа = BAC - EV = $130 000.

ФормулаРасчётEACVAC
BAC / CPI200,000 / 0.8235$242,857-$42,857
AC + (BAC - EV)85,000 + 130,000$215,000-$15,000
AC + (BAC - EV) / (CPI x SPI)85,000 + 130,000 / 0.7206$265,408-$65,408
AC + восходящая оценка ETC85,000 + 140,000$225,000-$25,000

По типовой формуле ETC = 242 857 - 85 000 = $157 857. TCPI для достижения BAC = 130 000 / 115 000 = 1,13, а TCPI для достижения EAC в $242 857 = 130 000 / 157 857 = 0,82, что просто совпадает с текущим CPI.

Выбор правильного EAC

  1. Выясните, почему возникло отклонение.
  2. Если причина сохраняется (например, ставки выше плановых), используйте BAC / CPI.
  3. Если оно было разовым (например, единичный сбой поставщика), используйте AC + (BAC - EV).
  4. Если нужно уложиться в фиксированную дату, а вы отстаёте, рассмотрите формулу с CPI x SPI.
  5. Если допущения существенно изменились, заново оцените оставшуюся работу восходящим методом.
  6. Указывайте диапазон: формулы вместе дают полезный разброс от лучшего до худшего сценария.

Типичные ошибки

  • Предположение, что перерасход чудесным образом компенсируется (использование AC + (BAC - EV) по умолчанию).
  • Использование единственного раннего значения CPI; дождитесь тренда.
  • Игнорирование принятых обязательств, по которым ещё не выставлены счета.
  • Путаница EAC с BAC или с лимитом финансирования.

Частые вопросы

Что такое прогноз по завершении?

Прогнозная общая стоимость проекта на момент завершения всех работ, обозначается EAC.

Какая формула EAC самая распространённая?

EAC = BAC / CPI, что предполагает сохранение текущей эффективности затрат.

В чём разница между EAC и ETC?

EAC — прогнозная общая стоимость; ETC — прогнозная стоимость оставшейся работы. EAC = AC + ETC.

Когда использовать EAC = AC + (BAC - EV)?

Когда прошлое отклонение было разовым и вы ожидаете, что остальная работа пойдёт по плану.

Когда использовать формулу EAC с CPI x SPI?

Когда давление сроков, вероятно, повлияет на затраты, например когда фиксированный срок требует дополнительных усилий, чтобы наверстать отставание.

Как EAC используется для расчёта VAC?

Отклонение по завершении = BAC - EAC. Отрицательный VAC — это прогнозируемый перерасход.

Что означает TCPI выше 1 при ориентации на EAC?

Оставшуюся работу нужно выполнить эффективнее, чем планировалось, чтобы достичь цели. Значения значительно выше 1 часто нереалистичны.

Как часто нужно обновлять EAC?

Каждый отчётный период вместе с другими показателями освоенного объёма.

Может ли EAC быть ниже BAC?

Да. Если CPI выше 1, прогнозируется завершение проекта с экономией бюджета.

Лучше ли восходящий EAC, чем расчёт по формуле?

Часто да, если план существенно изменился, потому что он отражает текущие знания. Формулы быстрее и полезны для перекрёстной проверки.

Чем EAC отличается от прогноза проекта?

EAC — это стоимостная часть прогнозирования проекта, которое также охватывает даты завершения и выгоды.
