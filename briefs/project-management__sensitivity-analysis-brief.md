## Outline (target ~3,800 words including FAQ)

Key takeaways (5-6).

### H2: What is sensitivity analysis?
- 40-60 word definition paragraph (featured snippet).
- Base case, inputs, output, swing; "what-if" framing.
- Where it sits: quantitative risk analysis (PMBOK Guide lists it with tornado diagrams), financial appraisal, schedule analysis.

### H2: Why project managers use sensitivity analysis
- Find the few drivers; test the business case; switching values; prioritise risk responses; size contingency; communicate to sponsors.

### H2: Key terms
- Table: base case, input variable, output, range, swing, switching value/break-even, sensitivity ratio, tornado chart, spider chart.

### H2: Types of sensitivity analysis
- One-at-a-time (local), two-way data tables, break-even/switching value, scenario analysis, probabilistic (Monte Carlo correlation/tornado).
- Table: method, what changes, output, when to use.

### H2: How to do a sensitivity analysis step by step
- OL of 9 steps with explanations (define decision and output, build model, base case, choose variables, set ranges, OAT runs, swings, rank/tornado, break-even, act and record).
- H3: Choosing realistic ranges (data, expert judgment, three-point estimates, avoid uniform ±10% when data exist).

### H2: Worked example 1: product profit and a tornado chart
- Model, base case, table of swings, tornado reading, sensitivity ratio, break-even price.
- H3: Why one-at-a-time is not the whole story (combined worst case goes negative).
- H3: Two-way data table (price x units grid).

### H2: Worked example 2: NPV of an IT investment
- Base case NPV, variable-specific ranges, table, break-even benefit and IRR as switching discount rate, decision.

### H2: Worked example 3: sensitivity in a project schedule
- Small network, critical and near-critical path, table of +/-5 day tests, lesson about float and non-linear response; link to Monte Carlo criticality/sensitivity reports.

### H2: How to read a tornado chart (and a spider chart)
- Bar order, asymmetric bars, colours for low/high, what spider charts add.

### H2: Sensitivity analysis vs other techniques
- Table vs scenario, break-even, Monte Carlo, EMV/decision tree, cost-benefit analysis.

### H2: Doing a sensitivity analysis in Excel or Google Sheets
- Steps: inputs block, model, one-variable data table, two-variable data table, Goal Seek for break-even, tornado chart from sorted bar chart.

### H2: Using the results in your project
- Risk register, contingency/reserves, estimating effort, contracts (fixed price on sensitive inputs), monitoring triggers, business case presentation.

### H2: Common mistakes
- Uniform ranges, ignoring correlations, wrong model, too many variables, treating results as probabilities, no record of sources, not repeating.

### H2: Sensitivity analysis checklist
- Short pre-presentation checklist.
