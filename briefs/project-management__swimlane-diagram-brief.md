### H2: What is a swimlane diagram?
- 40–60 word snippet definition.
- Other names: cross-functional flowchart, Rummler-Brache diagram, deployment flowchart, swimlane process map.
- Brief history: Rummler and Brache popularised them in *Improving Performance* (1990); the idea of multi-column process charts is older.
- Why the lanes matter: ownership and handoffs become visible.

### H2: Parts of a swimlane diagram
- Lanes, optional phase columns, start/end, activity, decision, document, data/system, arrows, handoffs.
- Table of symbols and meanings.
- H3: Pools and lanes (BPMN) – pool = organisation/participant, lanes = roles inside it; message flows between pools.

### H2: Swimlane diagram vs flowchart and other process maps
- Table: flowchart, swimlane, BPMN, value stream map, SIPOC, RACI – what each shows, best for.

### H2: When to use a swimlane diagram (and when not to)
- Good uses: cross-team processes, approvals, onboarding, change requests, incident handling, project handovers, training, audits.
- Poor fits: single-owner processes, timelines (use Gantt), dependency logic (network diagram), detailed responsibility levels (RACI).

### H2: Horizontal vs vertical swimlanes
- When each fits; a table of lane types (roles, departments, systems, external parties, phases).

### H2: How to make a swimlane diagram: step by step
- 10 numbered steps: scope the process, choose lane type, list participants, gather people, record steps (sticky notes), place in lanes, add decisions and exceptions, connect arrows and mark handoffs, add time data, validate and version.
- H3s for scope, interviewing, drawing conventions.

### H2: Worked example: a project change request process
- Illustrative as-is table (lane, step, work time, wait time).
- Handoff count, elapsed time, flow efficiency calculation.
- To-be redesign and comparison table.

### H2: Second example: new starter IT access (parallel lanes)
- Shows parallel work and a system lane; how to draw parallel steps.

### H2: How to analyse a swimlane diagram for improvements
- Signals table: many handoffs, long waits, loops, approval stacking, overloaded lane, steps with no owner.
- Questions to ask; link to Lean, value stream mapping, fishbone, flow efficiency.
