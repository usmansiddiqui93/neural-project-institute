## Fact-Checking Notes (verified 4 November 2026)

- Six-activity network values copied from the rewritten forward/backward pass and float guides (day-0 convention): ES/EF/LS/LF A 0/3/0/3, B 3/7/3/7, C 3/5/7/9, D 7/12/7/12, E 5/8/9/12, F 12/14/12/14; TF C 4, E 4; FF C 0, E 4; critical A-B-D-F, 14 days. Website relaunch: critical A-B-E-G-H-I 27 days, C-D float 5, F float 7.
- DCMA 14-point thresholds (Deltek Acumen documentation): logic ≤ 5% missing predecessors/successors; leads 0%; lags ≤ 5% of links; FS ≥ 90% of links; hard constraints ≤ 5%; high float > 44 working days; negative float flagged.
- Microsoft Project desktop (Microsoft Support): View > Network Diagram; Format > Layout and Box Styles; link labels can show dependency type and lead/lag.
- History (Mosaic Projects): CPM algorithms by Kelley and Walker from 1956/57 for DuPont; PERT by the US Navy Special Projects Office in 1957; Fondahl published the precedence (activity-on-node) approach in the early 1960s.
- Tool facts from our reviews: Wrike critical path, float and all four dependency types from the Team plan; ClickUp critical path and slack; Smartsheet critical path; monday.com Pro critical path; Microsoft Planner and Project Plan 3 baselines and critical path. Asana and Jira: our reviews say no classic critical path, so do not claim it.
