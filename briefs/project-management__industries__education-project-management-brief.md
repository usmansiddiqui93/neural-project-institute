## Worked example (illustrative)
Hypothetical English FE college, 380 teaching staff, replacing its VLE for teaching starting Mon 6 Sep 2027. Backward pass: staff last day Fri 16 Jul 2027; migration latest start Mon 7 Jun; training latest start Mon 21 Jun; pilot latest start Mon 19 Apr (6 weeks to Fri 28 May before half-term); configuration latest start Mon 22 Feb (8 weeks); contract/onboarding latest start Mon 1 Feb (3 weeks). Governors approve 16 Dec 2026 (paper deadline Wed 2 Dec): work from Mon 4 Jan, config can start Mon 25 Jan → +4 weeks float. Approval at 17 Mar 2027 instead: config Mon 12 Apr–Fri 4 Jun → −7 weeks. Training: 380/16 = 23.75 → 24 sessions; at 85% attendance 27.94 → 28; one trainer 3 days × 2 sessions × 4 weeks = 24 slots. All verified in Python.
