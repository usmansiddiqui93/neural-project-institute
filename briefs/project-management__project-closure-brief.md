## Fact-checking notes
- PMBOK 8th edition: published November 2025; 6 principles, 7 performance domains; 40 processes in five focus areas including Closing (site facts, corroborated by 4pmti). Exact names of the Closing processes in the 8th edition could not be confirmed from a primary source, so do not name them.
- PMBOK 6th edition: Close Project or Phase in integration management; Close Procurements was removed in the 6th edition (contract closure folded into Close Project or Phase).
- PRINCE2 7 (2023): Closing a project process; activities include preparing planned or premature closure, handing over products, evaluating the project and recommending closure; the project board authorises closure via Directing a project. Outputs include the end project report and lessons report (secondary sources; keep wording general).
- Worked example figures are illustrative.
