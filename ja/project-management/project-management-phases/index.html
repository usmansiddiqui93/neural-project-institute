プロジェクトマネジメントの5つのフェーズ（プロジェクトライフサイクル）

規模を問わず、すべてのプロジェクトはライフサイクルを経て進みます。最も一般的なモデルには5つのフェーズがあり、それぞれに固有の活動、意思決定、文書があります。

執筆Neural Project Instituteプロジェクトマネジメント編集チーム
  • 公開日 2026年9月5日
  • 3分で読めます

要点

  • 5つのフェーズ：立ち上げ、計画、実行、監視・コントロール、終結。
  • 各フェーズには、憲章、計画書、教訓などの明確なアウトプットがあります。
  • 監視・コントロールはプロジェクト全体を通じて行われます。

概要

フェーズ目的主なアウトプット
1. 立ち上げプロジェクトを実施するかどうか、その理由を決めるビジネスケース、 プロジェクト憲章、ステークホルダー一覧
2. 計画プロジェクトの実行方法を定めるプロジェクトマネジメント計画書、スコープ、スケジュール、予算
3. 実行作業を行う成果物、状況報告
4. 監視・コントロール全期間を通じて追跡し修正するパフォーマンス報告書、承認済みの変更
5. 終結正式に完了する受入れ、教訓、アーカイブ

1. 立ち上げ

  • ニーズや機会を特定します。
  • 必要に応じて フィージビリティスタディ を実施します。
  • ビジネスケースを作成します。
  • プロジェクト憲章を作成し、承認を得ます。
  • 特定：主要な ステークホルダー.

2. 計画

  • 定義： スコープ 。作成： WBS（ワーク・ブレークダウン・ストラクチャー）.
  • 作成： スケジュール 。特定： クリティカルパス.
  • コストを見積もり、予算を設定します。
  • リスク、品質、コミュニケーション、調達を計画します。
  • 設定： ベースライン 。その後キックオフを開催します。

Excelをダウンロードすべての形式とレベル

3. 実行

  • チームをリードし、調整します。
  • 成果物を作成します。
  • ステークホルダーのエンゲージメントとコミュニケーションを管理します。
  • 物品やサービスを調達します。

4. 監視・コントロール

  • 進捗をベースラインと比較します。
  • 次を使ってコストとスケジュールを追跡します： アーンドバリュー.
  • リスクと課題を管理します。参考： RAIDログ.
  • 変更は次を通じて処理します： 変更管理.

5. 終結

  • 正式な受入れを得ます。
  • 契約と会計を終了します。
  • チームを解放します。
  • 教訓のレビューを実施します。
  • 文書をアーカイブします。

アジャイルプロジェクトにおけるフェーズ

アジャイルプロジェクトでは、計画、実行、レビューは一度きりではなく、イテレーションごとに繰り返されます。参考： アジャイルプロジェクトマネジメント.

よくある質問

プロジェクトマネジメントのフェーズは常に順番に進みますか？

立ち上げと終結は一度だけ行われますが、計画、実行、監視は重なり合い、繰り返されます。特に反復型のプロジェクトでは顕著です。

プロジェクトマネジメントのフェーズで最も重要なのはどれですか？

計画は成功の土台を築きますが、プロジェクトを軌道に乗せ続けるのは監視・コントロールです。

プロジェクトマネジメントの5つのフェーズとは何ですか？

立ち上げ、計画、実行、監視・コントロール、終結です。

プロジェクトマネジメントの立ち上げフェーズでは何が行われますか？

ニーズを特定し、実現可能性を確認し、ビジネスケースを作成し、 プロジェクト憲章 を承認し、主要なステークホルダーを特定します。

プロジェクトマネジメントの計画フェーズでは何が行われますか？

チームがスコープを定義し、WBSを作成し、スケジュールと予算を作成し、リスク、品質、コミュニケーションを計画し、ベースラインを設定します。

プロジェクトマネジメントの実行フェーズでは何が行われますか？

チームが作業を行い、成果物を作成し、ステークホルダーのエンゲージメントを管理し、物品やサービスを調達します。

プロジェクトマネジメントの監視・コントロールフェーズとは何ですか？

進捗をベースラインと比較し、コストとスケジュールを追跡し、リスクと課題を管理し、変更を 変更管理で処理します。プロジェクト全体を通じて行われます。

プロジェクトマネジメントの終結フェーズでは何が行われますか？

正式な受入れ、契約と会計の終了、チームの解放、 教訓 レビューの実施、文書のアーカイブです。

プロジェクトライフサイクルとは何ですか？

プロジェクトが開始から完了までに経る一連のフェーズです。ライフサイクルには予測型、反復型、漸進型、アジャイル型があります。

アジャイルプロジェクトでは、プロジェクトマネジメントのフェーズはどのように機能しますか？

計画、実行、レビューはイテレーションごとに繰り返されますが、立ち上げと終結は引き続き開始時と終了時に一度ずつ行われます。

プロジェクトライフサイクルにおけるフェーズゲートとは何ですか？

フェーズの終わりに行うレビューで、プロジェクトを継続するか、方向を変えるか、中止するかを決定します。
