プロジェクト調達マネジメント：プロセス、契約、例

プロジェクトの調達マネジメントは、プロジェクトに必要な物品、サービス、所産をチームの外部から購入することを扱います。何を購入するかの決定、サプライヤーの選定、契約の合意、そして作業が受け入れられて終了するまでの契約の管理が含まれます。

要点

  • 調達マネジメントは、購入の計画、実行、コントロールを扱います。
  • 調達を決める前に、複数年のコストを用いた内外製分析を行いましょう。
  • 契約タイプによって、誰がコストリスクを負うかが決まります。
  • 明確な作業範囲記述書と公平な選定基準が争いを防ぎます。

調達のプロセス

PMBOK第6版では、調達マネジメントの3つのプロセスを説明しています：

プロセス行うこと主なアウトプット
調達マネジメントの計画何を、どのように、いつ購入するかを決め、内外製分析を行う調達マネジメント計画、作業範囲記述書、入札文書、選定基準
調達の実行入札文書を発行し、回答を受け取り、サプライヤーを評価・選定し、交渉する選定された売り手、締結された契約
調達のコントロール契約を管理し、実績を監視し、変更やクレームに対処し、契約を終了する受け入れ済みの成果物、終了した調達、更新された記録

多くの組織では、明確な 終了 ステップを加えています。すべての作業が受け入れられたことを確認し、最終支払いを精算し、次のためにサプライヤーの実績を記録します： 教訓.

内外製分析：計算例

あるプロジェクトで顧客予約システムが必要になりました。チームは自社で 構築する か、ホスト型製品を 購入する ことができます。比較は3年間の利用を対象とします。

コスト項目内製（社内で構築）購入（ホスト型製品）
初期費用600時間 x $90 = $54,000セットアップと設定 $8,000
年間運用コスト保守 $12,000サブスクリプション $1,500 x 12 = $18,000
3年間の合計$54,000 + 3 x $12,000 = $90,000$8,000 + 3 x $18,000 = $62,000

3年間で見ると、購入のほうが $28,000安くなります。自社構築の選択肢が追いつくのは$54,000 + $12,000t = $8,000 + $18,000tとなるときで、t = $46,000 / $6,000 = 約7.7年です。システムをそれよりはるかに長く使う見込みがあるか、どの製品にもない機能が必要でない限り、コスト面では購入のほうが優れた選択です。

財務以外の要素も重要です。機能のコントロール、データの所有権、サプライヤーへのロックイン、社内のスキル、市場投入までの時間などです。 費用便益分析 または 正味現在価値 の計算で、比較をさらに精緻にできます。

契約タイプ

種類支払いの仕組みリスクを主に負う側最適な場面
完全定額契約（FFP）定義されたスコープに対する1つの合意価格売り手スコープが明確で安定している
定額インセンティブ・フィー契約（FPIF）固定価格に、実績に連動したインセンティブを加減共有（主に売り手）実績目標を測定できる
経済価格調整付き定額契約（FP-EPA）インフレや商品価格に応じて調整される固定価格共有投入コストの変動が大きい長期契約
コスト・プラス定額フィー契約（CPFF）実際の許容コストに固定フィーを加算買い手スコープが不確実
コスト・プラス・インセンティブ・フィー契約（CPIF）目標に対する実績に応じて変動するフィーをコストに加算共有スコープは不確実だが、目標は測定可能
コスト・プラス・アワード・フィー契約（CPAF）主観的な実績評価に基づいて与えられるフィーをコストに加算買い手実績を客観的に測定するのが難しい
タイムアンドマテリアル（T&M）時間または日ごとの合意単価と資材費買い手小規模または緊急の作業、要員の補強

調達文書

文書目的
情報提供依頼書（RFI）購入方法を決める前に、市場が何を提供しているかを把握する
見積依頼書（RFQ）明確に仕様が定められた物品やサービスの価格を入手する
提案依頼書（RFP）より複雑なニーズに対して、サプライヤーに解決策と価格の提案を依頼する
調達作業範囲記述書サプライヤーが提供すべきものを記述する。参考： 作業範囲記述書
発注先選定基準価格、能力、経験、リスクなど、入札の採点方法を定義する

調達を進める手順

  1. ニーズを確認し、内外製の判断を完了する。
  2. 契約タイプを選び、作業範囲記述書を作成する。
  3. 入札を見る前に、重み付けした選定基準に合意しましょう。
  4. RFI、RFQ、RFPを発行し、サプライヤーからの質問にすべての入札者に対して公平に回答する。
  5. 基準に照らして入札を評価し、候補を絞り込み、交渉する。
  6. 契約を締結し、サプライヤーとキックオフ会議を開催する。
  7. 納品、品質、請求書、変更を監視する。変更は次を通じて管理する： 変更管理.
  8. 成果物を受け入れ、契約を終了し、教訓を記録する。

コツとよくある間違い

  • 作業範囲記述書は正確に書きましょう。あいまいなスコープは争いやクレームにつながります。
  • プロセスの公平性を保つため、入札が届く前に選定基準と重みを確定しましょう。
  • 価格だけで選ばず、能力、リスク、サポートを比較検討しましょう。
  • 次の中で調達のリードタイムを見込んでおく： プロジェクトスケジュール.
  • すべてのやり取りと変更の記録を残しましょう。
  • 重要な案件では、早い段階から法務部門と財務部門を関与させましょう。
ヒント

納期遅延や倒産などのサプライヤーリスクは、 リスク登録簿 に、契約締結後すぐに追加しましょう。

よくある質問

プロジェクトの調達マネジメントとは何ですか？

プロジェクトチームの外部から物品、サービス、所産を購入するためのプロセスで、計画とサプライヤーの選定から、契約管理と終了までを含みます。

PMBOKにおけるプロジェクトの調達マネジメントのプロセスとは何ですか？

PMBOK第6版では、調達マネジメントの計画、調達の実行、調達のコントロールが挙げられています。

プロジェクトの調達における内外製分析とは何ですか？

あるものを社内で生産する場合とサプライヤーから購入する場合のコスト、リスク、ベネフィットを比較するもので、調達するかどうかを決めるために使います。

プロジェクトの調達における主な契約タイプは何ですか？

定額契約、実費償還契約、タイム・アンド・マテリアル契約で、それぞれに買い手と売り手の間でリスクの分担が異なる派生形があります。

プロジェクトの調達において、買い手にとって最もリスクの高い契約タイプはどれですか？

実費償還契約です。買い手は売り手の実際の許容コストを支払うため、そのコストが上昇する可能性があるからです。

プロジェクトの調達において、売り手にとって最もリスクの高い契約タイプはどれですか？

完全定額契約です。コストが上昇しても、売り手は合意した価格で合意したスコープを提供しなければならないからです。

プロジェクトの調達におけるRFPとRFQの違いは何ですか？

RFQは明確に定義された品目の価格を求めるもので、RFPはサプライヤーに価格だけでなく解決策の提案も求めるものです。

プロジェクトの調達における作業範囲記述書とは何ですか？

サプライヤーが提供すべき作業、製品、サービスの記述で、サプライヤーが価格を見積もり、買い手が受け入れを判断できるだけの詳しさが必要です。

プロジェクトの調達における発注先選定基準とは何ですか？

入札の評価に使う要素とその重みで、価格、技術的アプローチ、経験、キャパシティ、財務の安定性などがあります。

プロジェクトの調達におけるタイム・アンド・マテリアル契約とは何ですか？

作業時間に対する合意した単価と資材費を支払う契約で、小規模または緊急の作業や追加要員によく使われます。

プロジェクトの調達マネジメントは誰が担当しますか？

プロジェクトマネージャーがニーズを定義して実績を管理し、通常は調達部門や契約部門が正式なプロセスを運営して契約を締結します。

プロジェクトの調達はどのように終了しますか？

すべての成果物が受け入れられたことを確認し、最終支払いとクレームを精算し、記録をアーカイブし、サプライヤーの実績を記録することで終了します。
