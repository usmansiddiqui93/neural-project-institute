アーンドバリューマネジメント（EVM）：計算式と計算例

アーンドバリューマネジメント（EVM）とは、計画した作業の価値、実際に完了した作業の価値、その作業の実コストを比較してプロジェクトのパフォーマンスを測定する技法です。コストとスケジュールのパフォーマンスを客観的に把握でき、最終コストを予測する根拠にもなります。

要点

  • EVMはPV、EV、ACを比較して、コストとスケジュールのパフォーマンスを測定します。
  • CVとCPIはコストを、SVとSPIはスケジュールを測定します。
  • EAC、ETC、VAC、TCPIでプロジェクトの着地点を予測します。
  • しっかりしたベースラインと客観的な進捗ルールが、EVMの信頼性を高めます。

3つの中核指標

指標別名意味
計画価値（PV）BCWS現時点までに完了予定の作業の予算コスト
アーンドバリュー（EV）BCWP現時点までに実際に完了した作業の予算コスト
実コスト（AC）ACWP完了した作業に実際にかかったコスト
完成時総予算（BAC）すべての作業の総予算。参考： BAC

アーンドバリュー = 完了率 × BAC（または完了した作業の予算の合計）。

主要な計算式

計算式計算読み方
コスト差異（CV）EV - AC負 = 予算超過
スケジュール差異（SV）EV - PV負 = スケジュール遅延
コスト効率指数（CPI）EV / AC1未満 = 予算超過
スケジュール効率指数（SPI）EV / PV1未満 = スケジュール遅延
完成時総コスト見積り（EAC）BAC / CPI（典型的）最終コストの予測
EAC（非典型的な差異）AC + (BAC - EV)過去の差異が再発しない場合
EAC（コストとスケジュール）AC + (BAC - EV) / (CPI x SPI)両方の指数が残作業に影響する場合
EAC（新たな見積り）AC + ボトムアップのETC当初の計画がもはや有効でない場合
残作業コスト見積り（ETC）EAC - AC今後必要な資金
完成時差異（VAC）BAC - EAC負 = 超過見込み
TCPI（BAC基準）(BAC - EV) / (BAC - AC)予算内で完了するために必要な効率
TCPI（EAC基準）(BAC - EV) / (EAC - AC)EACを達成するために必要な効率

計算例

あるプロジェクトは8か月でBAC = $200,000です。4か月目の終わりの時点で、PV = $80,000、EV = $70,000（35%完了）、AC = $85,000です。

指標計算結果
CV70,000 - 85,000-$15,000
SV70,000 - 80,000-$10,000
CPI70,000 / 85,0000.82
SPI70,000 / 80,0000.88 (0.875)
EAC（典型的）200,000 / 0.8235$242,857
EAC（非典型的）85,000 + 130,000$215,000
EAC（CPI x SPI）85,000 + 130,000 / 0.7206$265,408
ETC（典型的）242,857 - 85,000$157,857
VAC200,000 - 242,857-$42,857
TCPI（BAC基準）130,000 / 115,0001.13

解釈：このプロジェクトは予算超過かつスケジュール遅延です。現在のコスト効率が続けば、約$42,857の予算超過で完了します。予算内で完了するには、残作業でCPI 1.13が必要であり、これまでに達成した0.82を大きく上回ります。

EVMの導入方法

  1. 次を使ってスコープを定義します： WBS（ワーク・ブレークダウン・ストラクチャー）.
  2. 作業をスケジュールし予算を割り当てて、期間別のベースラインを作成します ( Sカーブ).
  3. 0/100、50/50、測定可能なマイルストーンなど、進捗を計上するルールを合意します。
  4. 期間ごとにワークパッケージ別の実コストを収集します。
  5. PV、EV、ACを計算し、続いて差異と指数を計算します。
  6. EACを予測し、原因を確認して対処します。
  7. 単発の数値だけでなく、傾向を報告します。

メリットと限界

メリット限界
スコープ、時間、コストを統合した客観的な視点適切なベースラインと正確な実コストが必要
早期警告：CPIは早い段階で安定する傾向があるSVは次について何も示さない： クリティカルパス
広く理解されている標準的な計算式プロジェクトが遅れていても、SVは最後にゼロに戻る
予測に役立つ進捗の計上が操作されたり主観的になったりしうる

コツ

  • 短いタスクにはシンプルな進捗ルールを使い、主観的な完了率を避けましょう。
  • CPIとSPIの傾向を複数の期間にわたって追跡しましょう。
  • SPIはクリティカルパス分析やアーンドスケジュールと組み合わせましょう。
  • 報告では結果を平易な言葉で説明しましょう。ほとんどのステークホルダーは略語を知りません。

よくある質問

アーンドバリューマネジメントとは何ですか？

計画価値、アーンドバリュー、実コストを比較してコストとスケジュールのパフォーマンスを評価する、プロジェクトのパフォーマンス測定手法です。

アーンドバリューマネジメントにおけるPV、EV、ACの違いは何ですか？

PVは現時点までに予定していた作業の予算上の価値、EVは実際に完了した作業の予算上の価値、ACはその作業に実際にかかったコストです。

アーンドバリューはどのように計算しますか？

作業の完了率に完成時総予算を掛けるか、完了したワークパッケージの予算を合計します。

コスト差異を求めるアーンドバリューの計算式は何ですか？

CV = EV - AC。負の値はプロジェクトが予算超過であることを意味します。

スケジュール差異を求めるアーンドバリューの計算式は何ですか？

SV = EV - PV。負の値は計画より完了した作業が少ないことを意味します。

アーンドバリューマネジメントでCPIが0.8とはどういう意味ですか？

1ドル使うごとに80セント分の計画作業しか得られていない、つまり予算超過で進んでいることを意味します。

アーンドバリューマネジメントでは、どのEAC計算式を使うべきですか？

現在のパフォーマンスが続くと見込まれる場合はBAC / CPI、差異が一時的なものだった場合はAC + (BAC - EV)、計画がもはや有効でない場合はAC + 新たなETCを使います。

アーンドバリューマネジメントにおけるTCPIとは何ですか？

残作業効率指数のことで、BACまたは新たなEACで完了するために残作業で必要となるCPIです。

アーンドバリューマネジメントにおけるBCWSとBCWPとは何ですか？

PV（計画作業の予算コスト）とEV（実施作業の予算コスト）の旧称です。ACWPは実施作業の実コストです。

EVMはアジャイルプロジェクトでも使われますか？

はい、形を変えて使われます。アジャイルEVMでは、リリースごとの計画ポイントに対する完了したストーリーポイントを使ってEVを計算することがよくあります。

アーンドバリューはPMP試験に出題されますか？

はい。アーンドバリューの計算はPMP試験対策の定番分野です。参考： PMP資格.

EVMにおけるアーンドスケジュールとは何ですか？

スケジュールのパフォーマンスを金額ではなく時間単位で測定するEVMの拡張手法で、SVが最後にゼロに戻ってしまう問題を回避できます。
