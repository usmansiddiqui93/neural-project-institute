フルタイム当量（FTE）：意味、計算式、例

フルタイム当量（FTE）とは、個人やチームが提供する労働時間を、フルタイム従業員1人と比較して表す単位です。1 FTEはフルタイムで1週間働く1人に相当し、その半分働く人は0.5 FTEです。

要点

  • FTE = 働いた時間 / 同じ期間のフルタイムの時間。
  • 使うフルタイムの基準を必ず明記しましょう。
  • プロジェクトに人員を配置する前に、実働時間に合わせてFTEを調整しましょう。
  • FTEはキャパシティを、ヘッドカウントは人数を測ります。

FTEの計算式

FTE = 働いた（または計画した）時間 / 同じ期間のフルタイムの勤務時間

フルタイムの意味は組織が定義し、一般的には週35時間、37.5時間、40時間です。同じ時間数でも定義によってFTEの数値が変わるため、使う基準を必ず明記しましょう。

  • 週単位：週あたりの時間 / 標準の週あたりの時間。
  • 年単位：年間の時間 / 標準の年間時間（40時間 x 52週 = 2,080時間が一般的な基準）。
  • プロジェクト単位：総工数の時間 /（標準の週あたりの時間 x 週数）。

計算例1：混成チームのFTE

この組織のフルタイムは週40時間です。

計算例2：工数をFTEに換算する

あるプロジェクトには 1,200時間 の開発工数が必要で、期間は 10週間です。標準の週40時間の場合：

  1. 10週間で1 FTEが提供する時間：40 x 10 = 400時間。
  2. 必要なFTE：1,200 / 400 = 3.0 FTE.
  3. 実働時間で調整する：時間の80%しかプロジェクト作業に使われない場合、1 FTEが提供するのは320時間のプロジェクト時間なので、1,200 / 320 = 3.75 FTE.

人員配置の基準にすべきなのは2つ目の数値です。3.0 FTEで計画すると、チームは240時間不足します。参考： 工数見積り （1,200時間の見積り方）。

計算例3：FTEとコスト

開発者1人の総コストが時間あたり$90の場合、週40時間で10週間の3.75 FTEのコストは 3.75 x 40 x 10 x $90 = $135,000。FTEの数値は簡単に次に換算できます： プロジェクト予算 と コスト見積り （時間に直接結びついているため）。

よくある間違い

  • フルタイムの基準（35、37.5、40時間）を明記しないこと。
  • 1.0 FTEを40時間の実働プロジェクト時間として扱うこと。会議や事務によって減ります。
  • 1人を複数のプロジェクトにそれぞれ1.0 FTEで割り当てること。
  • 契約上のFTE（支払われる時間）と割り当てられたFTE（このプロジェクトでの時間）を混同すること。
  • 0.5 FTEの2人が1.0 FTEの1人と同じ成果を出すと想定すること。引き継ぎやコンテキストスイッチには時間がかかります。
ヒント

リソース計画では、その人の契約上のFTEと、自分のプロジェクトに割り当てられたFTEの両方を示しましょう。その差から他の業務にどれだけ時間を割く必要があるかがわかり、次に役立ちます： キャパシティプランニング.

よくある質問

FTEは何の略ですか？

フルタイム当量：フルタイム従業員1人に対する相対値で労働時間を表す単位です。

FTEはどのように計算しますか？

働いた時間または計画した時間を、同じ期間のフルタイムの勤務時間で割ります。たとえば、週40時間のうち30時間なら0.75 FTEです。

1 FTEは年間何時間ですか？

組織のフルタイムの定義によります。週40時間の場合、一般的な基準は40 x 52 = 2,080時間です。休暇を差し引いて実働時間を求める組織もあります。

0.5 FTEとは何ですか？

フルタイムの勤務の半分です。たとえば、フルタイムが週40時間の場合は週20時間です。

FTEとヘッドカウントの違いは何ですか？

ヘッドカウントは人数を数え、FTEはその人々が提供する労働時間を測ります。パートタイム（半分）の2人はヘッドカウント2ですが、1.0 FTEです。

プロジェクトの時間をFTEに換算するにはどうすればよいですか？

総工数の時間を、プロジェクト期間に1 FTEが提供する時間で割ります。週40時間で10週間にわたる1,200時間なら、1,200 / 400 = 3.0 FTEです。

1人でFTEが1を超えることはありますか？

計算上は、定期的に残業していればあり得ますが、誰かを1.0 FTEを超えて計画することは、燃え尽きとリスクの警告サインです。

プロジェクトマネージャーがFTEを使うのはなぜですか？

勤務形態が異なるチーム間で、キャパシティ、需要、コストを比較しやすくなり、予算にも簡単に換算できるからです。

週37.5時間は1 FTEですか？

組織がフルタイムを37.5時間と定義していればそうなります。FTEは常に組織自身の基準に対する相対値です。

FTEはリソース計画でどのように使われますか？

リソース計画では、2〜6か月目に開発者2.0 FTEなど、期間ごとに必要なFTEを役割別に記載します。参考： プロジェクトのリソース.

1 FTEはプロジェクトに100%の時間を使うという意味ですか？

必ずしもそうではありません。1 FTEはフルタイムの勤務を意味しますが、会議やその他の業務を考慮すると、実際にプロジェクトに使われる割合は通常それより低くなります。
