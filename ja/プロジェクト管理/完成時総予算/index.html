完成時総予算（BAC）：定義、計算式、例

完成時総予算（BAC）とは、プロジェクト、またはコントロールアカウントやワークパッケージのすべての作業に対する計画上の総予算です。コストベースラインに等しく、アーンドバリュー、予測、差異を測る基準となる数値です。

要点

  • BACはコストベースライン、つまり作業に対して計画された総予算です。
  • コンティンジェンシー予備は含みますが、マネジメント予備は含みません。
  • EV、EAC、VAC、TCPIはすべてBACから計算されます。
  • BACは正式な変更管理を通じてのみ変わります。

BACの計算方法

BACは、すべてのワークパッケージの予算にコンティンジェンシー予備を加えた合計です。マネジメント予備は 含みません 。

構成要素金額
デザイン$40,000
構築$90,000
テスト$30,000
展開と研修$20,000
コンティンジェンシー予備$20,000
BAC（コストベースライン）$200,000
マネジメント予備（含まない）$15,000
プロジェクト総予算$215,000

BACの使い方

  • アーンドバリュー： EV = 完了率 x BAC。完了率35%の場合、EV = 0.35 x 200,000 = $70,000。
  • 予測： EAC = BAC / CPI。CPIが0.8235の場合、EAC = $242,857。
  • 完成時差異： VAC = BAC - EAC = 200,000 - 242,857 = -$42,857。
  • TCPI： (BAC - EV) / (BAC - AC) は、BAC内で完了するために必要な効率を示します。
  • 支出率： AC / BAC = 85,000 / 200,000 = 42.5%。これに対して完了率は35%です。

BACが変わるとき

BACはベースラインであるため、変更は次を通じてのみ行うべきです： 変更管理。たとえば、承認されたスコープが追加されたときや、スコープ内の新しい作業のためにマネジメント予備が解放されたときです。コストがかさんでいるという理由だけでBACを変更すると、実際のパフォーマンスが隠れてしまいます。

コツ

  • コントロールアカウントの予算の合計がBACに等しいことを確認しましょう。
  • 傾向に意味を持たせるため、承認された変更の間はBACを固定しておきましょう。
  • BACとEACを並べて報告し、予測との差が一目でわかるようにしましょう。
  • ベースラインの変更はすべて、理由と日付とともに記録しましょう。

よくある質問

完成時総予算とは何ですか？

プロジェクトのすべての作業に対して計画された総予算で、コストベースラインに等しいものです。BACと表記します。

BACはどのように計算しますか？

すべてのワークパッケージの予算とコンティンジェンシー予備を合計します。マネジメント予備は除きます。

BACにはマネジメント予備が含まれますか？

いいえ。マネジメント予備はコストベースラインの外にあり、これをBACに加えるとプロジェクト総予算になります。

BACとEACの違いは何ですか？

BACは作業にかかると計画されたコストです。EACは実際にかかるコストの現時点での予測です。

プロジェクトの途中でBACは変わりますか？

スコープの追加など、承認された変更を通じてのみ変わります。超過を隠すためだけに変更してはいけません。

BACはアーンドバリューの計算にどう使われますか？

EV = 作業の完了率 x BAC。BACが$200,000で作業が35%完了していれば、EVは$70,000です。

BACはVACの計算にどう使われますか？

完成時差異、BAC - EAC。マイナスの値は、終了時に見込まれる超過額です。

BACはプロジェクト予算と同じですか？

厳密には違います。BACはコストベースラインであり、プロジェクト予算にはさらにマネジメント予備が加わります。

BACにはコンティンジェンシー予備が含まれますか？

はい。特定されたリスクに対するコンティンジェンシー予備はコストベースラインの一部であり、したがってBACにも含まれます。

プロジェクトの一部についてBACを計算できますか？

はい。各コントロールアカウントとワークパッケージにはそれぞれBACがあり、それらを合計するとプロジェクトのBACになります。
