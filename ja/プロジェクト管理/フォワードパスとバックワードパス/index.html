フォワードパスとバックワードパス：ステップバイステップの計算例

フォワードパスとバックワードパスは、 クリティカルパス法の中核となる2つの計算です。フォワードパスは始まりから終わりに向かって各アクティビティの最早日付を求め、バックワードパスは終わりから始まりに向かって最遅日付を求めます。両者を比較するとフロートが得られます。

  • 4分で読めます

要点

  • フォワードパス：EF = ES + 所要期間。合流点では最大のEFを取ります。
  • バックワードパス：LS = LF - 所要期間。分岐点では最小のLSを取ります。
  • トータルフロート = LS - ES。フロートがゼロのものがクリティカルパスを示します。
  • フリーフロートは、後続アクティビティに影響を与えずにアクティビティがどれだけずれ込めるかを示します。

計算式

パス計算式複数のつながりがある場合のルール
フォワードEF = ES + 所要期間ES = 最大 値（すべての先行アクティビティのEF）
バックワードLS = LF - 所要期間LF = 最小 値（すべての後続アクティビティのLS）
フロートトータルフロート = LS - ES = LF - EFフリーフロート = 後続アクティビティの最も早いES - EF

このガイドでは0日目の慣行を使います。最初のアクティビティは0から始まり、後続アクティビティは先行アクティビティのEFから始まります。ES = 前のEF + 1とする1日目の慣行を使う教科書もありますが、フロートとクリティカルパスは同じ結果になります。

ステップ1：フォワードパス

  1. A：ES = 0、EF = 0 + 3 = 3。
  2. B：ES = 3（AのEF）、EF = 3 + 4 = 7。
  3. C：ES = 3、EF = 3 + 2 = 5。
  4. D：ES = 7、EF = 7 + 5 = 12。
  5. E：ES = 5、EF = 5 + 3 = 8。
  6. F：先行アクティビティはD（EF 12）とE（EF 8）の2つ。大きいほうを取る：ES = 12、EF = 12 + 2 = 14。
  7. プロジェクトの所要期間 = 14日。

ステップ2：バックワードパス

  1. F：LF = 14（プロジェクトの終了）、LS = 14 - 2 = 12。
  2. D：LF = 12（FのLS）、LS = 12 - 5 = 7。
  3. E：LF = 12、LS = 12 - 3 = 9。
  4. B：LF = 7（DのLS）、LS = 7 - 4 = 3。
  5. C：LF = 9（EのLS）、LS = 9 - 2 = 7。
  6. A：後続アクティビティはB（LS 3）とC（LS 7）の2つ。小さいほうを取る：LF = 3、LS = 3 - 3 = 0。

トータルフロートがゼロのアクティビティ（ A-B-D-F）がクリティカルパスです。Cにはトータルフロートが4日ありますが、フリーフロートはありません。Cが遅れればEの開始が遅れます。Eは両方とも4日あります。Fは12日目までEを必要としないからです。参考： フロートとスラック.

よくある間違い

  • フォワードパスの合流点で、最大ではなく最小のEFを取ること。
  • バックワードパスの分岐点で、最小ではなく最大のLSを取ること。
  • 1つの計算の中で0日目と1日目の慣行を混在させること。
  • ラグの加算を忘れること：FS+2の場合、後続アクティビティのES = 先行アクティビティのEF + 2。参考： リードとラグ.
ヒント

確認しましょう：クリティカルパス上ではすべてのアクティビティでESがLSと等しく、最後のアクティビティのEFはLFと等しくなければなりません。

よくある質問

フォワードパスとは何ですか？

ネットワークの始まりから終わりに向かって行う計算で、各アクティビティの最早開始と最早終了を求めます。

バックワードパスとは何ですか？

ネットワークの終わりから始まりに向かって行う計算で、各アクティビティの最遅終了と最遅開始を求めます。

フォワードパスで最大のEFを取るのはなぜですか？

アクティビティはすべての先行アクティビティが終わるまで開始できないため、最も遅く終わるものがそのアクティビティを左右するからです。

バックワードパスで最小のLSを取るのはなぜですか？

アクティビティは、最も早く必要とされる後続アクティビティに間に合うように終わらなければならず、そうでなければその後続アクティビティが遅れるからです。

フォワードパスとバックワードパスからフロートをどのように計算しますか？

トータルフロート = LS - ES、またはLF - EF。どちらも同じ答えになります。

フォワードパスとバックワードパスの後、トータルフロートとフリーフロートの違いは何ですか？

トータルフロートはプロジェクトの終了を動かさずに許容される遅れで、フリーフロートはどの後続アクティビティも動かさずに許容される遅れです。

フォワードパスは0日目と1日目のどちらから始めるべきですか？

一貫していればどちらでも構いません。0日目は計算が簡単で、1日目は暦日により自然に対応します。

要求された終了日がフォワードパスの終了より早い場合はどうなりますか？

バックワードパスを要求された日付から始めます。すると一部のアクティビティでフロートがマイナスになり、どれだけの時間を取り戻す必要があるかがわかります。

フォワードパスとバックワードパスを手計算する必要はありますか？

スケジューリングソフトウェアは自動的に計算しますが、小さな例を手計算すると、仕組みの理解と結果の確認に役立ちます。試験でもよく出題されるテーマです。

フォワードパスとバックワードパスはPMP試験に出題されますか？

フロートやクリティカルパスなどのネットワーク計算は、PMPの試験対策でよく扱われます。参考： PMP資格.
