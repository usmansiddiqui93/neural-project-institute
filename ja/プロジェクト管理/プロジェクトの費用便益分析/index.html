プロジェクトの費用便益分析：手順と例

費用便益分析（CBA）は、プロジェクトの予想される総コストと予想される総便益を比較し、実施する価値があるかどうか、あるいは複数の選択肢のうちどれが最適かを判断するものです。優れたCBAでは、コストと便益に期間ごとの金額を付け、将来の金額を現在価値に割り引きます。

要点

  • CBAはすべてのコストと便益を金額で比較します。
  • 将来の金額を割り引き、何もしない選択肢を含めましょう。
  • NPVがゼロを上回り、BCRが1を上回れば、実施する価値のあるプロジェクトであることを示します。
  • 感度分析で主要な前提条件を検証します。

費用便益分析を使う場面

  • ビジネスケースまたは次の作成： フィージビリティスタディ.
  • 代替となるソリューションやサプライヤーの中からの選択。
  • 承認可否の判断：大規模な 変更要求.
  • ポートフォリオ内のプロジェクトの優先順位付け。

含めるべきコストと便益

コストメリット
初期投資：人件費、ハードウェア、ソフトウェア、報酬追加の収益
運用コスト：サポート、ライセンス、保守コスト削減
研修とチェンジマネジメント罰金やダウンタイムなどの回避されるコスト
変化の期間中の混乱デリバリーの迅速化や品質の向上
廃止無形の便益：満足度、評判、士気

費用便益分析の進め方

  1. 判断の対象と、何もしない場合を含む選択肢を定義します。
  2. 合意した期間について、各選択肢のすべてのコストと便益を洗い出します。
  3. それぞれに金額を付け、無形のものは別に記録します。
  4. 合意した割引率を使って将来の金額を割り引きます。参考： 正味現在価値.
  5. 純便益（便益の現在価値 - コストの現在価値）と費用便益比（便益の現在価値 / コストの現在価値）を計算します。
  6. 主要な前提条件を次で検証します： 感度分析.
  7. 前提条件とリスクを明記したうえで、選択肢を推奨します。

計算例

新しい予約システムには初期費用$120,000と年間運用費$10,000がかかります。年間$60,000の削減になります。分析期間は3年、割引率は8%です（3年の年金現価係数2.5771）。

割引なし現在価値
コスト120,000 + 3 x 10,000 = $150,000120,000 + 10,000 x 2.5771 = $145,771
メリット3 x 60,000 = $180,00060,000 x 2.5771 = $154,626
純便益（NPV）$30,000$8,855
費用便益比1.20154,626 / 145,771 = 1.06

BCRが1を上回りNPVがプラスであるため、プロジェクトは実施する価値がありますが、割引後の余裕はわずかなので、削減額の見積りに対する感度テストが不可欠です。

判断基準

指標採用の条件
正味現在価値ゼロより大きい
費用便益比1より大きい
投資利益率組織の目標を上回る
回収期間許容される最大期間より短い

よくある落とし穴

  • いずれにせよ生じる便益を計上すること。
  • 運用、研修、混乱のコストを含めないこと。
  • 複数年にわたる期間で貨幣の時間価値を無視すること。
  • 同じ便益を別の名前で二重に計上すること。
  • 前提条件を検証せずに1つの数値だけを提示すること。

よくある質問

費用便益分析とは何ですか？

プロジェクトの予想される総コストと予想される総便益を金額で比較し、実施する価値があるかどうかを判断するものです。

費用便益分析における費用便益比とは何ですか？

便益の現在価値をコストの現在価値で割った値です。1を上回れば、便益がコストを上回ることを意味します。

費用便益分析で純便益はどのように計算しますか？

純便益 = 総便益 - 総コスト。理想的には現在価値を使い、それがNPVになります。

費用便益分析で将来のコストと便益を割り引くのはなぜですか？

将来受け取るお金は今日のお金より価値が低いため、割り引くことで異なる時点の金額を比較できるようになります。

費用便益分析ではどの割引率を使うべきですか？

通常は財務チームが定める率で、組織の資本コストや要求収益率に基づくことが多いです。

費用便益分析で無形の便益はどう扱いますか？

合理的に可能であれば金額を見積もり、そうでなければ別に列挙して、数値と並べて明確に説明します。

費用便益分析とROIの違いは何ですか？

CBAはすべてのコストと便益を比較衡量し、多くの場合NPVやBCRで示します。ROIは純利益をコストに対する割合で表します。

費用便益分析には何もしない選択肢を含めるべきですか？

はい。比較の基準になりますし、何もしないこと自体にもコストがかかることがよくあります。

費用便益分析は誰が作成しますか？

多くの場合、プロジェクトマネージャーやビジネスアナリストが財務部門とともに作成し、スポンサーがレビューします。

CBAはプロジェクトのどこに位置づけられますか？

ビジネスケースと事業化調査の段階で行い、大きな変更を検討する際にも再度行います。

費用便益分析にはどのような限界がありますか？

将来の便益の見積りに大きく依存しており、その見積りは不確実であったり楽観的であったりすることがあります。
