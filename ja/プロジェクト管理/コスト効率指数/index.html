コスト効率指数（CPI）：計算式、例、意味

コスト効率指数（CPI）は、プロジェクトのコスト効率、つまり支出する資金1単位あたりどれだけの予算上の作業が得られるかを測る指標です。CPI = EV / ACで計算されるので、CPI 0.90は1ドルの支出につき90セント分の計画作業を得ていることを意味します。このガイドでは、計算式、結果の読み方、累積CPIと期間CPI、CPIを使った予測、そして健全に見えるプロジェクトのCPIが本当の問題を隠している計算例を扱います。

要点

  • CPI = EV / AC。1未満は実施済みの作業について予算超過、1を超える場合は予算内を意味します。
  • CPI 0.85は、作業1単位あたりのコストが計画より15%ではなく約18%（1 / 0.85）多いことを意味します。
  • プロジェクトのCPIは、EVの合計をACの合計で割って計算します。ワークパッケージのCPIを平均してはいけません。
  • 変化をすばやく捉えるには期間CPIを注視し、EAC = BAC / CPIなどの予測には累積CPIを使います。
  • プロジェクト全体のCPIが良好でも、不調なパッケージが隠れていることがあるため、ワークパッケージ別とコスト種別にCPIを確認します。
  • CPIをTCPIと比較し、予算がまだ達成可能かどうかを判断します。

コスト効率指数（CPI）とは何ですか？

なお、 コスト効率指数（CPI） は、コスト効率を表すアーンドバリュー・マネジメントの指標です。完了した作業のアーンドバリュー（EV）を、その作業の実コスト（AC）で割ります。CPIが1.0なら作業のコストは予算どおり、1.0未満なら予算より多くかかり、1.0を超えるなら予算より少なく済んだことを意味します。

CPIは、 アーンドバリューマネジメント（EVM）、そして コスト差異, スケジュール差異 とスケジュール効率指数（SPI）と並ぶ主要な指標の1つです。金額ではなく比率なので、規模の大きく異なるワークパッケージやプロジェクトの効率を比較できます。

古いEVMの資料や多くの政府契約では、インプットの呼び方が異なります。アーンドバリューは 実施済作業の予算コスト（BCWP） 、実コストは 実施済作業の実コスト（ACWP）と呼ばれるため、CPI = BCWP / ACWPと書かれた計算式を目にすることもあります。

ヒント

プロジェクトのコスト効率指数は、同じCPIという略称を持つインフレ指標の消費者物価指数とは無関係です。レポートでインフレとコスト効率の両方を扱う場合は、両方の名称を省略せずに書きましょう。

CPIの計算式

計算式示す内容
CPI = EV / ACこれまでに完了した作業のコスト効率
EV ＝ 完了率 x BACアーンドバリュー：実際に完了した作業の予算
累積CPI = これまでのEVの合計 / これまでのACの合計プロジェクト開始以降の効率。予測に使う
期間CPI = 今期のEV / 今期のAC1か月または1スプリントの効率。直近の変化を示す
プロジェクトのCPI = パッケージのEVの合計 / パッケージのACの合計パッケージの数値を集計する正しい方法
1 / CPI計画コスト1単位あたりの実コスト。たとえば1 / 0.85 = 1.18

BAC は 完成時総予算、つまり作業に対して承認された予算の総額です。 AC は、EVと同じ作業と同じ期間を対象とし、実施済みで未請求の作業の未払計上も含めなければなりません。

CPIの計算手順

  1. ステータス日を選ぶ を、進捗とコストの両方に使います。
  2. BACを取り出し を各 ワークパッケージ 、現在承認されている コストベースライン。承認済みの変更は含みますが、マネジメント予備は含みません。
  3. 完了率を測定する を、個人の判断ではなく、合意したルール（0/100、50/50、加重マイルストーン、完了単位数）を使って行います。
  4. EVを計算する を各パッケージについて算出します：完了率 x BAC。
  5. ACを収集する を各パッケージについて行い、未払計上の人件費とサプライヤーのコストを含めます。
  6. EVをACで割る を各パッケージについて行い、パッケージのCPIを求めます。
  7. EVとACを合計する を全パッケージについて行い、合計どうしを割ってプロジェクトのCPIを求めます。
  8. 前の期間と比較する としきい値と比較し、合計を動かしているパッケージを記録します。

簡単な例。 あるウェブサイト再構築のBACは$120,000です。40%完了しているので、EV = 0.40 x 120,000 = $48,000です。これまでの実コストは$54,000です。CPI = 48,000 / 54,000 = 0.89。チームは1ドルの支出につき約89セント分の計画作業を得ています。

CPIを超過率に換算する

よくある近道は、CPI 0.85を「15%の超過」と読むことですが、これは正確ではありません。CPI 0.85は、資金1単位あたり0.85単位の計画作業が得られることを意味するので、計画作業1単位のコストは1 / 0.85 = 1.176、つまり17.6%の超過です。CPIが下がるほど差は広がります。次の表は、各CPIがプロジェクト終了まで続いた場合の、$500,000の予算への影響を示しています：

計算例：包装ラインの更新

ある食品メーカーが包装ラインを更新しています。BACは $500,000 で、5つのワークパッケージにわたります。6か月目末時点の計画価値（PV）は$345,000です。ステータスは次のとおりです：

1. エンジニアリング設計$80,000100%$80,000$76,000+$4,0001.05
2. 機器の購入$220,00080%$176,000$171,000+$5,0001.03
3. 設置$120,00035%$42,000$56,000-$14,0000.75
4. 制御ソフトウェア$50,00040%$20,000$26,000-$6,0000.77

プロジェクトレベルでの読み取り

  • CPI = 318,000 / 329,000 = 0.97。 これだけ見ると、計画に近いように見えます。
  • SPI = 318,000 / 345,000 = 0.92。 プロジェクトはスケジュールにやや遅れています。
  • EAC = BAC / CPI = 500,000 / 0.967 = 約$517,300、つまり約$17,300（3.5%）の超過予測です。

見出しの数値だけを読んだスポンサーは、プロジェクトがわずかに予算を超過しているだけだと結論づけるでしょう。

パッケージから見えること

良好なCPIは、ほぼ完了しており固定価格の購入で構成されている設計と機器購入によるものです。今後残っている作業は人件費の比重が大きいもので、設置（CPI 0.75）と制御ソフトウェア（CPI 0.77）、さらに同じ設置作業員を使う試運転です。初期の効率のよいパッケージが合計を良く見せているのです。

パッケージレベルの予測は $544,750で、約$45,000（9%）の超過です。プロジェクトレベルの式による約$17,300と比べてください。試運転が設置と同じ0.75で推移すれば、予測は$554,750に上がります。プロジェクトのCPIが間違っていたわけではありませんが、好調だった過去の作業と不調な今後の作業を平均していたのです。

ヒント

残作業が完了済みの作業と性質が異なる場合は、プロジェクト全体の単一のCPIではなく、パッケージ別またはコスト種別（人件費、資材費、外注費）に予測します。

パッケージのCPIを決して平均してはいけない理由

4つのパッケージのCPIを単純平均すると、(1.05 + 1.03 + 0.75 + 0.77) / 4 = 0.90。正しいプロジェクトのCPIは、EVの合計をACの合計で割ったものです：318,000 / 329,000 = 0.97。単純平均では、制御ソフトウェアのような小さなパッケージに、機器購入のような大きなパッケージと同じ重みを与えてしまいます。必ず先にEVとACを合計し、それから割りましょう。プロジェクトをプログラムやポートフォリオに集計する場合も同じルールが当てはまります。

累積CPIと期間CPI

累積CPIはプロジェクト開始以降のすべてを含みます。期間CPIは1か月だけを見ます。包装ラインについて両方を示します：

月今月のEV今月のAC期間CPI累積EV累積AC累積CPI
1$30,000$29,0001.03$30,000$29,0001.03
2$40,000$38,0001.05$70,000$67,0001.04
3$95,000$90,0001.06$165,000$157,0001.05
4$70,000$70,0001.00$235,000$227,0001.04
5$45,000$51,0000.88$280,000$278,0001.01
6$38,000$51,0000.75$318,000$329,0000.97

設置は5か月目に始まりました。期間CPIは0.88、さらに0.75へと下がりましたが、5か月目の累積CPIはまだ1.0を上回っていました。累積値だけを見ていた人には、ある月は「予算をわずかに下回る」、翌月は「わずかに上回る」と映り、現在の作業がどれほど急速に悪化しているかを見逃したでしょう。

  • 期間CPIを使う を、変化を早期に捉え、是正処置が機能しているかを確認するために行います。
  • 累積CPIを使う を予測に使います。1か月だけの数値は、大きな請求書や遅れた未払計上で簡単に歪むからです。
  • 両方をプロットする。あるいは、累積EVとACを Sカーブとしてプロットすれば、線の間の差が広がることで同じ状況が分かります。

CPIを使って最終コストを予測する

CPIは、 完成時総コスト見積り（EAC）。どの式を使うかは、将来のパフォーマンスについて何を想定するかによります。

EACの計算式包装ラインの結果使う場面
EAC = BAC / CPI500,000 / 0.967 = $517,300現在のコスト効率が続くと見込まれる
EAC = AC + (BAC - EV)329,000 + 182,000 = $511,000これまでの差異は一時的なもので、残りは計画どおりに進む
EAC = AC + (BAC - EV) / (CPI x SPI)329,000 + 182,000 / 0.891 = $533,300スケジュールの圧力もコストを押し上げる
パッケージ別のボトムアップ$544,750この例のように、残作業が完了済みの作業と異なる

手法によって結果が食い違う場合は、1つの数値ではなく幅を示し、どれを信頼しているか、その理由を説明します。当サイトのガイド プロジェクトの予測 では、スポンサーへの予測の示し方を説明しています。

CPIと残作業効率指数（TCPI）

なお、 TCPI は、目標を達成するために残作業で必要となるコスト効率です：TCPI = (BAC - EV) / (BAC - AC)。包装ラインの場合、(500,000 - 318,000) / (500,000 - 329,000) = 182,000 / 171,000 = 1.06.

予算内で終えるには残作業のCPIが1.06である必要がありますが、進行中の作業は約0.75で推移しています。根本的な変化がない限り当初予算は達成できず、スポンサーには今そのことを伝えるべきです。当サイトの実務上のルール：TCPIが現在の累積CPIを明らかに（0.05以上）上回る場合は、何によって残作業の効率が上がるのかをレポートで説明するか、目標を見直すべきです。

CPIとSPIの組み合わせ

CPIはコストについて、スケジュール効率指数（SPI = EV / PV）は進捗について教えてくれます。併せて読みましょう。

SPIが1を上回るSPIが1を下回る
CPIが1を上回るスケジュールより進んでいて予算内。データが正しいか確認する予算内だがスケジュールに遅れている。作業を安く済ませているのではなく、先送りしていないか？
CPIが1を下回るスケジュールより進んでいるが予算超過。スピードにお金を払っていないか？スケジュールに遅れ、予算も超過。最も深刻な状態：時間を取り戻すには通常さらにコストがかかる

2つを掛け合わせる組織もあります： CPI x SPIで、クリティカル比率と呼ばれることもあります。包装ラインの場合、0.967 x 0.922 = 0.89です。1を大きく下回る値は、コストとスケジュールの両方に圧力がかかっていることを示唆し、上記の3つ目のEACの式の除数になります。

金額に基づくSPIは、遅れているかどうかにかかわらず、プロジェクトの終盤には1.0に近づいていくことに注意してください。計画したすべての作業が最終的には獲得されるからです。CPIにはこの問題はありません。

CPIとコスト差異、SPI、TCPI

指標計算式種類答える問い
コスト効率指数（CPI）EV / AC比率、現時点までどれだけ効率的に支出しているか？
コスト差異（CV）EV - AC金額、現時点まで実施済みの作業は、予算をどれだけ上回っているか、下回っているか？
スケジュール効率指数（SPI）EV / PV比率、現時点まで計画に対してどれだけ効率的に進んでいるか？
残作業効率指数（TCPI）(BAC - EV) / (BAC - AC)比率、将来残りの作業はどれだけ効率的でなければならないか？
完成時総コスト見積り（EAC）たとえばBAC / CPI金額、予測プロジェクトの総コストはいくらになるか？

CPIとCVは常に同じ方向を示します。CVがマイナスならCPIは1未満です。両方を報告しましょう。CVは懸かっている金額を示し、CPIは効率を示すので、プロジェクト間で比較しやすくなります。

良いCPIとはどのくらいですか？

目標はCPIを1.0に近づけることです。許容限度に普遍的な基準はなく、見積りの精度、契約形態、組織のリスク選好によって異なります。限度は コストマネジメント計画。 例示 のみ：

ステータスCPIの範囲の例一般的な対応
緑0.95～1.05通常どおり報告
黄0.90～0.95、または1.05～1.10差異を説明し、対応計画を示す
赤0.90未満、または1.10超エスカレーションし、EACを改訂し、変更要求を検討する

どのような範囲を選ぶにせよ、CPIの傾向と1行の説明を毎回の プロジェクト状況報告書に記載し、読み手が数値だけでなく方向性も分かるようにします。

上側の範囲に注意してください。CPIが1を大きく上回るのは、自動的に良い知らせとは限りません。請求書やタイムシートが漏れている、進捗が過大報告されている、見積りが水増しされていた、あるいは安い作業が先に行われて高い作業がまだ残っている、といった可能性があります。高いCPIが続くと、より広いポートフォリオで使えたはずの予算が拘束されることにもなります。

CPIは早期に安定するか？20%ルール

「プロジェクトが20%完了すると、CPIはあまり変わらない」と聞くことがあるかもしれません。これは米国の大規模な防衛契約に関する研究に由来します。ChristensenとHeise（1993年）は国防総省の155件の契約を調査し、そのほとんどで累積CPIが20%完了時点から安定していたと結論づけました。ここでの安定とは、CPIの変動幅が0.20未満に収まっていたことを意味します。彼らのデータでは、155件中134件が20%完了時点でこの基準を満たしていました。CPIが変化した場合は、改善するよりも悪化する傾向がありました。

このルールはその後、広く過剰に適用されてきました。Mosaic Projectsの「CPI安定性の神話」に関する論文（HendersonとZwikael（2008年）を引用）など、後の論評では、特に小規模な民間プロジェクトにおいて、安定性は当てにすべきものではないと論じています。この効果の一部は算術的なものでもあります。完了した作業が増えるほど、新しい月が累積比率を動かす幅は小さくなるからです。

実務上の教訓は次のとおりです：

  • 早い段階でのCPIの低さは深刻な警告です。 自然に回復すると思い込まないでください。
  • 早めに手を打つ。 プロジェクトが進むほど、どんな対策でも累積CPIを動かしにくくなります。
  • 20%を過ぎても管理をやめないでください。 CPIの傾向が変わるのは、通常、プロジェクトで何かが変わったことを意味します。
  • TCPIを使う を使い、CPIが自然に戻ることを期待するのではなく、回復が現実的かどうかを判断します。

低いCPIを改善する方法

  1. データを検証する。 進捗の申告を確認し、ACに未払計上が含まれ、他のプロジェクトの分が含まれていないことを確かめます。
  2. 結果を左右しているパッケージとコスト種別を見つけます。 詳細な WBS（ワーク・ブレークダウン・ストラクチャー） によってこれが可能になります。パッケージ別のCPIと、可能であれば人件費、資材費、外注費の別を確認しましょう。
  3. 価格と数量を分けて考えます。 1時間や1単位あたりの支払いが増えているのか、それとも計画より多くの時間や数量を使っているのか？
  4. 根本原因を特定する を、作業を行う人と一緒に作成します。 特性要因図（フィッシュボーン図） は、原因が混在している場合に役立ちます。
  5. 原因が続くかどうかを判断し、 し、それに基づいてEACを更新します。
  6. 残作業について対策を講じる： 順序と手戻りを修正し、資源構成を変え、単価を再交渉し、またはバリューエンジニアリングを使います。
  7. 変更要求を提出する スコープやベースラインの変更が必要な場合は、 変更管理.
  8. 期間CPIを注視する を、次の1～2サイクルにわたって行い、対応策が機能していることを確認します。

これらのステップを含む月次ルーティンの全体については、当サイトのガイド コスト管理.

アジャイルプロジェクトにおけるCPI

アジャイルチームは、リリースレベルでCPIを計算できます。リリースの予算をBAC、計画したストーリーポイントのうち完了した割合を完了率、チームのこれまでのコストをACとして使います。

例。 あるチームのコストは1スプリントあたり$25,000で、12スプリントのリリースの予算は$300,000、240ストーリーポイントです。5スプリント後、チームは110ポイントを完了し、$125,000を費やしました。

  • EV = 110 / 240 x 300,000 = $137,500.
  • CPI = 137,500 / 125,000 = 1.10：チームは計画より1ドルあたり多くのポイントを提供しています。
  • ここでプロダクトオーナーが、予算を変えずに30ポイントの新しいスコープを追加したとします。完了率は110 / 270となり、EVは$122,222、CPIは 0.98に下がります。チームの効率は何も変わっていないにもかかわらずです。

教訓は、アジャイルでは、バックログのスコープ変更にリリース予算についての意思決定を合わせなければ、CPIが効率を測れなくなるということです。ベロシティと組み合わせて使いましょう。当サイトのガイド スクラムにおけるベロシティ と アジャイルのメトリクスとKPI.

CPIのよくある間違い

  • パッケージのCPIを平均する となります（EVの合計をACの合計で割る代わりに平均した場合）。
  • データの不一致：EVとACのステータス日が異なる、またはACに未払計上が含まれていない。
  • 主観的な完了率。これによりEVが水増しされ、CPIも上がります。
  • 読み方1 - CPIを超過率とみなす。 代わりに1 / CPI - 1を使います。
  • 1か月分の数値に頼る。 複数の期間にわたる傾向を見ます。
  • 良好なプロジェクトのCPIを信用する を、パッケージやコスト種別を確認せずに信用する。
  • コミット済みコストを無視する。たとえば、今日のCPIは健全でも、パッケージの超過を招く発注書などです。
  • マネジメント予備をBACに含める。これにより、ベースラインに対するパフォーマンスの測定が曖昧になります。

よくある質問

コスト効率指数とは何ですか？

コスト効率指数（CPI）は、コスト効率を表すアーンドバリューの指標です。完了した作業の予算上の価値を、その作業に実際にかかったコストと比較します：CPI = EV / AC。

CPIの計算式は何ですか？

CPI = EV / AC。EVはアーンドバリュー（完了率 x 完成時総予算）、ACは完了した作業の実コストです。旧来の用語では、CPI = BCWP / ACWPです。

CPIが1とはどういう意味ですか？

完了した作業のコストが予算どおりだったので、実施済みの作業についてプロジェクトは予算どおりです。

CPIが1を下回るとはどういう意味ですか？

完了した作業のコストが予算を上回っています。たとえばCPI 0.90は、1ドルの支出につき90セント分の計画作業しか得られていないことを意味します。

CPI 0.8は何を意味しますか？

1ドルで80セント分の計画作業しか得られていないので、作業1単位のコストは予算の1 / 0.8 = 1.25倍です。これが続けば、プロジェクトは予算を25%超過して終わります。$500,000の予算が$625,000になります。

CPIが1を超えていれば常に良いのですか？

いいえ。本当に効率が良いこともありますが、コストの漏れ、進捗の過大報告、水増しされた見積り、高コストの作業がまだ残っていることを意味する場合もあります。低いCPIだけでなく、高いCPIも調査しましょう。

良いCPIとはどのくらいですか？

CPIが1.0に近い値です。組織はコスト・マネジメント計画書で独自の限度を設定します。たとえば0.95～1.05を許容範囲とし、0.90未満でエスカレーションするなどです。普遍的な基準はありません。

CPIとSPIの違いは何ですか？

CPI = EV / ACはコスト効率を測ります。SPI = EV / PVはスケジュール効率、つまり計画した作業のうちどれだけが完了したかを測ります。どちらもアーンドバリューを使うので、併せて読むべきです。

CPIとコスト差異の違いは何ですか？

どちらもEVとACを使います。コスト差異は金額の差（EV - AC）、CPIは比率（EV / AC）です。コスト差異がマイナスなら、CPIは必ず1未満です。

CPIを使ってEACをどのように予測しますか？

最も一般的な式はEAC = BAC / CPIで、現在のコスト効率が続くと想定します。BACが$500,000、CPIが0.967なら、EACは約$517,300です。その他の式では、CPI x SPIやボトムアップの再見積りを使います。

累積CPIと期間CPIのどちらを使うべきですか？

両方を使います。累積CPIのほうが安定しており、予測に使われます。期間CPIは直近のパフォーマンスを示し、問題や改善をはるかに早く明らかにします。

TCPIとは何で、CPIとどう違うのですか？

CPIは、これまでに達成した効率を振り返るものです。TCPIは先を見て、目標を達成するために残作業で必要な効率を示します：TCPI = (BAC - EV) / (BAC - AC)。TCPIがCPIを大きく上回る場合、目標の達成は難しいでしょう。

CPIは20%完了後に安定しますか？

米国の大規模な防衛契約に関する研究（ChristensenとHeise、1993年）では、累積CPIは通常、約20%完了時点から安定することが分かりました。その後の研究では、これが他のプロジェクトにどこまで当てはまるかが疑問視されているため、保証ではなく、早めに行動すべきという警告として受け止めましょう。

コスト効率指数（CPI）は消費者物価指数（CPI）と同じですか？

いいえ。どちらもCPIと略されますが、消費者物価指数は経済のインフレを測り、コスト効率指数はプロジェクトのコスト効率を測ります。
