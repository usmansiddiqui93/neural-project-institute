コスト効率指数（CPI）：計算式と解釈

コスト効率指数（CPI）はコスト効率、つまり支出したお金1単位あたりにどれだけの作業価値を獲得しているかを測定します。CPI = EV / ACで計算されるため、CPIが1を下回ると、完了した作業に対して予算超過であることを意味します。

要点

  • CPI = EV / AC。1未満は予算超過、1超は予算内（予算を下回る）です。
  • EAC = BAC / CPIが標準的なコスト予測です。
  • 累積CPIと期間CPIの傾向を追跡しましょう。
  • 全体像をつかむため、CPIはSPIとあわせて読みましょう。

計算式と解釈

CPI = EV / AC

CPI意味例
1超予算を下回る：支出したお金より獲得した作業が多い1.10 = $1の支出あたり$1.10分の作業
1ちょうど予算どおり
1未満予算超過：支出したお金より獲得した作業が少ない0.82 = $1の支出あたり82セント分の作業

計算例

EV = $70,000、AC = $85,000。

  • CPI = 70,000 / 85,000 = 0.82.
  • 予測EAC = BAC / CPI = 200,000 / 0.8235 = $242,857.
  • 比較対象： スケジュール効率指数（SPI） SPI = EV / PV = 70,000 / 80,000 = 0.875。

累積CPIは全体の効率を示し、予測に使われます。期間CPIは最近の効率が改善しているかを示します。この例ではどちらも0.82前後で安定しているため、超過は一時的なものではなく構造的なものです。

CPIとSPIの組み合わせ

SPIが1を上回るSPIが1を下回る
CPIが1を上回るスケジュール先行、予算を下回るスケジュール遅延、予算を下回る
CPIが1を下回るスケジュール先行、予算超過スケジュール遅延、予算超過

コツ

  • 1回の数値ではなく、複数期間にわたる傾向を見ましょう。
  • CPIが1を下回る場合だけでなく、大きく上回る場合も調査しましょう。見積りの水増しや作業の省略を示している可能性があります。
  • CPIはわかりやすい説明を添えて報告しましょう。
  • 活用するのは TCPI （回復が現実的かどうかを判断するため）。

よくある質問

コスト効率指数とは何ですか？

アーンドバリューマネジメントにおけるコスト効率の指標：CPI = EV / AC。

CPIが1とはどういう意味ですか？

プロジェクトは完了した作業に対してちょうど予算どおりです。

CPIが1を下回るとはどういう意味ですか？

完了した作業に対して計画以上に支出しているため、予算超過です。

CPIが1を上回るとはどういう意味ですか？

計画より1ドルあたり多くの作業を達成しているため、予算を下回っています。

CPIはコストの予測にどう使われますか？

典型的な予測はEAC = BAC / CPIです。BACが$200,000、CPIが0.8235の場合、EACは約$242,857です。

CPIとSPIの違いは何ですか？

CPI = EV / ACはコスト効率を、SPI = EV / PVはスケジュール効率を測定します。

良いCPIとはどのくらいですか？

1に近いCPIが良好です。組織では、0.95未満や1.10超の値を調査するなどの閾値を設けることがよくあります。

CPIとCVの違いは何ですか？

CV = EV - ACは金額での差異、CPI = EV / ACは比率であり、プロジェクト間の比較がしやすくなります。

累積CPIと期間CPIのどちらが良いですか？

予測には累積CPIを、最近の効率の変化を見つけるには期間CPIを使いましょう。

TCPIとは何ですか？

残作業効率指数：目標予算で完了するために残りの作業に必要なCPIです。

プロジェクトの終盤でCPIは回復できますか？

コストの多くがすでに支出されているため、プロジェクトが進むほど難しくなります。早めに行動しましょう。
