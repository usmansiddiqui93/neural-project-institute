コスト差異（CV）：計算式、計算方法、例

コスト差異（CV）とは、完了した作業の価値と、それに実際にかかったコストとの差です。アーンドバリューマネジメントではCV = EV - ACで計算され、結果がマイナスであれば、これまでに完了した作業に対してプロジェクトが予算超過であることを意味します。

要点

  • CV = EV - AC。マイナスは予算超過を意味します。
  • CV% = CV / EVを使うと、規模の異なるプロジェクトを比較できます。
  • コストは、計画支出ではなく獲得した作業と比較しましょう。
  • CVが大きい場合は原因を調査し、EACを更新しましょう。

計算式

計算式意味
CV = EV - AC金額でのコスト差異
CV% = CV / EV完了した作業に対する割合で表したコスト差異
VAC = BAC - EAC完了時に見込まれるコスト差異
結果意味
CV > 0完了した作業に対して予算を下回る
CV = 0予算どおり
CV < 0完了した作業に対して予算超過

計算例

BAC = $200,000。4か月目時点で、EV = $70,000、AC = $85,000。

  • CV = 70,000 - 85,000 = -$15,000.
  • CV% = -15,000 / 70,000 = -21.4%.
  • つまり、これまでに完了した作業のコストは予算より21.4%多くかかっています。

2つ目の例：EV = $50,000、AC = $46,000の場合、CV = +$4,000（予算を8%下回る）。

PVではなくEVと比較する理由

よくある間違いは、実コストを計画支出（PV）と比較することです。この例では、PVが$80,000、ACが$85,000なので、超過はわずか$5,000に見えます。しかし、チームが完了した作業は$70,000分だけなので、完了した作業に対する実際の超過は$15,000です。EVと比較することで、コストのパフォーマンスとスケジュールのパフォーマンスを切り分けられます。参考： スケジュール差異.

CVがマイナスになる主な原因

  • 楽観的な 見積り 、または項目の漏れ。
  • 計画より高い人件費単価や資材価格。
  • 欠陥や不明確な要件による手戻り。
  • スコープクリープ （変更要求なしに吸収されたもの）。
  • 低い生産性、作業の中断、経験の浅いスタッフ。

対処方法

  1. データを確認する：実コストと進捗は正しく記録されているか？
  2. どのコントロールアカウントやワークパッケージが差異を生んでいるかを見つけます。
  3. 根本原因と、それが今後も続くかどうかを特定します。
  4. 更新する： EAC を算出し、次を確認します： CPI の推移。
  5. 是正措置または変更要求に合意し、その判断を記録します。

よくある質問

プロジェクトマネジメントにおけるコスト差異とは何ですか？

アーンドバリューと実コストの差（CV = EV - AC）で、完了した作業のコストが予算より多かったか少なかったかを示します。

コスト差異がマイナスとはどういう意味ですか？

これまでに完了した作業のコストが予算を上回っている、つまりプロジェクトは予算超過です。

コスト差異がプラスとはどういう意味ですか？

完了した作業のコストが予算より少なかった、つまり完了した作業に対してプロジェクトは予算を下回っています。

コスト差異の割合はどのように計算しますか？

CV% = CV / EV x 100。CVが-$15,000、EVが$70,000の場合、CV%は-21.4%です。

コスト差異とスケジュール差異の違いは何ですか？

CV = EV - ACはコストを、SV = EV - PVはスケジュールを測定します。どちらもEVを使います。

コスト差異で実コストを計画価値と比較しないのはなぜですか？

PVは達成した内容ではなく作業の計画上のタイミングを反映しているためです。両者を混ぜると、スケジュールとコストの影響が混在してしまいます。

コスト差異は予算差異と同じですか？

一般的な財務では、予算差異は実際の支出を予算と比較することが多いです。EVMでは、CVは実コストを完了した作業のアーンドバリューと比較します。

許容できるコスト差異はどのくらいですか？

次で合意した閾値によって決まります： コストマネジメント計画。多くのプロジェクトでは、設定した割合を超える差異を調査します。

完成時差異はコスト差異とどう関係しますか？

完成時差異（VAC = BAC - EAC）は、プロジェクト完了時に見込まれるコスト差異です。

コスト差異はCPIとどう関係しますか？

どちらもEVとACを使います。CVは差（EV - AC）、CPIは比率（EV / AC）です。

プロジェクトに問題があってもコスト差異がプラスになることはありますか？

はい。プロジェクトが予算を下回っていても、スケジュールが大幅に遅れていることがあるため、必ずSVとSPIも確認しましょう。
