プロジェクトマネジメントにおけるコスト見積り：手法と例

コスト見積りとは、プロジェクトの作業にどれだけの資金が必要かを予測するプロセスです。良い見積りは数値だけでなく、その精度の範囲、背景にある前提条件、作成方法も示します。

要点

  • 作業についてどれだけわかっているかに合わせて見積り手法を選びましょう。
  • 常に範囲で示し、見積りの根拠を文書化しましょう。
  • 三点見積りとPERT見積りは不確実性を見える化します。
  • プロジェクトが進み知識が深まるにつれて、見積りをやり直しましょう。

主な見積り手法

手法仕組み適した場面
類推見積り（トップダウン）類似した過去のプロジェクトの実コストを、違いに応じて調整して使う初期段階で、詳細が少ないとき
パラメトリック見積り1平方メートルあたりのコストなど、単価に数量を掛ける作業が反復的で、信頼できる過去の単価がある
ボトムアップ見積り各ワークパッケージを見積もり、合計するなお、 WBS が明確に定義されている
三点見積り楽観値、最頻値、悲観値を使う不確実性が大きい
ベンダー入札分析サプライヤーの見積りを比較する作業を外部から調達する
専門家の判断類似の作業を経験した人の知見を活用する他のあらゆる手法と併用

見積り精度の範囲

見積りは、プロジェクトの理解が深まるにつれて精度が上がります。一般的によく示される範囲は次のとおりです：

見積りの区分典型的な範囲時期
超概算見積り（ROM）-25%〜+75%立ち上げ、アイデア、事業化調査
予算見積り約-10%〜+25%スコープの概要が固まった後の計画
確定見積り約-5%〜+10%WBS完成後の詳細計画

意思決定者が不確実性を理解できるよう、1つの数値だけでなく常に範囲を示しましょう。

プロジェクトのコストの見積り方

  1. スコープを確認し、ワークパッケージに分解します。
  2. 各パッケージに必要なリソース（人、設備、資材、サービス）を特定します。
  3. パッケージごとに手法を選び、最新の単価を適用します。
  4. リスク対応のコストと、次に基づくコンティンジェンシー予備を加えます： リスク登録簿.
  5. 間接費、ライセンス、出張費、研修費、長期プロジェクトではインフレも含めましょう。
  6. 見積りの根拠（前提条件、情報源、除外事項、精度の範囲）を文書化しましょう。
  7. 作業を行う人々や財務部門とレビューします。

計算例

パラメトリック： オフィスの内装工事は1平方メートルあたり約$1,200です。250平方メートルの場合：1,200 x 250 = $300,000.

類推： 以前の40画面のアプリは$80,000、つまり1画面あたり$2,000でした。同程度の複雑さの新しい50画面のアプリ：50 x 2,000 = $100,000（差異を調整する前の値）。

三点（PERT）： 楽観値$8,000、最頻値$12,000、悲観値$22,000。PERT見積り = (8,000 + 4 x 12,000 + 22,000) / 6 = 78,000 / 6 = $13,000です。三角分布による平均は (8,000 + 12,000 + 22,000) / 3 = $14,000となります。

ボトムアップ： 設計$18,000 + 構築$54,000 + テスト$16,000 + 研修$7,000 = $95,000。これにコンティンジェンシー予備$9,500（10%）を加えて$104,500となります。

より良い見積りのためのヒント

  • まず工数を見積もり、それをコストに換算します。参考： 工数見積り.
  • 作業を行う人自身に見積もってもらいましょう。
  • 過去のプロジェクトの実コストをライブラリとして蓄積しましょう。
  • コンティンジェンシーを基本見積りから分け、オープンに管理できるようにしましょう。
  • 知識が深まるにつれて、各フェーズで見積りをやり直します（段階的詳細化）。
  • 楽観バイアスや、目標の数値に合わせようとするプレッシャーに注意しましょう。

よくある質問

プロジェクトマネジメントにおけるコスト見積りとは何ですか？

プロジェクトの作業を完了するために必要な資金を予測することで、精度の範囲とその背景にある前提条件を添えて示します。

4つの主要なコスト見積り手法は何ですか？

類推見積り、パラメトリック見積り、ボトムアップ見積り、三点見積りが最も広く使われています。

最も精度の高いコスト見積り手法は何ですか？

ボトムアップ見積りは詳細なワークパッケージに基づくため通常は最も精度が高いですが、最も時間がかかります。

超概算（ROM）のコスト見積りとは何ですか？

ごく初期の見積りで、精度は一般に-25%〜+75%とされ、アイデアを追求する価値があるかどうかの判断に使われます。

コスト見積りのPERTの計算式は何ですか？

PERT見積り =（楽観値 + 4 x 最頻値 + 悲観値）/ 6。最頻値に最も大きな重みを置きます。

類推見積りとパラメトリック見積りの違いは何ですか？

類推見積りは、類似した過去のプロジェクトの総額を規模に応じて調整します。パラメトリック見積りは、1メートルあたりのコストなど、単価に数量を掛けます。

コスト見積りにおける見積りの根拠とは何ですか？

見積りがどのように作成されたかを説明する裏付け文書で、前提条件、情報源、単価、除外事項、リスク、精度の範囲を含みます。

コスト見積りにコンティンジェンシーを含めるべきですか？

特定されたリスクに対するコンティンジェンシーは見積りに加えられてコストベースラインを形成しますが、タスクの見積りに紛れ込ませるのではなく、別に示すべきです。

コスト見積りは誰が作成すべきですか？

作業を行う人々が作成し、プロジェクトマネージャー、コストの専門家、財務部門がそれを支えます。理想的には過去のデータと照らしてレビューします。

アジャイルプロジェクトではコスト見積りをどのように行いますか？

アジャイルチームは、スプリントあたりのコスト（チームのコスト x スプリント数）を見積もり、スコープの相対見積りと組み合わせることがよくあります。参考： ストーリーポイント.

プロジェクトのコスト見積りが外れることが多いのはなぜですか？

よくある原因は、不明確なスコープ、楽観、間接費などの項目の漏れ、管理されていないリスク、低い金額を提示しようとするプレッシャーです。
