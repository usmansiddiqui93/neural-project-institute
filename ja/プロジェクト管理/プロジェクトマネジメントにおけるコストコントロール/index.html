プロジェクトマネジメントにおけるコストコントロール：プロセスと技法

コスト管理とは、プロジェクトの支出をコストベースラインと照らして監視し、差異を分析し、最終コストを予測し、プロジェクトを予算内に収めるために行動する継続的なプロセスです。支出額を数えるだけでなく、パフォーマンスを理解することが目的です。

要点

  • コスト管理では、支出と予算を比べるだけでなく、獲得した価値と支出したお金を比較します。
  • CV、CPI、EAC、TCPIで、現在の位置と最終的な着地点がわかります。
  • 閾値を事前に合意しておき、早めに対策が発動されるようにしましょう。
  • ベースラインの変更は、正式な変更管理を通じてのみ行いましょう。

コスト管理に含まれるもの

  • タイムシートによる社内の人件費を含め、実コストを記録する。
  • 次を用いて完了した作業の価値を測定する： アーンドバリュー.
  • 差異と指数（CV、SV、CPI、SPI）を計算する。
  • 予測： 完成時総コスト見積り（EAC）.
  • 是正措置や予防措置を決定する。
  • ベースラインを守れなくなったときに変更要求を起票する。
  • 次でステークホルダーに報告する： 状況報告書.

コスト管理のプロセス

  1. 報告期間の実コストと進捗を収集します。
  2. 計画価値（PV）、アーンドバリュー（EV）、実コスト（AC）を計算します。
  3. 次を算出します： コスト差異 （EV - AC）と CPI （EV / AC）。
  4. 結果を合意済みの管理閾値と比較します。
  5. 大きな差異について根本原因を見つけます。
  6. 最終コストを予測し、次を確認します： 残作業効率指数（TCPI）.
  7. 対策に合意して記録し、次の期間にフォローアップします。

計算例

BACは$200,000です。4か月目時点で、PV = $80,000、EV = $70,000、AC = $85,000。閾値はCPIが0.95を下回ることです。

指標計算結果
コスト差異70,000 - 85,000-$15,000
CPI70,000 / 85,0000.82（閾値を超過）
EAC200,000 / 0.8235約$242,857
BACを達成するためのTCPI(200,000 - 70,000) / (200,000 - 85,000)1.13

TCPIが1.13ということは、予算内で完了するには残りの作業を計画より13%効率よく行う必要があることを意味しますが、現在の効率が0.82では困難です。プロジェクトマネージャーが調査したところ、不明確な要件による手戻りが見つかり、その対策と追加資金のための変更要求に合意します。

是正措置

アクション効果
根本原因を解決する（例：要件、欠陥）残りの作業の効率を高める
スコープを削減または延期する残りのコストを下げる。承認が必要
リソースの構成を変える単価の引き下げや、より経験豊富な人材
サプライヤーとの条件を再交渉する外部調達のコストを下げる
コンティンジェンシー予備を使う発生したリスクに対応する
追加予算を要求する変更管理を通じてベースラインを変更する

よくある間違い

  • 進捗を測らずに支出と予算を比較すること。
  • 何週間も遅れて届く財務部門の月末の数値を待つこと。
  • 署名済みの発注書など、確定済みのコストを無視すること。
  • 超過を隠すためにベースラインを動かすこと。
  • 根本原因ではなく症状に対して手を打つこと。

よくある質問

プロジェクトマネジメントにおけるコスト管理とは何ですか？

支出をコストベースラインと照らして監視し、差異を分析し、最終コストを予測し、予算内に収めるために行動することです。

コスト管理とコストマネジメントの違いは何ですか？

コストマネジメントは計画、見積り、予算化、管理を含みます。コスト管理はそのうち監視と是正の部分です。

プロジェクトのコスト管理の主要なツールは何ですか？

アーンドバリューマネジメント は、スコープ、スケジュール、コストを組み合わせるため、最も広く使われています。

コスト管理においてCPIが1を下回るとはどういう意味ですか？

プロジェクトは支出した1ドルあたり、計画上1ドル分に満たない作業しか得られていないため、完了した作業に対して予算超過となっています。

コスト管理における管理閾値とは何ですか？

CVが10%を超える、CPIが0.95を下回るなど、調査やエスカレーションのきっかけとなる合意済みの限度です。

コスト管理のレビューはどのくらいの頻度で行うべきですか？

少なくとも毎月、理想的には毎週またはスプリントごとに行い、問題を早期に発見しましょう。

コスト管理における確定済みコストとは何ですか？

署名済みの発注書など、すでに約束されているがまだ支払われていないお金です。予測の際には含めるべきです。

コスト管理で予算超過のプロジェクトをどのように軌道に戻しますか？

根本原因を解決する、スコープを削減または延期する、リソースの構成を変える、コンティンジェンシーを使う、または正式に追加予算を要求します。

コスト管理におけるTCPIとは何ですか？

残作業効率指数：目標どおりに完了するために残りの作業に必要なコスト効率で、(BAC - EV) / (BAC - AC) で求めます。

アジャイルプロジェクトではコスト管理をどのように行いますか？

はい。アジャイルチームはスプリントあたりのコストが固定されていることが多いため、バックログの優先順位付けと提供した価値の追跡によってコストをコントロールします。

コスト管理の責任者は誰ですか？

プロジェクトマネージャーが責任を持ち、コントロールアカウントマネージャーと財務部門がそれを支え、予算の変更はスポンサーが承認します。
