プロジェクトマネジメントにおけるキャパシティプランニング：ガイドと例

キャパシティプランニングとは、組織やチームが行う必要のある作業を、実際に利用可能な時間とスキルと比較するプロセスです。どこで需要がキャパシティを上回るかを事前に示すため、プロジェクトが遅れる前に優先順位の見直し、採用、スケジュールの変更を行えます。

執筆Neural Project Instituteプロジェクトマネジメント編集チーム

要点

  • キャパシティプランニングでは、需要と実質的なキャパシティを比較します。
  • 比較する前に、休暇とプロジェクト以外の時間を差し引きます。
  • 人数だけでなく、スキル別に計画しましょう。
  • 毎月見直し、小さな未割り当てのバッファを残しておきましょう。

キャパシティ、需要、割り当ての比較

用語意味
キャパシティチームや個人が一定期間に提供できる実働時間
需要プロジェクトや通常業務から求められる作業時間
割り当てどの作業をどの人に割り当てるか。参考： リソース配分
稼働率割り当てられた時間を稼働可能時間で割った値（%）

割り当ては1つのプロジェクト内のタスクレベルで行います。キャパシティプランニングは通常、チーム、部門、ポートフォリオ全体を対象に、日単位ではなく月単位で行います。

キャパシティプランニングの手順

  1. 対象範囲（チーム、スキルグループ、部門）と計画期間（たとえば次の四半期）を決めます。
  2. 総キャパシティを計算する：人数 x 週あたりの時間 x 週数。
  3. 計画された休暇、祝日、研修を差し引きます。
  4. 会議、事務、サポート業務を考慮して実働時間係数を適用します。
  5. すべてのプロジェクトと通常業務から、スキル別に需要を集めます。
  6. スキルと期間ごとに需要とキャパシティを比較し、不足や余剰を見つけます。
  7. 優先順位の見直し、スケジュールの変更、採用、業務委託、スコープの削減によって不足を解消し、毎月見直します。

計算例：5人チームの1か月

あるデザインチームには週40時間働く5人のメンバーがいます。その月の稼働週は4週間です。計画された休暇は合計40時間です。経験上、時間の約20%が会議、事務、サポートに費やされます。

ステップ計算時間
総キャパシティ5人 x 40時間 x 4週間800
休暇の差し引き800 - 40760
実質キャパシティ760 x 80%608
需要の発生源時間
プロジェクトA（Webサイトのリニューアル）320
プロジェクトB（ブランドの刷新）240
通常業務の依頼120
総需要680

680時間の需要は、608時間の実質キャパシティを 72時間上回っており、約12%の超過です。選択肢としては、プロジェクトBの72時間分を翌月に移す、約2週間フリーランサーを起用する、優先度の低い依頼の一時停止を事業部門に求める、などがあります。 フルタイム当量（FTE）で表すと、不足はその月で72 / (160 x 80%) = 0.56 FTEです。

キャパシティプランニングのアプローチ

アプローチ説明使う場面
リード戦略需要が発生する前にキャパシティを増やす成長が確実で、遅れのコストが大きい
ラグ戦略需要が確定してからキャパシティを増やす予算が厳しく、需要が不確実
マッチ戦略需要の増加に合わせて少しずつキャパシティを増やすほとんどのプロジェクト組織
チームベース（アジャイル）チームの規模を固定し、それに収まるよう作業に優先順位を付ける安定したプロダクトチーム。参考： アジャイルのキャパシティプランニング

よくある間違い

  • 1人を週40時間の実働時間として数えること。
  • 通常業務やサポート業務を無視すること。これらは知らないうちにキャパシティを消費します。
  • スキルではなく人数で計画し、テスターの余剰が開発者の不足を覆い隠してしまうこと。
  • 計画を毎月見直さず、一度きりの作業として扱うこと。
  • 共有のスペシャリストを、すべてのプロジェクトが自分に優先権があると思い込むこと。
ヒント

通常10〜15%程度の小さなバッファを未割り当てのまま残しておきましょう。100%で計画されたチームには緊急の作業に対応する余地がなく、それが発生すると他のすべてが遅れます。

キャパシティプランニングの責任者は誰ですか？

多くの組織では、 プロジェクトマネジメントオフィス またはリソースマネージャーがキャパシティの全体像を管理し、プロジェクトマネージャーが需要予測を提供します。どのプロジェクトを開始するかというポートフォリオの判断は、この全体像に基づいて行うべきです。参考： 複数プロジェクトの管理.

よくある質問

プロジェクトマネジメントにおけるキャパシティプランニングとは何ですか？

プロジェクトや日常業務が求める作業量を、利用可能な実働時間とスキルと比較し、不足を事前に解消できるようにすることです。

キャパシティプランニングのためにチームのキャパシティをどう計算しますか？

人数に勤務時間と週数を掛け、休暇と祝日を差し引いたうえで、会議や事務を考慮して75〜80%などの実働時間係数を適用します。

キャパシティプランニングとリソース計画の違いは何ですか？

キャパシティプランニングはチームやポートフォリオ全体の供給と需要の総量を見るもので、リソース計画と割り当ては特定の人を特定のタスクに割り当てるものです。

キャパシティプランニングにおける適切な稼働率はどのくらいですか？

唯一の正解はありませんが、プロジェクト作業に対して70〜85%程度で計画すると、通常は会議、サポート、想定外の事態に対応する余地が残ります。

キャパシティプランニングにおけるキャパシティと稼働可能時間の違いは何ですか？

稼働可能時間とは、休暇ではなく勤務している時間のことです。キャパシティとは、そのうち計画された作業に充てられる実働部分のことです。

キャパシティ計画はどのくらいの頻度で更新すべきですか？

ポートフォリオでは毎月、個々のチームでは毎週またはスプリントごとが一般的です。

キャパシティプランニングにおけるリード戦略、ラグ戦略、マッチ戦略とは何ですか？

リード戦略は需要に先立ってキャパシティを増やし、ラグ戦略は需要が確定するまで待ち、マッチ戦略は需要の増加に合わせて少しずつキャパシティを増やします。

アジャイルではキャパシティプランニングをどのように行いますか？

チームは稼働可能時間と過去のベロシティからスプリントごとのキャパシティを見積もり、収まる作業だけを確約します。参考： アジャイルのキャパシティプランニング.

需要がキャパシティを上回った場合、キャパシティプランニングではどうしますか？

優先順位の見直し、スケジュールの変更、人員の追加、外部委託、スコープの縮小のいずれかを行う必要があります。そうしなければ作業は遅れ、人は燃え尽きてしまいます。

キャパシティプランニングにはどのようなツールを使いますか？

小規模チームならスプレッドシート、または次のワークロードビューやポートフォリオビューです： プロジェクト管理ソフトウェア.

FTEはキャパシティプランニングとどう関係しますか？

FTEはキャパシティと需要をフルタイム1人分の単位で表すため、不足を比較しやすくなります。参考： フルタイム当量（FTE）.
