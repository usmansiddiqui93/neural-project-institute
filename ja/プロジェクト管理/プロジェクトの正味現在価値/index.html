プロジェクトの正味現在価値（NPV）：計算式と例

正味現在価値（NPV）とは、プロジェクトの将来のすべてのキャッシュインフローとキャッシュアウトフローを、現在の貨幣価値で合計したものです。将来のキャッシュフローは選択した率で割り引かれ、結果がプラスであれば、そのプロジェクトはコストを上回る価値を生むと見込まれます。

要点

  • NPVは将来のキャッシュフローを現在の貨幣価値に割り引きます。
  • 割引係数 = 1 / (1 + r)^t。
  • NPVがプラスのプロジェクトを採択し、選択肢の中ではNPVの高いほうを優先します。
  • 割引率とキャッシュフローの見積りに対する感度は必ず検証しましょう。

計算式

NPV = [t年目のキャッシュフロー / (1 + r)^t]の合計 - 初期投資

  • r は1期あたりの割引率で、たとえば8%（0.08）です。
  • t は期間の番号で、1年目の期末を1として数えます。
  • なお、 割引係数 は、t年目について1 / (1 + r)^tです。

計算例

あるプロジェクトは現時点で$100,000の費用がかかり、今後3年間、各年末に$40,000のリターンを生みます。割引率は8%です。

年キャッシュフロー8%での割引係数現在価値
0-$100,0001.00000-$100,000.00
1$40,0001 / 1.08 = 0.92593$37,037.04
2$40,0001 / 1.1664 = 0.85734$34,293.55
3$40,0001 / 1.259712 = 0.79383$31,753.29
NPV$3,083.88

割引なしで見ると、このプロジェクトは$100,000に対して$120,000を生み、$20,000の利益になります。貨幣の時間価値を考慮すると、利益は約$3,084です。割引率が10%ならNPVは約-$526に下がるため、判断は割引率次第です。

相互排他的なプロジェクトを比較する場合、リスクが同程度であれば、NPVの高いほうを優先します。

NPVとIRR

内部収益率（IRR）とは、NPVがゼロになる割引率です。この例ではIRRは約9.7%で、必要収益率8%を上回る（そのためNPVはプラス）一方、10%を下回ります（そのためNPVはマイナス）。IRRはNPVと併用しつつ、相互排他的な選択肢で両者の結論が食い違う場合はNPVを優先しましょう。

NPVの計算手順

  1. 初期投資を含め、各期間のキャッシュフローを一覧にする。
  2. 割引率は財務部門と合意しましょう。
  3. 各期間の割引係数を計算する：1 / (1 + r)^t。
  4. 各キャッシュフローにその係数を掛ける。
  5. 現在価値を合計する。
  6. 割引率とキャッシュフローに対する結果の感度を確認しましょう。参考： 感度分析.

よくある間違い

  • 0年目の投資を割り引くこと。
  • キャッシュフローの代わりに利益を使うこと。
  • 運用コストや廃棄時のコストを無視すること。
  • 期間の単位が一致していないこと（月次のキャッシュフローに年率を使うなど）。
  • ExcelのNPV関数は最初の値を第1期末のものとみなすため、0年目の支出は別途加算する点に注意してください。

よくある質問

正味現在価値とは何ですか？

プロジェクトの将来のキャッシュフローを現在価値に割り引いて合計し、初期投資を差し引いたものです。

NPVがプラスとはどういう意味ですか？

そのプロジェクトは必要収益率を上回るリターンを生むと見込まれるため、価値を生み出します。

NPVがマイナスとはどういう意味ですか？

選択した割引率では、プロジェクトのリターンが現在の貨幣価値でコストを賄えないことを意味します。

NPVの割引係数はどのように計算しますか？

割引係数 = 1 / (1 + r)^t。8%で2年目の場合は1 / 1.1664 = 0.85734です。

NPVにはどの割引率を使うべきですか？

通常は財務部門が設定する率で、資本コストや必要収益率に基づくことが多く、リスクに応じて調整されることもあります。

NPVとIRRの違いは何ですか？

NPVは特定の率における金額です。IRRはNPVがゼロになる率です。

NPVとROIの違いは何ですか？

NPVはキャッシュフローのタイミングを考慮しますが、単純なROIは考慮しません。参考： 投資利益率.

ExcelでNPVを計算するにはどうすればよいですか？

=NPV(割引率, 1年目からn年目までのキャッシュフロー)を使い、その後に0年目のキャッシュフロー（通常はマイナス）を加えます。

NPVはプロジェクト選定に使われますか？

はい。ビジネスケースやポートフォリオの意思決定で最もよく使われる財務指標の1つです。

正味現在価値では、なぜ将来のお金の価値が低くなるのですか？

今日のお金は投資してリターンを得られるからであり、またインフレとリスクがあるからです。

NPVはPMP試験に出題されますか？

NPV、IRR、回収期間などのプロジェクト選定手法は、PMPの受験対策教材で概念レベルで扱われるのが一般的です。
