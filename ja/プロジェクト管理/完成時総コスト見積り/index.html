完成時総見積り（EAC）：計算式と例

完成時総コスト見積り（EAC）とは、すべての作業が完了したときにプロジェクトにかかる総コストの予測です。これまでに支出した実コストと残作業の見積りコストの合計に等しく、最も広く使われる簡便式はEAC = BAC / CPIです。

要点

  • EACはプロジェクトの総コストの予測です：EAC = AC + ETC。
  • 標準的な計算式は4つあります。差異の原因に合ったものを選びましょう。
  • BAC / CPIは現在のコスト効率が続くと仮定し、AC + (BAC - EV)は残りが計画どおりに進むと仮定します。
  • VAC = BAC - EACは予想される超過額を示し、TCPIは目標を達成するために必要な効率を示します。
  • 単一の数値ではなく、EACの範囲と、推奨する数値の根拠を報告しましょう。
  • 報告期間ごとにEACを更新し、予算から離れ始めたら早めに対処しましょう。

完成時総コスト見積り（EAC）とは？

完成時総コスト見積り（EAC） は、プロジェクト、またはワークパッケージやコントロールアカウントのすべての作業が完了したときの予想総コストです。これまでの実コストに残作業見積り（ETC）を足して計算します（EAC = AC + ETC）。EACを完成時総予算（BAC）と比較することで、プロジェクトが予算超過に向かっているのか、予算を下回る方向にあるのかがわかります。

EACは、 アーンドバリューマネジメントにおける予測指標の1つです。その他の指標は、プロジェクトが現在どの位置にあるかを示します。 コスト効率指数 はコスト効率を示し、 コスト差異 と スケジュール差異 は計画からどれだけ離れているかを示します。EACはそうした実績を最終的な請求額の予測に変えます。

重要なのは、 EACとBACの区別です。 完成時総予算 はすべての作業に対する承認済みの予算であり、正式な変更管理を経なければ変わりません。EACは現時点での最善の予測であり、報告期間ごとに変わる可能性があります。EACがBACを上回り始めたら、その差は報告書に注記するだけでなく、意思決定が必要な警告です。

PMIのPMBOKガイドでは、予測はコストのコントロールに含まれます。第8版（2025年後半発行）では、コストに関する作業は 財務 パフォーマンス領域に属し、そのプロセスには財務の監視・コントロールが含まれます。計算式自体は、PMIの標準や多くのプロジェクトコントロールの指針で使われている、確立されたアーンドバリューの計算式です。

必要なインプット

どのEAC計算式も、少数のアーンドバリューの数値から成り立っています。まずこれらを正しく把握しましょう。質の低いデータに精密な計算式を当てはめても、精密そうに見える誤った答えが出るだけです。

用語意味計算方法
BAC：完成時総予算作業に対する承認済みの総予算コストベースラインの合計
PV：計画価値現時点までに予定された作業の予算コスト時系列のベースラインから
EV：アーンドバリュー実際に完了した作業の予算コスト完了率 x BAC
AC：実コスト完了した作業に実際にかかったコストタイムシート、請求書、未払計上から
CPI：コスト効率指数現時点までのコスト効率EV / AC
SPI：スケジュール効率指数現時点までのスケジュール効率EV / PV
ETC：残作業コスト見積り残りの作業の予想コストEAC - AC、または新たな見積り

特に重要なデータは2つあります。 EVは正直な進捗測定に依存します：タスクが何週間も80%完了と報告されていると、EVは水増しされ、すべての予測が実際より良く見えます。短いタスクには0/100や50/50、長いタスクにはマイルストーンといった客観的なルールを、 ワークパッケージ のレベルで合意しておきましょう。 ACには、発生済みでまだ請求されていないコストも含める必要があります（未払計上した外部委託先の作業時間など）。そうしないと、プロジェクトが実際より安く見えてしまいます。

EACの4つの計算式

PMIのアーンドバリューの指針では、EACを予測する標準的な方法を4つ挙げています。それぞれ、残りの作業がどのように進むかについて異なる仮定を置いています。

計算式前提条件主な用途
EAC = BAC / CPI現在のコスト効率が続く差異の原因が継続している（典型的な差異）
EAC = AC + (BAC - EV)残りの作業は予算どおりの単価で行われる差異は一度限りのものだった（非典型的な差異）
EAC = AC + (BAC - EV) / (CPI x SPI)コストとスケジュールの両方の実績が残りに影響するスケジュールが遅れており、それでも固定の期日に間に合わせる必要がある
EAC = AC + ボトムアップのETC当初の見積りがもはや有効でないスコープ、単価、進め方が大きく変わった

1. EAC = BAC / CPI（典型的な差異）

最も一般的な計算式で、多くのツールで既定になっています。プロジェクトが残りの期間も同じ効率で支出を続けると仮定します。チームが支出1ドルあたり82セントの価値しか生み出していなければ、それが続くと仮定するわけです。数学的にはEAC = AC + (BAC - EV) / CPIと同じです。

超過の原因が構造的な場合に使います。たとえば、人件費単価が計画より高い、生産性が見積りより低い、残りのすべての作業に影響する複雑さがある、といった場合です。作業のかなりの部分が終わると、累積CPIはゆっくりとしか動かなくなります。新しい期間ごとに合計に加わる分がわずかだからです。そのため、多くのプロジェクトコントローラーはこの計算式を現実的な基準となる予測として扱っています。

2. EAC = AC + (BAC - EV)（非典型的な差異）

この計算式は、すでに支出した額に、残りの作業の当初予算を足します。過去の差異は一度限りで、繰り返さないと仮定します。たとえば、サプライヤーの不履行、1回きりの手戻り、一時的な価格の急騰などです。

予算超過のプロジェクトでは4つの中で最も楽観的な計算式なので、原因が解消された理由を説明できる場合にのみ使いましょう。最も小さい数字が出るからという理由でこれを既定にするのは、予測で最もよくある間違いの1つです。

3. EAC = AC + (BAC - EV) / (CPI x SPI)

このバージョンは、残りの作業をコストとスケジュールの両方の実績で調整します。スケジュールが遅れていて終了日が固定されているプロジェクトに適しています。遅れを取り戻すには残業、人員の追加、納期の前倒しが必要になり、いずれもコストが増えるからです。

プロジェクトが遅れているときはCPI x SPIがCPIより小さくなるため、両方の指数が1未満の場合、通常はこれが最も高いEACになります。組織によっては、 加重版（AC + (BAC - EV) / (0.8 x CPI + 0.2 x SPI) など）を使い、スケジュールの圧力をある程度反映させつつ支配的にならないようにしています。重みは標準ではなく各組織の慣行なので、 コストマネジメント計画.

4. EAC = AC + ボトムアップのETC

この方法では指数を使わず、スコープ、単価、リスクに関する現在の知見をもとに、残りの作業をタスクごとにボトムアップで再見積りします。最も手間がかかりますが、計画が変わった場合（再設計、新しいサプライヤー、承認されたスコープ変更、根本的に異なる進め方など）には最も信頼できることが多い方法です。

ボトムアップのETCには、当初の見積りと同じ手法を使います。参照： コスト見積り と 工数見積り.

EACの計算手順

  1. BACを確認する。 承認された変更を含む、現在の承認済み予算を使います。パフォーマンス・ベースラインの外にあるマネジメント予備は除きます。
  2. EVを測定する。 合意した完了率のルールを各ワークパッケージに適用し、合計します。
  3. ACを集める。 完了した作業に関連する未払計上やコミット済みのコストを含め、実施した作業で発生したすべてのコストを含めます。
  4. PVを求める。 ベースラインから基準日時点の計画価値を読み取ります。
  5. CPIとSPIを計算する。 CPI = EV / AC、SPI = EV / PV。
  6. 計算式によるEACを求める。 指数に基づく3つの計算式をすべて計算します。インプットがわかっていれば数秒で済みます。
  7. 差異が生じた理由を問う。 これによって、どの計算式が最も現実的かが決まります。
  8. 計画が変わった場合はボトムアップのETCを作成する。 計算式の結果が大きく食い違う場合も同様です。
  9. ETC、VAC、TCPIを算出する （選んだEACから）。
  10. 報告する： 推奨するEAC、範囲、理由、推奨する対応策。
ヒント

EACは、コストを管理するレベル（通常はコントロールアカウントまたはワークパッケージ）で計算し、積み上げましょう。プロジェクト全体の合計が健全でも、1つのワークパッケージが大幅に超過していることが隠れている場合があります。

計算例：予算超過のプロジェクト

あるWebサイトの再構築プロジェクトの予算は、8か月間で $200,000 です。4か月目の終わりの時点で：

  • 計画価値（PV）= $80,000
  • アーンドバリュー（EV）= $70,000（作業の35%が完了）
  • 実コスト（AC）= $85,000

したがって CPI = 70,000 / 85,000 = 0.8235, SPI = 70,000 / 80,000 = 0.875で、残りの作業の予算価値はBAC - EV = $130,000です。このプロジェクトは予算超過でスケジュールも遅れています。

計算式計算EACVAC（BAC - EAC）
BAC / CPI200,000 / 0.8235$242,857-$42,857
AC + (BAC - EV)85,000 + 130,000$215,000-$15,000
AC + (BAC - EV) / (CPI x SPI)85,000 + 130,000 / 0.7206$265,408-$65,408
加重 0.8 CPI / 0.2 SPI85,000 + 130,000 / 0.8338$240,908-$40,908
AC + ボトムアップのETC85,000 + 140,000$225,000-$25,000

予測は$215,000から$265,408までの幅があります。どれを報告するかは原因によって決まります。調査の結果、主な要因はシニア開発者の日額単価が見積りより15%高いことで、その開発者が最後まで残ると判明したとします。原因は継続しているため、 BAC / CPI = $242,857 が最も説得力のある予測です。ボトムアップの$225,000という数字を採用するには、なぜ効率が改善するのかについて信頼できる説明が必要です。

選んだEACから：

  • ETC = EAC - AC = 242,857 - 85,000 = $157,857 がまだ必要です。
  • VAC = BAC - EAC = -$42,857で、約21%の超過が予測されます。
  • BACを達成するためのTCPI = (BAC - EV) / (BAC - AC) = 130,000 / 115,000 = 1.13。残りの作業は計画より13%高い効率が必要ですが、チームは現在18%低い効率で進んでいます。スコープや進め方を変えない限り、現実的ではありません。
  • EACを達成するためのTCPI = (BAC - EV) / (EAC - AC) = 130,000 / 157,857 = 0.82で、この計算式で予想されるとおり、現在のCPIと等しくなります。

同じプロジェクトデータを アーンドバリューマネジメント, CPI と コスト差異のガイドでも使っているため、すべてのガイドを通して数値を追うことができます。

計算例：予算を下回るプロジェクト

EACがBACを下回ることもあります。小規模なオフィス移転の予算は $50,000です。基準日時点でPV = $22,000、EV = $20,000、AC = $18,000です。

  • CPI = 20,000 / 18,000 = 1.11 （予算を下回る）
  • SPI = 20,000 / 22,000 = 0.91 （スケジュールがわずかに遅れている）
  • BAC - EV = $30,000 の作業が残っている
計算式EACVAC
BAC / CPI$45,000+$5,000
AC + (BAC - EV)$48,000+$2,000
AC + (BAC - EV) / (CPI x SPI)$47,700+$2,300

この場合、BAC / CPIが最も楽観的な数値です。初期のコスト削減は簡単なタスクによるもので続かないことが多いため、慎重なプロジェクトマネージャーなら$48,000と報告するかもしれません。VACがプラスなのは良い知らせですが、当初の見積りに余裕を持たせすぎていた可能性もあります。今後の見積りを改善するために、理由を 教訓 に記録しておきましょう。

EAC、ETC、VAC、TCPIの比較

これら4つの予測指標は密接に関連しており、特に試験問題で混同されがちです。

指標答える問い計算式良い結果
EACプロジェクト全体でいくらかかるか？AC + ETC（または4つの計算式のいずれか）BAC以下
ETCあといくら支出するか？EAC - AC、またはボトムアップの見積り残りの予算（BAC - AC）以内
VAC最終的にどれだけ予算を超過する、または下回るか？BAC - EACゼロまたはプラス
TCPI残りの作業にどれだけの効率が必要か？(BAC - EV) / (BAC - AC) または (BAC - EV) / (EAC - AC)現在のCPIに近いか、それ以下

TCPIの読み方

残作業効率指数は、あらゆる目標の現実性を確認するものです。BACを達成するためのTCPIが1.13で、現在のCPIが0.82なら、頑張るだけで予算内に収まる可能性は非常に低いでしょう。おおよその目安は次のとおりです（正式な標準ではなく、当サイトの指針です）：

  • TCPIが現在のCPI以下、またはそれに近い： 現在の実績で目標を達成できる。
  • TCPIがCPIをわずかに上回る（約0.05～0.10まで）： 具体的な改善策を講じた場合にのみ達成できる。
  • TCPIがCPIを大きく上回る： 非現実的。再計画、スコープ変更、予算変更が必要。

TCPIはプロジェクトの終盤に急上昇します。取り戻すために残っている作業が少なくなるからです。実コストがすでにBACを超えている場合、BACに基づくTCPIは無意味になるかマイナスになり、EACに基づくバージョンだけが役に立ちます。

どのEAC計算式を使うべきか？

適切な計算式は、どの答えが最も良く見えるかではなく、実績が計画と異なる理由によって決まります。次の表を出発点にしてください：

状況推奨するEAC理由
単価、生産性、複雑さが見積りより悪く、その状態が続くBAC / CPI原因が残りのすべての作業に影響する
1つの出来事が超過の原因で、すでに解決しているAC + (BAC - EV)残りの作業は計画どおりに進むはず
スケジュールが遅れており、必ず守るべき固定の終了日があるAC + (BAC - EV) / (CPI x SPI)挽回には追加のコストがかかる
スコープ、設計、サプライヤー、進め方が変わったAC + ボトムアップのETC当初の見積りがもはや当てはまらない
プロジェクトの初期（完了率が約15～20%未満）ボトムアップのETC（計算式で検算）初期の指数は変動が大きい
計算式の結果に大きな幅があるボトムアップのETCと範囲不確実性を可視化する必要がある

独立EACとマネジメントEAC

正式なアーンドバリューのシステムでは、2種類の予測が使われます。 独立EAC（IEAC） は、誰の判断も交えずに計算式から算出され、統計的なチェックとして機能します。 マネジメントEAC （公式EACと呼ばれることもあります）はプロジェクトマネージャー自身の予測で、通常はボトムアップで作成します。マネジメントEACが独立EACよりはるかに低い場合、スポンサーは何が変わるのかについて明確な説明を求めるでしょう。

点ではなく範囲で報告する

最良のケース（AC + (BAC - EV)）、最も可能性の高いケース、最悪のケース（CPI x SPI）を示すことで、意思決定者に現実的な全体像を伝えられます。不確実性の高いプロジェクトでは、残りの作業の モンテカルロ・シミュレーション によって、確率に基づく範囲（たとえば信頼度80%のEAC）を算出できます。

スプレッドシートでEACを計算する

専用のソフトウェアは必要ありません。セルB1にBAC、B2にPV、B3にEV、B4にACを入力すれば、次の数式がExcelとGoogle Sheetsで使えます：

セル指標計算式
B5CPI=B3/B4
B6SPI=B3/B2
B7EAC（典型的）=B1/B5
B8EAC（非典型的）=B4+(B1-B3)
B9EAC（CPI x SPI）=B4+(B1-B3)/(B5*B6)
B10ETC=B7-B4
B11VAC=B1-B7
B12BACに対するTCPI=(B1-B3)/(B1-B4)

基準日ごとに1行ずつ、毎期これらを記録すれば、推移をグラフにできます。EACの上昇線は、どの単一の値よりも多くを物語ります。当サイトの無料の 予算テンプレート と プロジェクトコスト見積りテンプレート を使えば、BACとボトムアップの見積りの枠組みが得られます。

予算機能を備えたプロジェクト管理ツールのほとんどは、計画コストと実コストを記録できます。お使いのツールが必要な数値をエクスポートできるか確認しましょう。当サイトの プロジェクト管理ソフトウェア のレビューでは、どのツールに予算編成や財務追跡の機能があるかを紹介しています。

スポンサーへのEACの報告

EACだけを示すと「それで？」と問われがちです。 プロジェクト状況報告書 に載せる有益な予測には、次の内容が含まれます：

  • なお、 推奨するEAC と、他の方法による範囲。
  • VAC （金額とBACに対する割合）。
  • なお、 推移：直近の数期間でEACがどう動いたか。
  • なお、 主な原因 （差異の原因）と、それが続くかどうか。
  • TCPI （予算をまだ達成できるかを示すため）。
  • 推奨する対応策：是正措置、コンティンジェンシーの使用、またはベースライン再設定のための変更要求。

VACがBACの5%や10%を超えたらエスカレーションするなど、しきい値を事前に合意しておけば、超過の予測が議論ではなく意思決定のきっかけになります。超過を吸収できない場合は、予算の改訂のために 変更管理 を経ます。EACを毎期見える状態にしておくことは、次の中核となる習慣の1つです： コスト管理.

コストだけでなく終了日や便益の予測も含めた全体像については、次をお読みください： プロジェクトの予測.

よくある間違い

  • AC + (BAC - EV)を既定にすること。 原因が解消された証拠もないのに、超過額が最も小さくなるという理由で選んでしまうこと。
  • 初期のCPIの1回の値に頼ること。 推移を待ちましょう。初期の指数は大きく振れます。
  • 質の低い進捗データを使うこと。 主観的な完了率はEVを水増しし、すべての予測を実際より良く見せます。
  • 未払計上やコミット済みのコストを除外すること。ACとEACが過小に表示されます。
  • EACをBACや資金上限と混同すること。 EACは予測、BACは承認済みの予算であり、資金にはマネジメント予備が含まれる場合があります。
  • マネジメント予備をBACに含めること。 予備はパフォーマンス測定ベースラインの外にあります。
  • プロジェクトレベルでのみ予測すること。超過しているワークパッケージが隠れてしまいます。
  • 根拠を示さずに1つの数字だけを報告すること。予測を信頼したり、検証したりするのが難しくなります。
  • 承認された変更の後にBACを更新しないこと。正式に追加されたスコープが差異に含まれてしまいます。

PMP試験におけるEAC

EACの問題はPMPやCAPMの対策教材によく登場します。いくつかの決まりごとを押さえておくと役立ちます：

  • 問題文で差異が 典型的 である、または実績が 続くとされている場合は、BAC / CPIを使います。
  • 差異が 非典型的, a 一度限り である、または 再発しないとされている場合は、AC + (BAC - EV)を使います。
  • コストとスケジュールの両方が残りの作業に影響すること、または 動かせない期限に触れている場合は、AC + (BAC - EV) / (CPI x SPI)を使います。
  • 問題文で 当初の見積りに欠陥がある 、または新たな見積りが作成されたとされている場合は、AC + ETCを使います。
  • ETC = EAC - AC、VAC = BAC - EACを覚えておきましょう。VACがマイナスなら予算超過です。
  • TCPIが1を超える場合、残りの作業は計画より高い効率が必要です。

よくある質問

プロジェクトマネジメントにおける完成時総コスト見積りとは何ですか？

完成時総コスト見積り（EAC）とは、すべての作業が完了したときのプロジェクトの総コストの予測です。現時点までの実コストと残作業の見積りコストの合計に等しく、完成時総予算と比較して予想される超過や余剰を示します。

EACの計算式は何ですか？

標準的な計算式は4つあります：BAC / CPI、AC + (BAC - EV)、AC + (BAC - EV) / (CPI x SPI)、AC + ボトムアップの残作業コスト見積り。一般的な関係は常にEAC = AC + ETCです。

最もよく使われるEACの計算式はどれですか？

EAC = BAC / CPIです。現在のコスト効率が続くと仮定しており、プロジェクトがかなり進んだ段階では現実的であることが多く、多くのツールや試験問題で既定になっています。

EACとETCの違いは何ですか？

EACはプロジェクトの総コストの予測です。ETC（残作業コスト見積り）は、まだ残っている作業のコストの予測です。EAC = AC + ETCなので、ETC = EAC - ACです。

EACとBACの違いは何ですか？

BACはすべての作業に対する承認済みの予算で、変更管理を経なければ変わりません。EACは最終コストの現時点の予測で、報告期間ごとに変わる可能性があります。その差はVAC = BAC - EACで示されます。

EAC = AC + (BAC - EV)はどのような場合に使うべきですか？

これまでの差異がすでに解決した一度限りの出来事によるもので、残りの作業は予算どおりの単価で行われると見込まれる場合です。予算超過のプロジェクトにとっては最も楽観的な計算式です。

CPI x SPIの計算式はいつ使うべきですか？

プロジェクトのスケジュールが遅れており、それでも固定の期日に間に合わせる必要があるため、残業、資源の追加、前倒しによって挽回のコストがかかる場合です。両方の指数が1未満のときは、通常これが最も高いEACになります。

EACはBACより低くなることがありますか？

はい。CPIが1を超えている場合、プロジェクトは実施した作業に対して予算より少なく支出しており、EACはBACを下回ります。その場合VACはプラスになり、予算の余剰が予測されることを示します。

VACがマイナスとはどういう意味ですか？

完成時差異 = BAC - EACです。VACがマイナスなら、プロジェクトはその額だけ予算を超過して終わると予測されます。たとえば、BACが$200,000でEACが$242,857なら、VACは-$42,857です。

TCPIとは何ですか？EACとどう関係しますか？

残作業効率指数は、目標を達成するために残りの作業が達成すべきコスト効率です。BACに対するTCPI = (BAC - EV) / (BAC - AC)、EACに対するTCPI = (BAC - EV) / (EAC - AC)です。TCPIが現在のCPIを大きく上回る場合、その目標は非現実的です。

EACはどのくらいの頻度で更新すべきですか？

他のアーンドバリューの指標とともに、報告期間ごと（通常は毎月、または各スプリントやフェーズの終わり）に更新します。また、承認された変更や重大なリスクの発生など、大きな出来事の後にも更新しましょう。

ボトムアップのEACは計算式より優れていますか？

計画が大きく変わった場合は、現在のスコープ、単価、リスクを反映するため、通常はボトムアップのほうが信頼できます。計算式はより速く、ボトムアップの数値に対する独立した検算として役立ちます。

独立EACとは何ですか？

独立EAC（IEAC）は、マネジメントの判断を交えず、アーンドバリューの計算式だけで算出した予測です。プロジェクトマネージャー自身の予測を検証するために使われ、両者に大きな差がある場合は説明が必要です。

EACはプロジェクト予測と同じですか？

EACはプロジェクト予測のうちコストの部分です。完全な予測には、予想終了日や、多くの場合は便益も含まれます。詳しくは次のガイドをご覧ください： プロジェクトの予測.
