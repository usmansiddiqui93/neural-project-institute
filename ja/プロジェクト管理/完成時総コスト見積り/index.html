完成時総コスト見積り（EAC）：計算式、例、コツ

完成時総コスト見積り（EAC）とは、すべての作業が完了したときにプロジェクトにかかる総コストの予測です。すでに支出した額と、残りの作業のコストの見積りを組み合わせたものです。

要点

  • EACは完了時の総コストを予測します。
  • 差異の原因に合った計算式を選びましょう。
  • ETC = EAC - AC、VAC = BAC - EAC。TCPIは必要な効率を示します。
  • 1つの数値ではなく、EACの範囲を報告しましょう。

EACの4つの計算式

計算式使う場面
EAC = BAC / CPI現在のコストパフォーマンスが続くと見込まれる（典型的な差異）
EAC = AC + (BAC - EV)過去の差異は一時的で、残作業は計画どおりに進む（非典型的な差異）
EAC = AC + (BAC - EV) / (CPI x SPI)コストとスケジュールの両方のパフォーマンスが残作業に影響する場合（例：終了日が固定されている）
EAC = AC + ボトムアップのETC当初の計画がもはや有効でなく、残作業を再見積りする

関連する予測

  • 残作業コスト見積り（ETC） = EAC - AC：まだ必要な資金。
  • 完成時差異（VAC） = BAC - EAC：見込まれる予算の余剰または超過。
  • TCPI（BAC基準） = (BAC - EV) / (BAC - AC)：予算内で完了するために必要な効率。
  • TCPI（EAC基準） = (BAC - EV) / (EAC - AC)：予測を達成するために必要な効率。

計算例

BAC = $200,000、PV = $80,000、EV = $70,000、AC = $85,000。したがってCPI = 0.8235、SPI = 0.875。残作業 = BAC - EV = $130,000。

計算式計算EACVAC
BAC / CPI200,000 / 0.8235$242,857-$42,857
AC + (BAC - EV)85,000 + 130,000$215,000-$15,000
AC + (BAC - EV) / (CPI x SPI)85,000 + 130,000 / 0.7206$265,408-$65,408
AC + ボトムアップのETC85,000 + 140,000$225,000-$25,000

典型的な計算式では、ETC = 242,857 - 85,000 = $157,857。BACを達成するためのTCPI = 130,000 / 115,000 = 1.13、一方、EACの$242,857を達成するためのTCPI = 130,000 / 157,857 = 0.82で、これは単に現在のCPIと一致します。

適切なEACの選び方

  1. 差異が生じた理由を突き止めます。
  2. 原因が継続的なもの（例：単価が計画より高い）であれば、BAC / CPIを使います。
  3. 一時的なもの（例：1社のサプライヤーの不履行）であれば、AC + (BAC - EV)を使います。
  4. 固定された日付を守らなければならず遅れている場合は、CPI x SPIの計算式を検討します。
  5. 前提条件が大きく変わった場合は、残作業をボトムアップで再見積りしましょう。
  6. 範囲で報告しましょう。複数の計算式を合わせると、最良から最悪までの有用な幅が得られます。

よくある間違い

  • 超過が魔法のように回復すると想定すること（既定でAC + (BAC - EV)を使うこと）。
  • 初期の1回だけのCPIの数値を使うこと。傾向が見えるまで待ちましょう。
  • まだ請求されていない確定済みのコストを無視すること。
  • EACをBACや資金の上限と混同すること。

よくある質問

完成時総コスト見積りとは何ですか？

すべての作業が完了したときのプロジェクトの予測総コストで、EACと表記します。

最も一般的なEACの計算式は何ですか？

EAC = BAC / CPIで、現在のコスト効率が続くと仮定します。

EACとETCの違いは何ですか？

EACは予測総コスト、ETCは残作業の予測コストです。EAC = AC + ETC。

EAC = AC + (BAC - EV)はどのような場合に使うべきですか？

過去の差異が一時的なもので、残りの作業は計画どおりに進むと見込まれる場合です。

CPI x SPIのEAC計算式はどのような場合に使うべきですか？

スケジュールのプレッシャーがコストに影響しそうな場合です。たとえば、期限が固定されていて遅れを取り戻すために追加の工数が必要になる場合です。

EACはVACの計算にどう使われますか？

完成時差異 = BAC - EAC。VACがマイナスであれば、それが予測される超過額です。

EACを目標とする場合、TCPIが1を上回るとはどういう意味ですか？

目標を達成するには、残りの作業を計画より効率的に行う必要があります。1を大きく上回る値は非現実的なことが多いです。

EACはどのくらいの頻度で更新すべきですか？

報告期間ごとに、他のアーンドバリューの指標とあわせて更新します。

EACはBACより低くなることがありますか？

はい。CPIが1を上回っていれば、プロジェクトは予算を下回って完了すると予測されます。

ボトムアップのEACは計算式より優れていますか？

計画が大きく変わった場合は、多くの場合そうです。現在の知識を反映しているからです。計算式はより速く、クロスチェックとして役立ちます。

EACはプロジェクトの予測とどう違いますか？

EACは プロジェクトの予測のうちコストに関する部分で、予測は完了日やベネフィットも対象とします。
