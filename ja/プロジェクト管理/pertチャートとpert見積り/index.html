プロジェクトマネジメントガイド · スケジューリングと時間

PERTチャートとPERT見積り：計算式と計算例

PERT（プログラム評価レビュー技法）は、各アクティビティについて楽観値、最頻値、悲観値という3つの所要期間の見積りを使い、期待所要期間と不確実性の尺度を算出するスケジューリング手法です。PERT図は、これらのアクティビティとその依存関係を示すネットワーク図です。

要点

  • PERTの期待所要期間 = (O + 4M + P) / 6、SD = (P - O) / 6。
  • パスに沿って期待所要期間を合計し、SDではなく分散を合計します。
  • パスのSDを使って、期限に間に合う確率を見積もりましょう。
  • 不確実な作業にはPERTを使い、パスの合流はシミュレーションで確認しましょう。

PERTの計算式

指標計算式
期待所要期間（E）(O + 4M + P) / 6
標準偏差（SD）(P - O) / 6
分散SDの2乗
パスのSDパス上の分散の合計の平方根

O = 楽観値、M = 最頻値、P = 悲観値。この計算式はベータ分布に基づき、最頻値に4倍の重みを置きます。より簡単な代替として、三角分布の平均 (O + M + P) / 3 が使われることもあります。参考： コスト見積り.

計算例：1つのアクティビティ

ある設計アクティビティは、O = 4日、M = 6日、P = 14日と見積もられています。

  • E = (4 + 4 x 6 + 14) / 6 = (4 + 24 + 14) / 6 = 42 / 6 = 7日.
  • SD = (14 - 4) / 6 = 10 / 6 = 約 1.67日.
  • 悲観値が大きく離れているため、期待所要期間（7日）が最頻値（6日）よりも長くなっている点に注目してください。

PERT図の作成方法

  1. 一覧にする：アクティビティとその 依存関係.
  2. 作業を行う人たちからO、M、Pの見積りを集める。
  3. 各アクティビティのEとSDを計算する。
  4. 作成する： ネットワーク図 （所要期間にはEを使用）。
  5. 次の方法でクリティカルパスを求める： フォワードパスとバックワードパス.
  6. クリティカルパス上の分散を合算し、期限に間に合う確率を見積もる。
  7. スポンサーが求める信頼水準に基づいて、コンティンジェンシーやバッファーを設定する。

限界とコツ

  • PERTはクリティカルパスのみを考慮するため、ニアクリティカルパスが合流する箇所ではリスクを過小評価することがあります。
  • 見積りには偏りが生じ得ます。余裕を上乗せした最頻値だけでなく、悲観的なケースを明示的に尋ねましょう。
  • 新しい作業や不確実な作業にはPERTを使いましょう。定型的な作業には単一の見積りで十分です。
ヒント

OとPが大きく離れている場合、そのアクティビティはよく理解されていません。単一の数値に頼る前に、分解するか調査しましょう。

よくある質問

PERTは何の略ですか？

Program Evaluation and Review Technique（プログラム評価レビュー技法）の略です。

PERTの計算式とは何ですか？

期待所要期間 = (楽観値 + 4 x 最頻値 + 悲観値) / 6。

PERTの標準偏差はどのように計算しますか？

(悲観値 - 楽観値) / 6。

PERT見積りの例にはどのようなものがありますか？

O = 4日、M = 6日、P = 14日の場合、PERT見積りは(4 + 24 + 14) / 6 = 7日です。

PERTではなぜ最頻値に4を掛けるのですか？

この計算式は、最頻値に最も大きな重みを置くベータ分布を近似したものです。

PERTとCPMの違いは何ですか？

PERTは3つの見積りを使って不確実性に対処し、CPMは1つの見積りを使ってロジックとフロートに焦点を当てます。

PERT図とガントチャートの違いは何ですか？

PERT図は依存関係のネットワークであり、ガントチャートはアクティビティをカレンダー上のバーで示します。

PERTにおける三点見積りとは何ですか？

楽観値、最頻値、悲観値を使って見積もる方法です。PERTはそれらを組み合わせる方法の1つであり、三角分布の平均も別の方法です。

PERTはいつ開発されましたか？

1950年代後半に、米海軍のポラリス・ミサイル計画のために開発されました。

PERTはアジャイルで使われますか？

完全な形で使われることは通常ありませんが、三点で考える方法は、次と併せてリリース予測に役立ちます： ストーリーポイント.
