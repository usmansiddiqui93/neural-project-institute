プロジェクトマネジメントにおける感度分析：ガイドと例

感度分析とは、他の入力値を固定したまま1つの入力値を変えたときに、コスト、利益、正味現在価値、終了日などのプロジェクトの結果がどれだけ変化するかを検証するものです。どの前提条件が最も重要かがわかるため、見積りの労力やリスク対応をどこに集中させるべきかを判断できます。

要点

  • 感度分析では、入力値を1つずつ変えてその影響を確認します。
  • 振れ幅で入力値を順位付けし、トルネードチャートで示しましょう。
  • 損益分岐点と組み合わせて、ビジネスケースの余裕度を検証しましょう。
  • 変数が相互に影響し合う場合は、シナリオ分析やモンテカルロを使いましょう。

プロジェクトマネージャーが感度分析を使う理由

  • コスト、ベネフィット、スケジュールの不確実性の大部分を左右する少数の変数を特定する。
  • 主要な前提条件が誤っていても、 ビジネスケース が成り立つかを検証する。
  • 製品がまだ利益を生む最低価格など、損益分岐点を求めます。
  • 次において、対応計画のためにリスクの優先順位を付ける： プロジェクトリスクマネジメント.
  • トルネードチャートを使って、不確実性をスポンサーにわかりやすく示す。

感度分析の手順

  1. 結果の簡単なモデルを作成します。対象は利益、 正味現在価値 または総コスト。
  2. 最善の見積りを使って基準ケースを計算します。
  3. 不確実な入力変数を洗い出します。
  4. 各変数について現実的な低い値と高い値を選びます。例えばプラスマイナス10%、または専門家による範囲です。
  5. 他の変数はすべて基準値のまま、1つの変数ずつ低い値と高い値に変えて、その結果を記録します。
  6. 各変数の振れ幅（高い値のときの結果 - 低い値のときの結果）を計算します。
  7. 振れ幅で変数を順位付けし、最も大きい棒を一番上にしてトルネードチャートを描きます。
  8. 見積りとリスク対応は、上位の変数に集中させます。

計算例：製品利益のトルネードチャート

あるプロジェクトで製品を発売します。基準ケースのモデルは次のとおりです： 利益 = 販売数量 x（価格 - 変動費）- 固定費。基準値：販売数量10,000、価格$50、単位あたり変動費$30、固定費$120,000。基準利益 = 10,000 x ($50 - $30) - $120,000 = $80,000.

他の入力値は基準値のまま、各入力値を上下に10%動かします。

変数（-10% / +10%）低い値のときの利益高い値のときの利益振れ幅
価格（$45 / $55）$30,000$130,000$100,000
変動費（$27 / $33）$110,000$50,000$60,000
販売数量（9,000 / 11,000）$60,000$100,000$40,000
固定費（$108,000 / $132,000）$92,000$68,000$24,000

トルネードチャートにすると、価格が最も幅の広い棒として一番上に来て、変動費、販売数量、固定費の順に続きます。最も重要なのは価格で、10%の変化で利益がどちらの方向にも$50,000動きます。損益分岐価格は$120,000 / 10,000 + $30 = $42となるため、価格が16%下落するまではプロジェクトは赤字になりません。チームは固定費の見積りを精緻化するよりも、価格の前提を検証し、単位コストを管理することに労力を注ぐべきです。

感度分析と他の技法の比較

技法変わる点アウトプット最適な用途
感度分析一度に1つの変数変数の順位、トルネードチャート最も重要なものの特定
シナリオ分析定義したケースで複数の変数を同時に変える最善、基準、最悪のケースの結果起こりうる将来像の説明
損益分岐点分析結果がゼロになるまで1つの変数を変えるしきい値ビジネスケースの余裕度を検証する
モンテカルロ・シミュレーションすべての変数をランダムに同時に、何度も変える結果の確率分布コストと日程の信頼水準

スケジュールにおける感度

同じ考え方は時間にも当てはまります。クリティカルなアクティビティを1つずつ延ばしてみると、どれが終了日を最も遅らせるかがわかります。モンテカルロのスケジュールツールでは、感度レポートやクリティカリティレポートが終了日への影響の強さでアクティビティを順位付けするため、次の的を絞るのに役立ちます： スケジュール短縮 とリスク対応。

限界とコツ

  • 1つずつ変える方法では相互作用が無視されます。変数が連動して動く場合は、シナリオ分析を加えましょう。
  • より良いデータがある場合は、すべてに同じ割合を使うのではなく、変数ごとに現実的な範囲を使いましょう。
  • モデルの良し悪しはその構造で決まります。順位を信頼する前に計算式を確認しましょう。
  • 他の人がレビューできるよう、範囲とその根拠を記録します。
  • 主要な前提条件が変わったら、分析をやり直します。
ヒント

トルネードチャートと損益分岐点をあわせてスポンサーに示しましょう。「何が最も重要か？」と「どこまで見込みが外れたら失敗するか？」の両方に1つの図で答えられます。

よくある質問

プロジェクトマネジメントにおける感度分析とは何ですか？

入力値を1つずつ変えて、コスト、利益、NPV、終了日などの結果にどれだけ影響するかを確認し、どの前提条件が最も重要かを明らかにする技法。

感度分析におけるトルネード図とは何ですか？

結果をどれだけ振れさせるかによって変数を順位付けした棒グラフです。最も幅の広い棒が一番上に来るため、竜巻（トルネード）のように見えます。

簡単な感度分析はどのように行いますか？

基準ケースを計算し、不確実な入力値を1つずつ低い値と高い値に動かして結果を記録し、変化の大きさで入力値を順位付けします。

感度分析とシナリオ分析の違いは何ですか？

感度分析は一度に1つの変数を変えます。シナリオ分析は複数の変数を同時に変えて、最善、基準、最悪のケースを描きます。

感度分析とモンテカルロ・シミュレーションはどのような関係ですか？

モンテカルロはすべての入力値を同時に何度も変えて確率を求めます。その感度出力によって、どの入力値が結果に最も影響するかがわかります。

感度分析は定性的ですか、それとも定量的ですか？

定量的です。定量的リスク分析や財務評価における標準的な技法です。

感度分析ではどのような範囲を使うべきですか？

各変数について、データや専門家の判断に基づく現実的な範囲を使いましょう。より良い根拠がない場合は、プラスマイナス10%や20%が簡単な出発点になります。

感度分析における損益分岐点分析とは何ですか？

利益がゼロになる価格など、結果がゼロに達する変数の値を求めることです。

感度分析はいつ行うべきですか？

ビジネスケースを作成するとき、リスク分析の際、そして主要な前提条件が変わったときに改めて行います。

感度分析はExcelで行えますか？

はい。データテーブルや1つずつ手動で値を変える簡単なモデルで十分です。振れ幅の順に並べた棒グラフがトルネードチャートになります。

感度分析の限界は何ですか？

変数間の相互作用を無視しており、結果はモデルと選んだ範囲の現実性に左右されます。
