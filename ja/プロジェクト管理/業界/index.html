建設、エンジニアリング、不動産

建設、エンジニアリング、インフラ、建築、不動産、インテリアデザインのプロジェクトマネジメント。

  1. 建設プロジェクトマネジメント：フェーズ、役割、ツール、コツ建設プロジェクトマネジメントの仕組み：設計前から完了までのフェーズ、主要な役割、契約、手法、文書、KPI、使うべきソフトウェア。
  2. エンジニアリング・プロジェクトマネジメント：フェーズ、役割、手法、KPIエンジニアリング・プロジェクトマネジメントを解説：ステージゲートとデザインレビュー、Vモデル、主要な役割、文書、KPI、よくある課題、使うべきソフトウェア。
  3. インフラ・プロジェクトマネジメント：フェーズ、役割、ツール道路、鉄道、公益事業、エネルギーにおけるインフラ・プロジェクトマネジメントの仕組み：フェーズ、許認可、役割、契約、KPI、課題、ソフトウェア。
  4. 建築プロジェクトマネジメント：ステージ、役割、報酬、ツール設計事務所のための建築プロジェクトマネジメント：RIBAとAIAのステージ、役割、報酬と資源の管理、文書、KPI、課題、使うべきソフトウェア。
  5. 不動産プロジェクトマネジメント：フェーズ、役割、KPI、ツール不動産プロジェクトマネジメントを解説：取得から安定稼働までの開発サイクル、役割、評価、文書、KPI、リスク、ソフトウェア。
  6. インテリアデザインのプロジェクトマネジメント：フェーズ、FF&E、ツールスタジオのためのインテリアデザイン・プロジェクトマネジメント：ブリーフから設置までのフェーズ、FF&Eの調達、役割、文書、KPI、課題、使うべきソフトウェア。

IT、ソフトウェア、デジタル

IT、ソフトウェア開発、ゲーム開発のプロジェクトマネジメント。

  1. ITプロジェクトマネジメント：フェーズ、役割、手法、ツールITプロジェクトマネジメントを解説：立ち上げからハイパーケアまでのフェーズ、役割、アジャイル、ウォーターフォール、ITIL、主要な文書、KPI、課題、ソフトウェア。
  2. ソフトウェアプロジェクトマネジメント：ライフサイクル、役割、手法、KPIソフトウェアプロジェクトマネジメントを解説：SDLC、役割、スクラム、かんばん、DevOps、バックログとリリース計画、DORAメトリクス、よくある落とし穴、ツール。
  3. ゲーム開発のプロジェクトマネジメント：フェーズ、役割、ツールゲーム開発のプロジェクトマネジメントを解説：コンセプトからライブ運営まで、マイルストーン、役割、スタジオでのスクラムとかんばん、文書、KPI、クランチ、ツール。

マーケティング、クリエイティブ、イベント

マーケティング、クリエイティブ、エージェンシー、動画制作、イベントチームのプロジェクトマネジメント。

  1. マーケティング・プロジェクトマネジメント：フェーズ、役割、ツール、コツマーケティング・プロジェクトマネジメントの仕組み：キャンペーンのライフサイクル、役割、手法、ブリーフとテンプレート、KPI、よくある課題、使うべきソフトウェア。
  2. クリエイティブ・プロジェクトマネジメント：ワークフロー、役割、ツール、コツクリエイティブ・プロジェクトマネジメントを解説：ブリーフから納品までのクリエイティブワークフロー、主要な役割、手法、テンプレート、KPI、課題、ソフトウェア。
  3. エージェンシーのプロジェクトマネジメント：プロセス、役割、ツール、コツエージェンシーのプロジェクトマネジメントの仕組み：クライアントエンゲージメントのサイクル、役割、手法、SOWとテンプレート、稼働率などのKPI、課題、ソフトウェア。
  4. 動画制作のプロジェクトマネジメント：フェーズ、役割、ツール動画制作のプロジェクトマネジメントの仕組み：企画開発、プリプロダクション、撮影、ポストプロダクションの各段階、クルーの役割、コールシート、予算、KPI、ツール。
  5. イベントのプロジェクトマネジメント：フェーズ、役割、ツール、コツイベントのプロジェクトマネジメントを解説：イベント企画のライフサイクル、役割、進行表とテンプレート、KPI、リスクと安全、課題、ソフトウェア。

プロフェッショナルサービス

プロフェッショナルサービス企業、コンサルティング会社、法務チームのプロジェクトマネジメント。

  1. プロフェッショナルサービスのプロジェクトマネジメント：ガイドとツールプロフェッショナルサービスのプロジェクトマネジメントの仕組み：エンゲージメントのライフサイクル、役割、価格モデル、SOWとテンプレート、稼働率KPI、PSAツール。
  2. コンサルティングのプロジェクトマネジメント：フェーズ、役割、ベストプラクティスコンサルティングのプロジェクトマネジメントの仕組み：エンゲージメントのフェーズ、役割、仮説主導のワークプラン、提案書とテンプレート、KPI、課題、ツール。
  3. リーガル・プロジェクトマネジメント：プロセス、役割、ツール、コツリーガル・プロジェクトマネジメントを解説：訴訟と取引案件のフェーズ、役割、予算と報酬モデル、テンプレート、KPI、LPMソフトウェア。

医療、公共部門、研究

医療、行政、非営利団体、教育、研究におけるプロジェクトマネジメント。

  1. 医療プロジェクトマネジメント：フェーズ、役割、ツール、コツ医療プロジェクトマネジメントの仕組み：臨床安全、規制、ライフサイクルのフェーズ、役割、手法、文書、KPI、課題、ソフトウェア。
  2. 行政プロジェクトマネジメント：フェーズ、役割、ツール、コツ行政プロジェクトマネジメントの仕組み：公的説明責任、調達、資金ルール、ライフサイクルのフェーズ、役割、手法、KPI、ソフトウェア。
  3. 非営利団体のプロジェクトマネジメント：フェーズ、役割、ツール、コツ非営利団体のプロジェクトマネジメントの仕組み：助成金、寄付者、ボランティア、変化の理論、フェーズ、役割、文書、KPI、課題、ツール。
  4. 教育分野のプロジェクトマネジメント：フェーズ、役割、ツール、コツ学校や大学における教育プロジェクトマネジメントの仕組み：学事暦、役割、フェーズ、手法、文書、KPI、課題、ツール。
  5. 研究プロジェクトマネジメント：フェーズ、役割、ツール、コツ研究プロジェクトマネジメントの仕組み：研究助成金、倫理審査、データ管理、フェーズ、役割、手法、文書、KPI、課題、ツール。

産業とオペレーション

製造業、エネルギー、医薬品、人事におけるプロジェクトマネジメント。

  1. 製造業のプロジェクトマネジメント：NPI、フェーズ、手法、KPI製造業のプロジェクトマネジメントを解説：新製品導入、APQPとステージゲートのフェーズ、役割、リーンとシックスシグマ、文書、KPI、ツール。
  2. エネルギー分野のプロジェクトマネジメント：フェーズ、役割、ツール、コツ石油・ガス、電力、再生可能エネルギーにおけるエネルギープロジェクトマネジメントの仕組み：ステージゲート、FEED、EPCの役割、許認可、テンプレート、HSEのKPI、ソフトウェア。
  3. 医薬品のプロジェクトマネジメント：フェーズ、役割、ツール医薬品プロジェクトマネジメントの仕組み：医薬品開発のフェーズ、GxP、臨床試験の役割、ステージゲート、テンプレート、KPI、課題、ソフトウェア。
  4. 人事のプロジェクトマネジメント：フェーズ、役割、ツール、コツ人事プロジェクトマネジメントの仕組み：HRIS導入、組織再編、制度変更、従業員データ、協議、フェーズ、役割、手法、KPI、ツール。

ビジネスとエンタープライズ

大企業、中小企業、リモートチームなど、あらゆる規模の企業のためのプロジェクトマネジメント。

  1. ビジネスプロジェクトマネジメント：フェーズ、役割、ツール、コツビジネスプロジェクトマネジメントの仕組み：プロジェクトと戦略の連動、ビジネスケース、ベネフィット、フェーズ、役割、手法、文書、KPI、ツール。
  2. エンタープライズ・プロジェクトマネジメント（EPM）：フェーズ、役割、ツールエンタープライズ・プロジェクトマネジメント（EPM）とは何か：ポートフォリオガバナンス、PMO、標準手法、資源管理、役割、KPI、課題、EPMソフトウェア。
  3. 中小企業のプロジェクトマネジメント：手法、ツール、コツ中小企業のための実践的なプロジェクトマネジメント：軽量なフェーズ、一人が何役もこなす場合の役割、シンプルな手法、テンプレート、KPI、ツール。
  4. リモート・プロジェクトマネジメント：プラクティス、役割、ツール、コツリモート・プロジェクトマネジメントの仕組み：非同期コミュニケーション、タイムゾーン、ドキュメント化、役割、手法、定例の習慣、KPI、課題、リモートPMツール。

その他のガイド

プロジェクトマネジメントガイド計画、スケジューリング、リスク、予算、ステークホルダー、ツール、方法論など、プロジェクトマネジメントのあらゆる分野を扱う無料の実践ガイド。アジャイルガイドアジャイルを理解し実践するために必要なすべて：価値観と原則、プラクティス、役割、スケーリングフレームワーク、始め方。スクラムガイドスクラムの完全ガイド：責任、イベント、作成物、見積り、スケーリング、スクラムを上手に運用する方法。かんばんガイドかんばんとリーンフローを解説：ボード、WIP制限、メトリクス、比較、その背景にあるリーンの考え方。
