プロジェクトの予測：コストと日程を予測する手法

プロジェクトの予測とは、これまでの実績と残りの作業に基づき、プロジェクトが最終的にどうなるか、主に最終コストと完了日を予測することです。優れた予測は、スポンサーに早期かつ正直な警告を与え、まだ時間があるうちに意思決定できるようにします。

  • 公開日 2026年9月30日
  • 3分で読めます

要点

  • 最終コストと完了日の両方を予測しましょう。
  • 計算式を出発点として使い、その後チームと検証しましょう。
  • 信頼水準付きの範囲で示しましょう。
  • 予測は期間ごとに更新し、正直に報告しましょう。

予測する対象

  • 最終コスト： 完成時総コスト見積り（EAC）.
  • 完了までのコスト： 残作業コスト見積り（ETC）。
  • 完了日： 最後の成果物がいつ完成するか。
  • 必要な資源： 残りの作業に必要な人員とスキル。
  • ベネフィット： 期待される価値が引き続き実現されるかどうか。

予測の手法

手法仕組み強み
アーンドバリューの計算式EAC = BAC / CPIとその派生式迅速かつ客観的で、傾向データを使える
アーンドスケジュール所要期間の予測 = 計画所要期間 / SPI(t)時間の予測が得られる
ボトムアップの再見積り残りのすべての作業を再見積りする最新の知見を反映できる
クリティカルパス分析スケジュールネットワークを更新する実際にスケジュールを左右するタスクがわかる
モンテカルロ・シミュレーション範囲から多数のシナリオを実行する確率が得られる（例：信頼度80%）
アジャイルのスループットまたはベロシティ残りのバックログ / 平均ベロシティ反復型の作業ではシンプル。参考： ベロシティ

計算例

BAC = $200,000、計画所要期間は8か月。4か月目の時点で、EV = $70,000、AC = $85,000、CPI = 0.8235、SPI = 0.875、アーンドスケジュールのSPI(t) = 0.917です。

予測計算結果
EAC（コスト）200,000 / 0.8235$242,857
ETC242,857 - 85,000$157,857
所要期間（単純なSPI）8 / 0.8759.1か月
所要期間（アーンドスケジュール）8 / 0.9178.7か月

2つの所要期間の予測から、おおよそ8.7〜9.1か月という範囲が得られます。プロジェクトマネージャーは報告前にクリティカルパスを確認し、どちらがより現実的かを見極めます。

信頼できる予測の作り方

  1. 実コストと進捗のデータが最新かつ正確であることを確認する。
  2. 計算式に基づく予測を出発点として算出する。
  3. 計画が変わった部分については、チームに残作業の再見積りを依頼する。
  4. 未解決のリスクと保留中の変更要求を考慮に入れる。
  5. 単一の点ではなく、信頼水準付きの範囲で示しましょう。
  6. 要因と、結果を改善し得るアクションを説明しましょう。

よくある間違い

  • スポンサーが聞きたいことを予測すること。
  • 根拠もなくプロジェクトが挽回すると想定すること。
  • 日付を予測せずにコストだけを予測すること、またはその逆。
  • 予測の更新頻度が低すぎること。
  • 契約済みのコストや保留中の変更を無視すること。

よくある質問

プロジェクトの予測とは何ですか？

これまでの実績と残りの作業から、プロジェクトの最終コスト、完了日、その他の結果を予測することです。

プロジェクトの予測では、最終コストをどのように予測しますか？

EAC = BAC / CPIなどのアーンドバリューの計算式を使い、残作業のボトムアップ見積りと照合します。

プロジェクトの予測では、完了日をどのように予測しますか？

スケジュールとクリティカルパスを更新するか、アーンドスケジュールを使います：計画所要期間 / SPI(t)。

プロジェクトの予測と見積りの違いは何ですか？

見積りは作業開始前に行われ、予測は実際の実績を使って見通しを更新するものです。

プロジェクトの予測はどのくらいの頻度で更新すべきですか？

報告期間ごと、そして重大な変更やリスクが発生したときです。

モンテカルロ法によるプロジェクトの予測とは何ですか？

見積りの範囲から数千のシナリオを実行し、ある日付までに、またはあるコスト内で完了する確率を示すシミュレーションです。

アジャイルチームでは、プロジェクトの予測はどのように行いますか？

残りのバックログを直近のベロシティやスループットで割って求めます。多くの場合、範囲で示します。

プロジェクトの予測を単一の数値ではなく範囲で示すのはなぜですか？

未来は不確実だからです。信頼水準付きの範囲のほうが、より誠実で有用です。

プロジェクトの予測におけるETCとは何ですか？

残作業コスト見積り：残りの作業にかかると予想されるコストで、ETC = EAC - ACです。

プロジェクトの予測に役立つツールは何ですか？

スプレッドシート、スケジューリングツール、および プロジェクト管理ソフトウェア （アーンドバリューやバーンアップのレポート機能を備えたもの）。
