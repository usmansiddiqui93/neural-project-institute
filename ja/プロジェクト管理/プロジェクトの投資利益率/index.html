プロジェクトの投資利益率（ROI）：計算式と例

投資利益率（ROI）は、プロジェクトのコストに対してどれだけの利益を得られるかをパーセントで表す指標です。基本の計算式はROI =（純ベネフィット / コスト）x 100で、純ベネフィットは総ベネフィットから総コストを引いたものです。

要点

  • ROI = 純ベネフィット / コスト x 100。
  • 必ず対象期間を明記し、すべてのコストを含めましょう。
  • 基本的なROIはタイミングを考慮しないため、回収期間やNPVと組み合わせて使いましょう。
  • 提供後に実際のROIを測定し、ベネフィットを確認しましょう。

計算式

ROI =（総ベネフィット - 総コスト）/ 総コスト x 100

  • ROIがプラスであれば、ベネフィットがコストを上回っていることを意味します。
  • ROIはシンプルで伝えやすい指標ですが、基本的なROIでは資金がいつ入ってくるかが考慮されません。
  • 3年間のROIなど、対象期間を明記します。

計算例

あるプロジェクトはコストが$100,000で、3年間にわたり年$40,000のコスト削減を生み出します。

  • 総ベネフィット = 3 x 40,000 = $120,000。
  • 純ベネフィット = 120,000 - 100,000 = $20,000。
  • 3年間のROI = 20,000 / 100,000 x 100 = 20%.
  • 回収期間 = 100,000 / 40,000 = 2.5年.

8%で割り引いた数値を使うと、 NPV は約$3,084となり、割引後のROIは約3,084 / 100,000 = 3.1%となります。この差から、タイミングがいかに重要かがわかります。

プロジェクトROIの計算方法

  1. 対象期間と、何をベネフィットとみなすかについて合意します。
  2. すべてのコストを洗い出します：構築、運用、トレーニング、サポート、社内スタッフの時間。
  3. ベネフィットを見積もります：収益、コスト削減、回避できたコスト。いずれにしても発生するベネフィットは除外します。
  4. 純ベネフィットとROIを計算します。
  5. 全体像をより正確に把握するため、回収期間とNPVも加えましょう。
  6. プロジェクト終了後、ベネフィット実現の一環として実際のROIを測定します。

よくある落とし穴

  • 継続的に発生するコストを除外し、ROIを過大に見せる。
  • 異なる期間で測定したROIを比較する。
  • 節約できた時間などのソフトなベネフィットを、それを実現する計画もないまま現金として計上する。
  • リスクを無視する：不確実なベネフィットに基づく高いROIは、確実で控えめなROIより価値が低い場合があります。

よくある質問

プロジェクトマネジメントにおけるROIとは何ですか？

投資利益率：プロジェクトの純ベネフィットをコストで割り、パーセントで表したもの。

ROIの計算式は何ですか？

ROI =（総ベネフィット - 総コスト）/ 総コスト x 100。

プロジェクトにとって良いROIとはどの程度ですか？

組織の目標、リスク、代替案によって異なります。財務チームは最低限のハードルレートを設定していることがよくあります。

ROIとNPVの違いは何ですか？

ROIは通常タイミングを考慮しないパーセントの指標で、NPVは将来のキャッシュフローを割り引いた金額の指標です。

ROIとあわせて回収期間はどのように計算しますか？

キャッシュインフローが毎年一定の場合、初期投資額を年間の純キャッシュインフローで割ります。$100,000 / 年$40,000 = 2.5年です。

ROIがマイナスになることはありますか？

はい。ROIがマイナスであれば、測定期間においてプロジェクトのコストがリターンを上回っていることを意味します。

社内プロジェクトのROIはどのように測定しますか？

コスト削減、回避できたコスト、生産性の向上を金額に換算し、提供後にそれらをどう測定するかについて合意します。

社内スタッフの時間はROIに含めるべきですか？

はい。スタッフの時間は新たな支払いを伴わなくてもコストがかかるため、含めましょう。

ROIはいつ測定すべきですか？

ビジネスケースで見積もり、提供後にベネフィットが現れるまでの時間をおいてから測定します。

年率換算ROIとは何ですか？

ROIを同等の年率に換算したものです。期間の異なる投資を比較する際に役立ちます。

ROIと費用便益分析の違いは何ですか？

ROIは1つの結果にすぎません。 費用便益分析 は、その元となる費用と便益を全面的に比較するものです。
