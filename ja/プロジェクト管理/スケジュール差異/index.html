スケジュール差異（SV）：計算式、例、限界

スケジュール差異（SV）は、ある時点までにプロジェクトが計画より多くの作業を完了したか少ない作業しか完了していないかを、金額で表したものです。SV = EV - PVで計算し、結果がマイナスであればプロジェクトはスケジュールより遅れています。

要点

  • SV = EV - PV。マイナスはスケジュールの遅れを意味します。
  • SVは金額で表され、完了時にはゼロに戻ります。
  • 結論を出す前に、SVだけでなくクリティカルパスも確認しましょう。
  • アーンドスケジュールはSVを時間の単位に換算します。

計算式

計算式意味
SV = EV - PV金額で表したスケジュール差異
SV% = SV / PV計画作業に対するスケジュール差異の割合
SPI = EV / PVスケジュール効率指数
結果意味
SV > 0スケジュールより前倒し
SV = 0スケジュールどおり
SV < 0スケジュール遅延

計算例

4か月目の時点で、PV = $80,000、EV = $70,000です。

  • SV = 70,000 - 80,000 = -$10,000.
  • SV% = -10,000 / 80,000 = -12.5%.
  • SPI = 70,000 / 80,000 = 0.875：チームは現時点までに計画した作業の87.5%を達成しています。

SVの限界

  • 時間ではなく金額で表される。 -$10,000という値からは、何日遅れているかはわかりません。
  • 終了時にはゼロに戻る。 すべての作業が完了すると、EV = PV = BACとなるため、プロジェクトが数か月遅れて終了したとしてもSV = 0になります。
  • クリティカルパスを考慮しない。 クリティカルでないタスクで計画より先に進んだ作業が、クリティカルなタスクの遅れを覆い隠すことがあります。参考： クリティカルパス法.
ヒント

SVは必ず、次に示されたクリティカルパスとマイルストーンの日付の確認と組み合わせましょう： ガントチャート.

アーンドスケジュール：時間単位のSV

アーンドスケジュール（ES）は、現在のEVが本来獲得されているべきだった時点を求めます。3か月目の累積PVが$50,000、4か月目が$80,000であることを使うと、$70,000のEVが計画されていた時点は次のとおりです：

  • ES = 3 + (70,000 - 50,000) / (80,000 - 50,000) = 3 + 0.67 = 3.67か月.
  • 実績時間（AT）= 4か月なので、SV(t) = 3.67 - 4 = -0.33か月 （約3分の1か月の遅れ）。
  • SPI(t) = 3.67 / 4 = 0.92.

マイナスのSVへの対処法

  1. 遅れている作業がクリティカルパス上にあるかを確認します。
  2. 原因を特定します：資源、依存関係、スコープ、サプライヤーの遅延。
  3. 検討すべき手法 スケジュール短縮: ファストトラッキングまたはクラッシング.
  4. 次を使って作業の順序を組み直すか、担当を再割り当てします： 資源平準化.
  5. 完了予定日の予測を更新し、ステークホルダーに知らせます。

よくある質問

スケジュール差異とは何ですか？

アーンドバリューと計画価値の差（SV = EV - PV）で、計画より多くの作業が行われたか少ない作業しか行われていないかを示します。

マイナスのスケジュール差異は何を意味しますか？

この時点までに完了した作業が計画より少ないため、プロジェクトはスケジュールより遅れています。

スケジュール差異はなぜ金額で測定するのですか？

アーンドバリューは作業を予算の観点で測定するからです。アーンドスケジュールはそれを時間に換算します。

SVのパーセントはどのように計算しますか？

SV% = SV / PV x 100。SVが-$10,000、PVが$80,000の場合は-12.5%です。

プロジェクトの終了時にSVがゼロになるのはなぜですか？

すべての作業が完了すると、EVはBACと等しくなり、PVも同様にBACと等しくなるため、遅れの有無にかかわらずSVはゼロになります。

SVとSPIの違いは何ですか？

SVは金額で表した差（EV - PV）、SPIは比率（EV / PV）です。

SVがプラスでもプロジェクトが遅れていることはありますか？

はい。クリティカルパス上のタスクが遅れている一方で、クリティカルでないタスクで余分な作業が進んでいる場合です。

アーンドスケジュールはスケジュール差異のどの点を改善しますか？

アーンドスケジュールはEVMを拡張したもので、現在のEVが本来いつ獲得される計画だったかを求めることで、スケジュール・パフォーマンスを金額ではなく時間で測定します。SVとは異なり、プロジェクトが完了に近づいてもゼロに戻ることはありません。

スケジュール差異はコスト差異とどう違いますか？

SV = EV - PVは完了した作業を計画した作業と比較します。CV = EV - ACは完了した作業をそのコストと比較します。

マイナスのスケジュール差異はどのように是正しますか？

クリティカルパスに注力し、障害を取り除き、ファストトラッキング、クラッシング、再計画を検討したうえで、予測を更新します。
