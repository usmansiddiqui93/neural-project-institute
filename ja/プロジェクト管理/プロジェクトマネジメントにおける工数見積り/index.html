プロジェクトマネジメントにおける工数見積り：手法と例

工数見積りは、タスクやプロジェクトに必要な作業量を人時や人日で予測するものです。工数は、スケジュール（どのくらいの期間がかかるか）と予算（どのくらいの費用がかかるか）の両方の基礎となります。

要点

  • 工数は人時で表す作業量であり、期間とコストはそこから導き出されます。
  • タスクが不確実な場合は三点見積りを使いましょう。
  • 勤務時間のすべてではなく、現実的な実働時間で計画しましょう。
  • 実績を見積りと比較し、今後の見積りを補正しましょう。

工数、期間、コストの比較

指標単位例
工数人時または人日開発に120人時
所要期間営業日または週10営業日
経過時間暦日週末を含めて暦日で14日
コスト金額120時間 x $60 = $7,200

期間は、工数と、そのタスクに取り組む人数、各人の1日あたりの実働時間によって決まります。

一般的な手法

  • 専門家の判断： 経験豊富な人が、過去に見てきたことに基づいて見積もります。
  • 類推： 類似した過去のタスクと比較して調整します。
  • パラメトリック： テストケース1件あたりやレポート1件あたりの時間など、生産性の係数を適用します。
  • 三点見積り／PERT： 不確実性を反映するため (O + 4M + P) / 6 を使います。
  • ワイドバンド・デルファイ法： グループで匿名で見積もり、相違点について話し合い、再度見積もります。
  • 相対見積り： アジャイルチームは、時間ではなく ストーリーポイント やTシャツサイズを使います。

工数見積りの手順

  1. 作業を見積もれる程度の小さなタスクに分解します。通常は1タスクあたり8〜80時間です。
  2. テストとレビューを含め、各タスクの完了の意味を明確にします。
  3. 作業を行う人に見積もってもらい、不確実性が高い場合は三点見積りを使います。
  4. スキルレベル、不慣れな技術、既知のリスクに応じて調整します。
  5. プロジェクトマネジメント、会議、手戻りの時間は、合意した水準で1回だけ加えます。
  6. 現実的な稼働状況を使って工数を期間に換算し、さらに単価を使ってコストに換算します。
  7. 見積りを記録し、後で実績と比較して改善に役立てます。

計算例

あるデータ移行は、楽観値80、最頻値110、悲観値170人時と見積もられています。

  • PERTによる工数 = (80 + 4 x 110 + 170) / 6 = 690 / 6 = 115人時.
  • 標準偏差 = (170 - 80) / 6 = 15時間。したがって、約100〜130時間が1標準偏差の範囲です。
  • 2人のアナリストの実働時間はそれぞれ1日6時間なので、1日あたり12時間です。期間 = 115 / 12 = 約9.6、つまり10営業日.
  • 平均単価$60/時間の場合、コスト = 115 x 60 = $6,900.

よくある間違い

  • 1日8時間をすべて実働時間と想定すること。
  • 工数と期間を混同し、早すぎる段階で日付を約束すること。
  • 人を増やせばタスクが比例して短くなると考えること。調整のための工数が増えます。
  • テスト、文書化、レビュー、引き継ぎを忘れること。
  • 一点見積りをコミットメントとして扱うこと。
ヒント

数週間、見積りに対する実際の工数を追跡しましょう。その比率は、手に入る中で最も有用な補正係数になります。

よくある質問

工数見積りとは何ですか？

タスクやプロジェクトを完了するために必要な作業量を、人時や人日で予測することです。

工数見積りにおける工数と期間の違いは何ですか？

工数は作業の量であり、期間は稼働時間でどのくらいかかるかです。40時間の工数は、1人なら1週間、2人なら半週間になり得ます。

工数見積りを期間に換算するにはどうすればよいですか？

工数を「人数 x 1日あたりの実働時間」で割り、さらに非稼働日を考慮します。

工数見積りにはどのような単位を使いますか？

通常は人時、人日、人月です。アジャイルチームは代わりにストーリーポイントを使うことがよくあります。

工数見積りのPERTの計算式は何ですか？

期待工数 =（楽観値 + 4 x 最頻値 + 悲観値）/ 6、標準偏差 =（悲観値 - 楽観値）/ 6。

工数見積りでは1日あたり何時間の実働時間を想定すべきですか？

組織によって異なります。多くの計画担当者は、勤務時間のすべてではなく5〜6時間程度の実働時間を想定しています。自分のチームについて測定しましょう。

ワイドバンド・デルファイ法による工数見積りとは何ですか？

専門家が匿名で見積もり、相違の理由について話し合い、見積りが収束するまで繰り返すグループ手法です。

工数見積りは誰が行うべきですか？

作業を行う人々が、プロジェクトマネージャーと過去のデータの支援を受けて行います。

工数見積りは予算にどのように使われますか？

人件費は、工数に作業を行う人の時間単価または日単価を掛けたものです。

工数見積りにおける人月とは何ですか？

1人が1か月に行う作業量です。時間数は採用する慣行によって異なるため、前提を明記しましょう。

工数見積りが外れるのはなぜですか？

タスクの漏れ、楽観、不明確な要件、作業の中断、マルチタスクが一般的な原因です。
