プロジェクトコストマネジメント：プロセス、ツール、例

プロジェクトのコストマネジメントとは、プロジェクトが承認済みの予算内で完了するよう、コストを計画、見積り、予算化、コントロールする作業です。スコープとスケジュールを金額に換算してベースラインを設定し、それに対して実際の支出を追跡することで、問題を早期に発見します。

要点

  • コストマネジメントは、コストの計画、見積り、予算設定、コントロールを扱います。
  • コストベースラインは、実績を測定する基準となる時間軸に沿った予算です。
  • アーンドバリューは、支出したお金が計画どおりの量の作業を生み出しているかを示します。
  • 超過がまだ小さいうちに見つけられるよう、早めに、頻繁に予測しましょう。

プロジェクトコストの種類

コストの種類意味例
直接費プロジェクトに直接ひも付けられる外部委託費、プロジェクト用ソフトウェアのライセンス
間接費プロジェクトに配賦される共通の間接費オフィス賃料、財務チームの作業時間
固定費作業量によって変わらない一度限りの機器購入
変動費作業量に応じて変わる時間単位の人件費、単位あたりの資材費
埋没費用すでに支出済みで回収できない中止になった設計に使った費用
機会費用断念した最善の代替案の価値実施しないことにしたプロジェクトから得られたはずの利益
ヒント

埋没費用（サンクコスト）を将来の意思決定の根拠にすべきではありません。今日から完了までにいくらかかるか、残りのベネフィットがそれに見合うかを問いましょう。

コストマネジメントの実際

  1. コストの見積り、測定、報告の方法を、コストマネジメント計画で合意する。
  2. まず WBS（ワーク・ブレークダウン・ストラクチャー） を使って作業を分解し、各ワークパッケージを見積もる。
  3. 既知のリスクに対するコンティンジェンシー予備を加え、見積りを時間軸に沿ったコストベースラインに積み上げる。
  4. スポンサーが保持するマネジメント予備を含め、資金を確保する。
  5. 作業の進行に合わせて実コストを記録し、次を使って計画と比較する： アーンドバリューマネジメント.
  6. 最終コストを予測し、是正措置を講じ、ベースラインを変更する必要がある場合は変更要求を提出します。

計算例

あるウェブサイト再構築プロジェクトのコストベースラインは、8か月にわたって$200,000です。4か月目の終わりの時点で、計画では$80,000分の作業が完了しているはずでした（計画価値）。チームは$70,000分の作業を完了しましたが（アーンドバリュー）、$85,000を支出しています（実コスト）。

  • コスト差異 = EV - AC = 70,000 - 85,000 = -$15,000 （予算超過）。
  • コスト効率指数 = EV / AC = 70,000 / 85,000 = 0.82：1ドルの支出につき、計画した作業の約82セント分しか生み出していないことになります。
  • 完成時総コスト見積り = BAC / CPI = 200,000 / 0.8235 = 約$242,857 （この効率が続いた場合）。

これでプロジェクトマネージャーは明確な早期のシグナルを得られ、超過が大きくなる前に原因を探ることができます。

ツールと技法

  • コスト見積り の手法：類推見積り、パラメトリック見積り、ボトムアップ見積り、三点見積り。
  • コンティンジェンシー予備とマネジメント予備のための予備設定分析。
  • アーンドバリューマネジメント および Sカーブ.
  • 財務評価： 費用便益分析, 正味現在価値 と 投資利益率.
  • スプレッドシート、または プロジェクト管理ソフトウェア （予算とタイムシートの機能を備えたもの）。

よくある間違い

  • スコープが明確になる前に見積もり、その見積りを約束として扱うこと。
  • 間接費、ライセンス、研修、社内スタッフのコストを含め忘れること。
  • 支出だけを追跡し、それによってどれだけの作業が得られたかを測定しないこと。
  • コンティンジェンシーを明示せず、個々の見積りの中に隠すこと。
  • コストを毎週追跡せず、月末の財務報告を待つこと。

よくある質問

プロジェクトのコストマネジメントとは何ですか？

プロジェクトが承認済みの予算内で完了するよう、プロジェクトのコストを計画、見積り、予算化、コントロールするための一連のプロセスです。

プロジェクトのコストマネジメントの4つのプロセスとは何ですか？

PMBOK第6版では、コスト・マネジメントの計画、コストの見積り、予算の設定、コストのコントロールの4つです。

プロジェクトのコストマネジメントはなぜ重要なのですか？

コストマネジメントがなければ、使いすぎに気づいたときには手遅れになりがちです。優れたコストマネジメントは早期の警告を発し、スコープや優先順位に関するより良い意思決定を支えます。

プロジェクトのコストマネジメントにおけるコストベースラインとは何ですか？

プロジェクトの作業に対する承認済みの時間軸に沿った予算で、コンティンジェンシー予備を含み、マネジメント予備は含みません。実績はこれに対して測定されます。

プロジェクトのコストマネジメントにおける予算と見積りの違いは何ですか？

見積りは、作業にかかるコストの予測です。予算は、見積りに予備を加えて作成された、承認済みの金額です。

プロジェクトのコストマネジメントにおける直接費と間接費とは何ですか？

直接費は、外部委託費のようにプロジェクトに直接ひも付けられるコストです。間接費は、オフィススペースのように共通の間接費をプロジェクトに配賦したものです。

プロジェクトのコストマネジメントは誰が担当しますか？

プロジェクトマネージャーが日々のコストを管理し、スポンサーが予算を承認してマネジメント予備を保持します。

アーンドバリューマネジメントは、プロジェクトのコストマネジメントをどのように支えますか？

計画価値、アーンドバリュー、実コストを比較して、コストとスケジュールの実績を測定します。参考： アーンドバリューマネジメント.

プロジェクトのコストマネジメントの一環として、コストはどのようにコントロールしますか？

ベースラインに対する実コストを定期的に追跡し、差異を分析し、最終コストを予測し、是正措置や変更要求を早めに行います。

アジャイルプロジェクトではプロジェクトのコストマネジメントを行いますか？

はい。アジャイルチームは多くの場合、スプリントやリリースごとにコストを固定してスコープを変動させ、詳細なタスク予算ではなく、予算消化率と提供した価値を追跡します。

プロジェクトのコストマネジメントにおけるコスト超過とは何ですか？

承認済みの予算を超えて支出することです。よくある原因は、不明確なスコープ、楽観的な見積り、スコープクリープ、不十分な追跡です。
