Sprint-Retrospektive: Ziel, Format und Moderationstipps

Die Sprint Retrospective ist die Gelegenheit des Scrum Teams, Wege zur Steigerung von Qualität und Effektivität zu planen. Sie schließt den Sprint ab, und hier findet kontinuierliche Verbesserung statt.

Verfasst vonNeural Project InstituteRedaktionsteam Projektmanagement
  • Veröffentlicht 12. September 2026
  • 3 Min. Lesezeit

Das Wichtigste in Kürze

  • Die Retrospektive verbessert Qualität und Effektivität.
  • Folgen Sie einer Struktur: Rahmen setzen, Daten sammeln, Erkenntnisse gewinnen, entscheiden, abschließen.
  • Enden Sie mit wenigen Maßnahmen mit klarer Verantwortung und verfolgen Sie sie nach.

Ziel

Das Team überprüft, wie der letzte Sprint in Bezug auf Personen, Interaktionen, Prozesse, Tools und seine Definition of Done verlaufen ist. Es identifiziert die hilfreichsten Änderungen und setzt sie so schnell wie möglich um; sie können sogar in das nächste Sprint Backlog aufgenommen werden.

Timebox

Höchstens drei Stunden bei einem einmonatigen Sprint; bei einem zweiwöchigen Sprint typischerweise etwa eine Stunde bis neunzig Minuten.

Eine fünfstufige Struktur

Die weit verbreitete Struktur von Esther Derby und Diana Larsen:

  1. Rahmen setzen: ein kurzer Check-in, damit alle früh zu Wort kommen.
  2. Daten sammeln: Was ist passiert? Nutzen Sie Fakten und Gefühle.
  3. Erkenntnisse gewinnen: Warum ist es passiert?
  4. Entscheiden, was zu tun ist: Wählen Sie ein bis drei konkrete Maßnahmen.
  5. Abschließen: einander Wertschätzung zeigen und die Retrospektive selbst bewerten.

Tipps zur Moderation

  • Wechseln Sie das Format, damit es frisch bleibt; siehe Retrospektiven-Spiele.
  • Schaffen Sie Sicherheit: Was im Raum gesagt wird, bleibt im Raum.
  • Konzentrieren Sie sich auf das System, nicht auf Schuldzuweisungen an Einzelne.
  • Nutzen Sie stilles Schreiben, damit auch ruhigere Personen gehört werden.
  • Prüfen Sie zuerst die Maßnahmen aus dem letzten Sprint.
  • Geben Sie jeder Maßnahme eine verantwortliche Person.

Verbesserungen verankern

  • Beschränken Sie Maßnahmen auf das, was das Team realistisch umsetzen kann.
  • Nehmen Sie Verbesserungen ins Sprint Backlog auf.
  • Machen Sie Maßnahmen auf dem Board sichtbar.
  • Messen Sie, ob die Änderung geholfen hat.

Häufig gestellte Fragen

Wer nimmt an der Sprint Retrospective teil?

Das Scrum Team: Product Owner, Scrum Master und Developers.

Was tun, wenn sich Retrospektiven wiederholen?

Wechseln Sie das Format, konzentrieren Sie sich auf ein bestimmtes Thema oder lassen Sie das Team moderieren. Wiederholungen bedeuten oft, dass Maßnahmen nicht umgesetzt werden.

Wie lange dauert eine Sprint Retrospective?

Höchstens drei Stunden bei einem einmonatigen Sprint. Kürzere Sprints haben meist kürzere Retrospektiven.

Wann findet die Sprint Retrospective statt?

Nach dem Sprint Review. Sie schließt den Sprint ab.

Was wird in einer Sprint Retrospective besprochen?

Wie der letzte Sprint in Bezug auf Personen, Interaktionen, Prozesse, Tools und die Definition of Done verlaufen ist, was gut lief, welche Probleme auftraten und wie sie gelöst wurden oder nicht.

Was ist das Ergebnis einer Sprint Retrospective?

Eine kleine Zahl von Verbesserungen, die so schnell wie möglich umgesetzt werden. Die wirkungsvollsten können in das Sprint Backlog des nächsten Sprints aufgenommen werden.

Wer moderiert die Sprint Retrospective?

Oft der Scrum Master, doch jedes Teammitglied kann moderieren. Eine wechselnde Moderation kann neue Perspektiven bringen.

Sollten Führungskräfte an der Sprint Retrospective teilnehmen?

Sie ist ein Event für das Scrum Team. Die Anwesenheit von Führungskräften kann die Offenheit verringern, daher werden sie meist nicht eingeladen, es sei denn, das Team wünscht es.

Was ist die Prime Directive in Retrospektiven?

Eine Aussage von Norm Kerth, die die Teilnehmenden bittet anzunehmen, dass alle mit ihrem damaligen Wissen ihr Bestes gegeben haben. Viele Teams lesen sie vor, um einen schuldfreien Ton zu setzen.

Wie viele Maßnahmen sollte eine Retrospektive hervorbringen?

Meist eine bis drei. Einige umgesetzte Verbesserungen sind mehr wert als eine lange Liste, die nie abgearbeitet wird.

Welche Retrospektiven-Formate können wir nutzen?

Start, Stop, Continue; Sailboat; 4Ls; Mad, Sad, Glad und viele andere. Siehe Retrospektiven-Spiele.
