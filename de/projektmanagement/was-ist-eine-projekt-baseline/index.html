Was ist eine Projekt-Baseline? Umfang, Termine und Kosten

Eine Baseline ist die genehmigte Version eines Plans, die eingefroren wird, damit die tatsächliche Leistung mit ihr verglichen werden kann. Projekte haben in der Regel drei: Umfang, Termine und Kosten.

Verfasst vonNeural Project InstituteRedaktionsteam Projektmanagement
  • Veröffentlicht 21. September 2026
  • 3 Min. Lesezeit

Das Wichtigste in Kürze

  • Baselines sind genehmigte Pläne, an denen die Leistung gemessen wird.
  • Projekte haben Umfangs-, Termin- und Kostenbaselines.
  • Ändern Sie sie nur über die Änderungssteuerung.

Die drei Baselines

BaselineInhalt
UmfangsbaselineUmfangsbeschreibung, Projektstrukturplan und PSP-Lexikon
TerminbaselineGenehmigte Anfangs- und Endtermine für Vorgänge und Meilensteine
KostenbaselineZeitlich verteiltes Budget ohne Managementreserve

Zusammen bilden sie die Performance Measurement Baseline, die verwendet wird für das Earned Value Management.

Eine Baseline festlegen

  1. Schließen Sie die Planung ab und lassen Sie den Plan genehmigen.
  2. Speichern Sie die Baseline in Ihrem Terminplanungstool.
  3. Kommunizieren Sie sie an Team und Stakeholder.

Die Baseline nutzen

  • Vergleichen Sie den tatsächlichen Fortschritt mit den Baseline-Terminen.
  • Berechnen Sie Termin- und Kostenabweichung; siehe Terminabweichung und Kostenabweichung.
  • Zeigen Sie Baseline-Balken in Gantt-Diagrammen an.
  • Zeigen Sie Plan und Ist auf einer S-Kurve.

Re-Baselining

Ändern Sie die Baseline nur über eine formelle Änderungssteuerung, zum Beispiel nach einer größeren genehmigten Umfangsänderung. Bewahren Sie frühere Baselines auf, damit die Historie sichtbar bleibt.

Häufig gestellte Fragen

Was ist eine Baseline im Projektmanagement?

Die genehmigte Version des Umfangs-, Termin- oder Kostenplans, an der die Leistung gemessen wird.

Warum ist eine Projekt-Baseline wichtig?

Ohne sie können Sie Abweichungen und Fortschritt nicht objektiv messen.

Wann wird die Projekt-Baseline festgelegt?

Am Ende der Planung, sobald der Plan genehmigt ist.

Was bedeutet Re-Baselining für eine Projekt-Baseline?

Die formelle Änderung der Projekt-Baseline nach einer genehmigten Änderung.

Sollten Sie die Projekt-Baseline oft ändern?

Nein. Häufiges Re-Baselining verschleiert Leistungsprobleme.

Wie hängt die Performance Measurement Baseline mit der Projekt-Baseline zusammen?

Sie besteht aus den integrierten Umfangs-, Termin- und Kostenbaselines, dem Teil der Projekt-Baseline, an dem die Leistung gemessen wird.

Ist die Managementreserve Teil der Projekt-Baseline?

Nein. Sie liegt außerhalb der Kostenbaseline im Gesamtbudget.

Wie wird eine Projekt-Baseline in einem Gantt-Diagramm dargestellt?

Als zweiter, meist grauer Balken unter jeder Aufgabe.

Nutzen agile Projekte eine Projekt-Baseline?

Nicht im klassischen Sinne; Releasepläne und Burn-up-Charts erfüllen eine ähnliche Funktion.

Welche Tools unterstützen Projekt-Baselines?

Die meisten Terminplanungstools wie Wrike, Smartsheet und die Premium-Pläne von Microsoft Planner.
