Project Scope: Definition, Scope Statement and Examples

Project scope defines all the work needed to deliver the project's product, service or result, and only that work. A clear scope prevents misunderstandings, overruns and scope creep.

Written byNeural Project InstituteProject management editorial team
  • Published 15 September 2026
  • 3 min read

Key takeaways

  • Scope defines all the work needed, and only that work.
  • Write a scope statement with explicit exclusions.
  • Control scope through formal change control.

Product scope vs project scope

Product scopeProject scope
DescribesFeatures and functions of the resultWork required to deliver the result
ExampleA website with search and checkoutDesign, build, test and launch the website

The scope statement

  • Project objectives.
  • Deliverables and acceptance criteria.
  • Inclusions: what is in scope.
  • Exclusions: what is explicitly out of scope.
  • Constraints and assumptions.

Scope management steps

  1. Plan how scope will be managed.
  2. Collect requirements.
  3. Define scope in a scope statement.
  4. Create a work breakdown structure.
  5. Validate scope: formal acceptance of deliverables.
  6. Control scope: manage changes through change control.

Example

In scope: new booking website, payment integration, staff training. Out of scope: mobile app, migrating historical bookings, marketing campaign.

Frequently asked questions

What is project scope?

All the work needed to deliver the project's result, and only that work.

What is a scope statement?

A document describing objectives, deliverables, inclusions, exclusions, constraints and assumptions.

Why list exclusions in a scope statement?

To prevent misunderstandings and scope creep.

Who approves the project scope?

The sponsor and key stakeholders.

What is project scope validation?

Formal acceptance of completed deliverables by the customer or sponsor.

What is project scope control?

Monitoring scope and managing changes to the scope baseline.

What is the project scope baseline?

The approved scope statement, WBS and WBS dictionary.

How is project scope managed in Agile?

Scope is held in a prioritised backlog and allowed to change while time and cost per iteration are fixed.

What is gold plating in project scope?

Adding features beyond what was agreed, often without the customer asking.

How does project scope relate to the triple constraint?

Changing scope usually affects time, cost or both.
