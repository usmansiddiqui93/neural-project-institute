Project Resources: Types, Planning and Management Explained

Project resources are the people, equipment, materials, facilities, services and money needed to complete a project's work. Managing them means identifying what is needed, getting it at the right time and using it efficiently.

Written byNeural Project InstituteProject management editorial team
  • Published 30 September 2026
  • 3 min read

Key takeaways

  • Resources include people, equipment, materials, facilities, services and money.
  • Plan, estimate, acquire, develop, manage and control them.
  • An RBS and resource calendars make needs and availability visible.
  • Check capacity across projects to avoid over-allocation.

The resource management processes

PMBOK 6 describes six resource management processes:

  1. Plan resource management: decide how resources will be estimated, acquired and managed.
  2. Estimate activity resources: work out what each activity needs.
  3. Acquire resources: obtain people, equipment and materials.
  4. Develop team: build skills and teamwork.
  5. Manage team: track performance, resolve issues and give feedback.
  6. Control resources: ensure physical resources are available and used as planned.

Resource breakdown structure

A resource breakdown structure (RBS) is a hierarchy of resources by category and type, for example Labour > Developers > Senior developer. It helps with estimating, costing and spotting gaps, and can be cross-referenced with the work breakdown structure.

Tips for managing resources

  • Name the people early; generic roles hide real availability problems.
  • Check availability against other projects with capacity planning.
  • Use resource allocation and resource leveling to avoid over-allocation.
  • Agree responsibilities with a RACI matrix.
  • Order long-lead equipment and materials early.
  • Release resources promptly when their work ends.

Frequently asked questions

What are project resources?

The people, equipment, materials, facilities, services and money needed to complete a project.

What are the main types of project resources?

Human resources, equipment, materials, facilities, services, information and financial resources.

What does managing project resources involve?

Planning, acquiring, deploying and controlling resources so the right ones are available when needed.

What is a resource breakdown structure for project resources?

A hierarchical list of resources by category and type, used for estimating, costing and planning.

What is a resource calendar for project resources?

A calendar showing when each resource is available, including holidays, shifts and other commitments.

What is allocation of project resources?

Assigning specific resources to tasks; see resource allocation.

What is the difference between leveling and smoothing project resources?

Leveling resolves over-allocation even if the end date moves; smoothing adjusts within float without moving the end date.

Who manages project resources?

The project manager, working with functional or resource managers who own the people and equipment.

How do you estimate project resource needs?

Break down the work, decide which skills and equipment each activity needs and how much, using past data and expert judgment.

What happens if project resources are over-allocated?

Work slips, quality drops and people burn out. Re-plan using leveling or by adding capacity.
