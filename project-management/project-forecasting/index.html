Project Forecasting: Methods for Predicting Cost and Dates

Project forecasting is predicting where a project will end up, mainly its final cost and completion date, based on performance so far and the work remaining. Good forecasts give sponsors early, honest warning so they can make decisions while there is still time.

Written byNeural Project InstituteProject management editorial team
  • Published 30 September 2026
  • 3 min read

Key takeaways

  • Forecast both final cost and completion date.
  • Use formulas as a start, then validate with the team.
  • Present ranges with confidence levels.
  • Update forecasts every period and report them honestly.

What to forecast

  • Final cost: estimate at completion.
  • Cost to finish: estimate to complete (ETC).
  • Completion date: when the last deliverable will be done.
  • Resource needs: people and skills needed for the remaining work.
  • Benefits: whether the expected value will still be delivered.

Forecasting methods

MethodHow it worksStrength
Earned value formulasEAC = BAC / CPI and variantsQuick, objective, uses trend data
Earned scheduleDuration forecast = planned duration / SPI(t)Gives a time forecast
Bottom-up re-estimateRe-estimate all remaining workReflects current knowledge
Critical path analysisUpdate the schedule networkShows the real driving tasks
Monte Carlo simulationRuns many scenarios from rangesGives probabilities, e.g. 80% confidence
Agile throughput or velocityRemaining backlog / average velocitySimple for iterative work; see velocity

Worked example

BAC = $200,000, planned duration 8 months. At month four: EV = $70,000, AC = $85,000, CPI = 0.8235, SPI = 0.875, and earned schedule SPI(t) = 0.917.

ForecastCalculationResult
EAC (cost)200,000 / 0.8235$242,857
ETC242,857 - 85,000$157,857
Duration (simple SPI)8 / 0.8759.1 months
Duration (earned schedule)8 / 0.9178.7 months

The two duration forecasts give a range of roughly 8.7 to 9.1 months. The project manager checks the critical path to see which is more realistic before reporting.

How to produce a reliable forecast

  1. Make sure actual costs and progress data are current and accurate.
  2. Calculate formula-based forecasts as a starting point.
  3. Ask the team to re-estimate remaining work where the plan has changed.
  4. Factor in open risks and pending change requests.
  5. Present a range with a confidence level, not a single point.
  6. Explain the drivers and the actions that could improve the outcome.

Common mistakes

  • Forecasting what the sponsor wants to hear.
  • Assuming the project will recover without a reason to believe it.
  • Forecasting cost without forecasting dates, or the reverse.
  • Updating forecasts too rarely.
  • Ignoring committed costs and pending changes.

Frequently asked questions

What is project forecasting?

Predicting a project's final cost, completion date and other outcomes from performance to date and the work remaining.

How does project forecasting predict final cost?

Use earned value formulas such as EAC = BAC / CPI, and cross-check with a bottom-up estimate of remaining work.

How does project forecasting predict a completion date?

Update the schedule and critical path, or use earned schedule: planned duration / SPI(t).

What is the difference between a project forecast and an estimate?

Estimates are made before work starts; forecasts update predictions using actual performance.

How often should project forecasts be updated?

Every reporting period, and whenever a significant change or risk occurs.

What is a Monte Carlo project forecast?

A simulation that runs thousands of scenarios from estimate ranges to show the probability of finishing by a date or within a cost.

How does project forecasting work in Agile teams?

By dividing the remaining backlog by recent velocity or throughput, often shown as a range.

Why present a project forecast as a range rather than a single figure?

Because the future is uncertain. A range with a confidence level is more honest and more useful.

What is ETC in project forecasting?

Estimate to complete: the expected cost of the remaining work, ETC = EAC - AC.

What tools support project forecasting?

Spreadsheets, scheduling tools and project management software with earned value or burn-up reports.
