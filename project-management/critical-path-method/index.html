Critical Path Method (CPM): Steps, Example and Formulas

The critical path method (CPM) is a scheduling technique that finds the longest sequence of dependent activities in a project. That sequence, the critical path, sets the shortest possible project duration, and any delay to a critical activity delays the whole project unless you recover the time.

Written byNeural Project InstituteProject management editorial team
  • Published 24 September 2026
  • 3 min read

Key takeaways

  • CPM finds the longest path, which sets the minimum project duration.
  • Forward and backward passes give early and late dates; zero float means critical.
  • Only shortening critical activities shortens the project.
  • Recalculate after every update because the critical path can move.

Key terms

TermMeaning
Early start (ES)Earliest an activity can start
Early finish (EF)ES + duration
Late start (LS)Latest an activity can start without delaying the project
Late finish (LF)Latest it can finish without delaying the project
Total floatLS - ES (or LF - EF); see float and slack
Critical pathThe path with zero total float in a normal schedule

Steps of the critical path method

  1. List the activities and their durations.
  2. Identify the dependencies between them.
  3. Draw a network diagram.
  4. Do a forward pass to find ES and EF for every activity.
  5. Do a backward pass to find LS and LF.
  6. Calculate total float for each activity.
  7. The activities with zero total float form the critical path. Highlight them on the Gantt chart.

Worked example

Activities (duration, predecessors): A 3 days (none), B 4 days (A), C 2 days (A), D 5 days (B), E 3 days (C), F 2 days (D and E). Day 0 is the project start.

The critical path is A-B-D-F with a duration of 14 days. The other path, A-C-E-F, takes 10 days, so C and E can share 4 days of float. The calculation is explained step by step in forward and backward pass.

CPM vs PERT vs critical chain

CPMPERTCritical chain
DurationsSingle estimateThree estimates, weighted averageAggressive estimates plus buffers
FocusLogic and floatUncertainty in durationResource limits and buffer management
Typical useConstruction, engineering, most projectsResearch and novel workMulti-project, resource-constrained environments

Managing the critical path

  • Focus monitoring and risk management on critical and near-critical activities (those with little float).
  • Recalculate after every update: the critical path can move as work progresses.
  • To shorten the project, you must shorten critical activities; see schedule compression.
  • Watch for multiple critical paths, which increase the chance of delay.
  • Remember that CPM assumes unlimited resources; resource levelling can lengthen the path.
Tip

Shortening a non-critical activity does not shorten the project. Always check the path before spending money to speed things up.

Frequently asked questions

What is the critical path in project management?

The longest sequence of dependent activities from start to finish. It determines the shortest time in which the project can be completed.

How do you calculate the critical path?

Do a forward pass to get early dates, a backward pass to get late dates, then find the activities with zero total float.

Can a project have more than one critical path?

Yes. When two or more paths have the same longest duration, they are all critical, which raises schedule risk.

What is total float on the critical path?

The amount of time an activity can be delayed without delaying the project finish, calculated as LS - ES.

Does the critical path change?

Yes. If non-critical activities slip enough to use up their float, or critical ones finish early, a different path can become critical.

Can an activity on the critical path have negative float?

Yes, if the schedule is already behind a required finish date. Negative float shows how much time must be recovered.

Who developed the critical path method?

CPM was developed in the late 1950s in the United States for planning large industrial projects.

What is the difference between CPM and PERT?

CPM uses single duration estimates; PERT uses three estimates to reflect uncertainty. See PERT chart.

What is a near-critical path?

A path with only a little float. It can become critical with a small delay, so it deserves close watching.

How do I shorten the critical path?

Use crashing or fast tracking, reduce scope, or change the logic. Only changes to critical activities shorten the project.
