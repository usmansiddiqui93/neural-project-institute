Cost Performance Index (CPI): Formula, Examples, Meaning

The cost performance index (CPI) measures a project's cost efficiency: how much budgeted work you get for each unit of money you spend. It is calculated as CPI = EV / AC, so a CPI of 0.90 means you are getting 90 cents of planned work for every dollar spent. This guide covers the formula, how to read the result, cumulative and period CPI, forecasting with CPI and a worked example in which a healthy-looking project CPI hides a real problem.

Key takeaways

  • CPI = EV / AC. Below 1 means over budget for the work done; above 1 means under budget.
  • A CPI of 0.85 means each unit of work costs about 18% more than planned (1 / 0.85), not 15%.
  • Calculate the project CPI as total EV divided by total AC. Never average the CPIs of work packages.
  • Watch period CPI to spot changes quickly; use cumulative CPI for forecasts such as EAC = BAC / CPI.
  • A good project CPI can hide poor packages, so check CPI by work package and by cost type.
  • Compare CPI with the TCPI to judge whether a budget is still achievable.

What is the cost performance index (CPI)?

The cost performance index (CPI) is an earned value management measure of cost efficiency. It divides the earned value of work completed (EV) by the actual cost of that work (AC). A CPI of 1.0 means the work has cost exactly what was budgeted; below 1.0 means it has cost more, and above 1.0 means it has cost less.

CPI is one of the core indicators in earned value management (EVM), alongside cost variance, schedule variance and the schedule performance index (SPI). Because it is a ratio rather than a money amount, it lets you compare the efficiency of work packages and projects of very different sizes.

In older EVM material and many government contracts, the inputs have different names. Earned value is the budgeted cost of work performed (BCWP) and actual cost is the actual cost of work performed (ACWP), so you will also see the formula written as CPI = BCWP / ACWP.

Tip

The project cost performance index has nothing to do with the consumer price index, the inflation measure that shares the CPI abbreviation. If a report mixes inflation and cost efficiency, spell out both names.

The CPI formula

FormulaWhat it shows
CPI = EV / ACCost efficiency of the work done to date
EV = % complete x BACEarned value: the budget for the work actually completed
Cumulative CPI = total EV to date / total AC to dateEfficiency since the project started; used for forecasting
Period CPI = EV this period / AC this periodEfficiency in one month or sprint; shows recent change
Project CPI = sum of package EVs / sum of package ACsThe correct way to roll package figures up
1 / CPIActual cost per unit of planned cost, for example 1 / 0.85 = 1.18

BAC is the budget at completion, the total approved budget for the work. AC must cover the same work and the same period as EV, including accruals for work done but not yet invoiced.

How to calculate CPI step by step

  1. Choose the status date and use it for both progress and costs.
  2. Take the BAC for each work package from the current approved cost baseline, including approved changes but excluding management reserve.
  3. Measure percent complete using agreed rules (0/100, 50/50, weighted milestones or units completed), not personal judgement.
  4. Calculate EV for each package: % complete x BAC.
  5. Collect AC for each package, including accrued labour and supplier costs.
  6. Divide EV by AC for each package to get the package CPI.
  7. Add up EV and AC across all packages and divide the totals to get the project CPI.
  8. Compare with last period and with your thresholds, and note any package that is moving the total.

Quick example. A website rebuild has a BAC of $120,000. It is 40% complete, so EV = 0.40 x 120,000 = $48,000. Actual cost to date is $54,000. CPI = 48,000 / 54,000 = 0.89. The team is getting about 89 cents of planned work for every dollar spent.

Converting CPI into an overrun percentage

A common shortcut is to read a CPI of 0.85 as a "15% overrun". That is not quite right. A CPI of 0.85 means you get 0.85 units of planned work per unit of money, so each unit of planned work costs 1 / 0.85 = 1.176, a 17.6% overrun. The gap grows as CPI falls. Worked example: packaging line upgrade

A food manufacturer is upgrading a packaging line. The BAC is $500,000 across five work packages. At the end of month six, planned value (PV) is $345,000. Here is the status:

Work packageBAC% completeEVACCVCPI
1. Engineering design$80,000100%$80,000$76,000+$4,0001.05
2. Equipment purchase$220,00080%$176,000$171,000+$5,0001.03
3. Installation$120,00035%$42,000$56,000-$14,0000.75
4. Controls software$50,00040%$20,000$26,000-$6,0000.77
5. Commissioning and training$30,0000%$0$0$0-
Total$500,00064%$318,000$329,000-$11,0000.97

The project-level reading

  • CPI = 318,000 / 329,000 = 0.97. On its own, this looks close to plan.
  • SPI = 318,000 / 345,000 = 0.92. The project is somewhat behind schedule.
  • EAC = BAC / CPI = 500,000 / 0.967 = about $517,300, a forecast overrun of around $17,300 (3.5%).

A sponsor reading only the headline would conclude the project is slightly over budget and nothing more.

What the packages reveal

The good CPIs come from design and equipment purchase, which are mostly finished and made up of fixed-price purchases. The work that is still ahead is labour-heavy: installation (CPI 0.75) and controls software (CPI 0.77), plus commissioning, which uses the same installation crews. The early, efficient packages are flattering the total.

The package-level forecast is $544,750, an overrun of nearly $45,000 (9%), compared with about $17,300 from the project-level formula. If commissioning runs at the same 0.75 as installation, the forecast rises to $554,750. The project CPI was not wrong, but it was averaging good past work with poor future work.

Tip

When the remaining work is different in kind from the completed work, forecast by package or by cost type (labour, materials, subcontract), not with a single project CPI.

Why you must never average package CPIs

A simple average of the four package CPIs is (1.05 + 1.03 + 0.75 + 0.77) / 4 = 0.90. The correct project CPI is total EV divided by total AC: 318,000 / 329,000 = 0.97. The simple average gives a small package such as controls software the same weight as a large one such as equipment purchase. Always add up EV and AC first, then divide. The same rule applies when rolling projects up to a programme or portfolio.

Cumulative vs period CPI

The cumulative CPI includes everything since the project started. The period CPI looks at one month on its own. Here are both for the packaging line:

MonthEV this monthAC this monthPeriod CPICumulative EVCumulative ACCumulative CPI
1$30,000$29,0001.03$30,000$29,0001.03

Installation started in month five. The period CPI fell to 0.88 and then 0.75, while the cumulative CPI was still above 1.0 in month five. Anyone watching only the cumulative figure would have seen "slightly under budget" one month and "slightly over" the next, and missed how fast the current work was deteriorating.

  • Use period CPI to spot changes early and to check whether corrective actions are working.
  • Use cumulative CPI for forecasts, because a single month is easily distorted by a large invoice or a late accrual.
  • Plot both, or plot cumulative EV and AC as an S-curve, where a widening gap between the lines shows the same story.

Using CPI to forecast the final cost

CPI is the main input to the estimate at completion (EAC). Which formula you use depends on what you believe about future performance.

EAC formulaPackaging line resultUse when
EAC = BAC / CPI500,000 / 0.967 = $517,300Current cost efficiency is expected to continue
EAC = AC + (BAC - EV)329,000 + 182,000 = $511,000The variance so far was a one-off; the rest will go to plan
EAC = AC + (BAC - EV) / (CPI x SPI)329,000 + 182,000 / 0.891 = $533,300Schedule pressure will also push costs up
Bottom-up by package$544,750Remaining work differs from completed work, as here

Present a range rather than a single number when the methods disagree, and explain which one you believe and why. Our guide to project forecasting covers how to present forecasts to sponsors.

CPI and the to-complete performance index (TCPI)

The TCPI is the cost efficiency you would need on the remaining work to hit a target: TCPI = (BAC - EV) / (BAC - AC). For the packaging line, (500,000 - 318,000) / (500,000 - 329,000) = 182,000 / 171,000 = 1.06.

To finish on budget, the remaining work would need a CPI of 1.06, while the work in progress is running at about 0.75. Unless something changes fundamentally, the original budget is not achievable, and the sponsor should hear that now. Our working rule: whenever the TCPI is noticeably above the current cumulative CPI (by 0.05 or more), the report should explain what will make the remaining work more efficient, or the target should be revisited.

CPI and SPI together

CPI tells you about cost; the schedule performance index (SPI = EV / PV) tells you about progress. Read them together.

SPI above 1SPI below 1
CPI above 1Ahead of schedule and under budget. Check the data is rightUnder budget but behind schedule. Is work being delayed rather than done cheaply?
CPI below 1Ahead of schedule but over budget. Are you paying for speed?Behind schedule and over budget. The most serious position: recovering time usually costs more

Some organisations multiply the two: CPI x SPI, sometimes called the critical ratio. For the packaging line, 0.967 x 0.922 = 0.89. A value well below 1 suggests both cost and schedule are under pressure, and it is the divisor in the third EAC formula above.

Bear in mind that SPI based on money drifts back towards 1.0 at the end of a project whether or not it is late, because all planned work is eventually earned. CPI does not have this problem.

CPI and CV always point in the same direction: a negative CV means a CPI below 1. Report both. CV shows the amount at stake and CPI shows the efficiency, which is easier to compare between projects.

What is a good CPI?

A CPI close to 1.0 is the goal. There is no universal standard for acceptable limits; they depend on estimate accuracy, contract type and the organisation's appetite for risk, and they should be set in the cost management plan. As an illustration only:

StatusExample CPI rangeTypical response
Green0.95 to 1.05Report as normal
Amber0.90 to 0.95, or 1.05 to 1.10Explain the variance and set out an action plan
RedBelow 0.90, or above 1.10Escalate, revise the EAC and consider a change request

Whatever bands you choose, show the CPI trend and a one-line explanation in every project status report, so readers see the direction as well as the number.

Note the upper band. A CPI well above 1 is not automatically good news. It can mean that invoices or timesheets are missing, that progress is overstated, that the estimates were padded, or that cheap work has been done first and the expensive work is still ahead. Persistent high CPIs also tie up budget that the wider portfolio could use.

Does CPI stabilise early? The 20% rule

You may hear that "once a project is 20% complete, the CPI will not change much". This comes from research on large US defence contracts. Christensen and Heise (1993) studied 155 Department of Defense contracts and concluded that the cumulative CPI was stable from the 20% completion point on most of them, where stability meant the CPI stayed within a range of less than 0.20. In their data, 134 of the 155 contracts met that test at 20% complete. Where the CPI did change, it tended to get worse rather than better.

The rule has since been widely over-applied. Later commentary, such as Mosaic Projects' paper on the "CPI stability myth" citing Henderson and Zwikael (2008), argues that stability is not something to rely on, especially on smaller commercial projects. Part of the effect is also arithmetic: as more work is completed, each new month moves the cumulative ratio less.

The practical lessons are:

  • An early low CPI is a serious warning. Do not assume it will recover on its own.
  • Act early. The further a project progresses, the less any action can move the cumulative CPI.
  • Do not stop managing after 20%. A change in the CPI trend usually means something on the project has changed.
  • Use the TCPI to judge whether recovery is realistic, rather than hoping the CPI will drift back.

How to improve a low CPI

  1. Validate the data. Check progress claims and make sure AC includes accruals and nothing from other projects.
  2. Find the packages and cost types driving the result. A detailed work breakdown structure makes this possible. Look at package CPIs and, where possible, labour versus materials versus subcontract.
  3. Separate price from quantity. Are you paying more per hour or unit, or using more hours or units than planned?
  4. Identify the root cause with the people doing the work. A fishbone diagram helps when causes are mixed.
  5. Decide whether the cause will continue, and update the EAC on that basis.
  6. Act on the remaining work: fix sequencing and rework, change the resource mix, renegotiate rates or use value engineering.
  7. Raise a change request if scope or the baseline must change, through change control.
  8. Watch the period CPI over the next one or two cycles to confirm the actions are working.

CPI in Agile projects

Agile teams can calculate CPI at release level. Use the release budget as BAC, the share of planned story points completed as percent complete, and the team's cost to date as AC.

Example. A team costs $25,000 per sprint, and a 12-sprint release has a budget of $300,000 and 240 story points. After five sprints, the team has completed 110 points and spent $125,000.

  • EV = 110 / 240 x 300,000 = $137,500.
  • CPI = 137,500 / 125,000 = 1.10: the team is delivering more points per dollar than planned.
  • Now the product owner adds 30 points of new scope without changing the budget. Percent complete becomes 110 / 270, so EV falls to $122,222 and CPI to 0.98, even though nothing about the team's efficiency has changed.

The lesson is that in Agile, scope changes to the backlog must be matched by a decision about the release budget, or the CPI stops measuring efficiency. Pair it with velocity; see our guides to Scrum velocity and Agile metrics and KPIs.

How to calculate CPI in Excel or Google Sheets

Set up one row per work package with these columns:

ColumnHeadingFormula (row 2)
AWork packageText
BBACValue from the baseline
C% completeValue, for example 35%
DEV=B2*C2
EACValue from timesheets and invoices
FCV=D2-E2
GCPI=IFERROR(D2/E2,"-")

For the project total, use =SUM(D2:D6)/SUM(E2:E6), not =AVERAGE(G2:G6). For the period CPI, keep last month's cumulative EV and AC in two extra columns and divide the differences. Conditional formatting on column G against your thresholds turns the sheet into a simple traffic-light report. Common CPI mistakes

  • Averaging package CPIs instead of dividing total EV by total AC.
  • Mismatched data: EV at one status date and AC at another, or AC missing accruals.
  • Subjective percent complete, which inflates EV and the CPI with it.
  • Reading 1 - CPI as the overrun. Use 1 / CPI - 1 instead.
  • Relying on one month's figure. Look at the trend over several periods.
  • Trusting a good project CPI without checking packages and cost types.
  • Ignoring committed costs, such as purchase orders that will overrun a package with a healthy CPI today.
  • Including management reserve in BAC, which blurs the measure of performance against the baseline.

Frequently asked questions

What is the cost performance index?

The cost performance index (CPI) is an earned value measure of cost efficiency. It compares the budgeted value of the work completed with what that work actually cost: CPI = EV / AC.

What is the formula for CPI?

CPI = EV / AC, where EV is earned value (percent complete x budget at completion) and AC is the actual cost of the work completed. In older terms, CPI = BCWP / ACWP.

What does a CPI of 1 mean?

The work completed has cost exactly what was budgeted for it, so the project is on budget for the work done.

What does a CPI below 1 mean?

The work completed has cost more than its budget. For example, a CPI of 0.90 means the project is getting 90 cents of planned work for every dollar spent.

What does a CPI of 0.8 mean?

Each dollar is buying 80 cents of planned work, so each unit of work costs 1 / 0.8 = 1.25 times its budget. If that continues, the project will finish 25% over budget: a $500,000 budget becomes $625,000.

Is a CPI above 1 always good?

No. It can mean genuine efficiency, but it can also mean missing costs, overstated progress, padded estimates or expensive work still to come. Investigate high CPIs as well as low ones.

What is a good CPI?

A CPI close to 1.0. Organisations set their own limits in the cost management plan, for example treating 0.95 to 1.05 as acceptable and escalating below 0.90. There is no universal standard.

What is the difference between CPI and SPI?

CPI = EV / AC measures cost efficiency. SPI = EV / PV measures schedule efficiency: how much of the planned work has been done. Both use earned value, and they should be read together.

What is the difference between CPI and cost variance?

Both use EV and AC. Cost variance is the difference in money (EV - AC); CPI is the ratio (EV / AC). A negative cost variance always means a CPI below 1.

How do you forecast EAC using CPI?

The most common formula is EAC = BAC / CPI, which assumes current cost efficiency continues. With a BAC of $500,000 and a CPI of 0.967, EAC is about $517,300. Other formulas use CPI x SPI or a bottom-up re-estimate.

Should I use cumulative or period CPI?

Use both. Cumulative CPI is more stable and is used for forecasts. Period CPI shows recent performance and reveals problems, or improvements, much sooner.

What is TCPI and how is it different from CPI?

CPI looks back at efficiency achieved so far. TCPI looks forward: the efficiency needed on the remaining work to meet a target, TCPI = (BAC - EV) / (BAC - AC). If TCPI is well above CPI, the target is unlikely to be met.

Does CPI stabilise after 20% complete?

Research on large US defence contracts (Christensen and Heise, 1993) found that cumulative CPI was usually stable from about 20% complete. Later work questions how far this applies to other projects, so treat it as a warning to act early, not a guarantee.

Is the cost performance index the same as the consumer price index?

No. Both are abbreviated to CPI, but the consumer price index measures inflation in an economy, while the cost performance index measures cost efficiency on a project.
