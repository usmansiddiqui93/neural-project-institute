What Is a Work Package in Project Management?

A work package is the lowest level of the work breakdown structure: a piece of work small enough to estimate reliably, assign to one owner and track to completion.

Written byNeural Project InstituteProject management editorial team
  • Published 17 September 2026
  • 3 min read

Key takeaways

  • A work package is the lowest WBS level.
  • Use the 8/80 rule as a guide to size.
  • Each has one owner, acceptance criteria and estimates.

Characteristics of a good work package

  • One clear owner.
  • A defined deliverable and acceptance criteria.
  • Reliable estimates of effort, duration and cost.
  • Clear start and finish.
  • Fits within a reporting period where possible.

The 8/80 rule

A common guideline is that a work package should take between 8 and 80 hours of effort. Smaller packages add administrative overhead; larger ones are hard to estimate and track.

Frequently asked questions

What is a work package?

The lowest level of the WBS, which can be estimated, owned and tracked.

What is the 8/80 rule for work packages?

A guideline that work packages should take 8 to 80 hours of effort.

Who owns a work package?

One named person, though several people may work on it.

Is a work package the same as a task?

No. Work packages are deliverable-based; tasks or activities are the steps to produce them.

How does a control account relate to a work package?

A management point above work packages where scope, budget and schedule are integrated for earned value.

How are work packages estimated?

Using analogous, parametric or bottom-up estimation; see cost estimation.

What is the difference between a planning package and a work package?

A planning package is a WBS element with known scope but not yet detailed into work packages.

In PRINCE2, what is a work package?

An authorisation given to a team manager to deliver specific products.

How many work packages should a project have?

As many as needed to cover the scope at a manageable level of detail.

Do work packages need acceptance criteria?

Yes, so everyone knows when the work is done.
