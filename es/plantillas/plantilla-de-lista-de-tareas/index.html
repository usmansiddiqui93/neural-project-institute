Plantilla gratuita de lista de tareas (diaria y semanal) para Sheets, Excel y PDF

Una plantilla de lista de tareas reúne sus tareas en un solo lugar con prioridades, fechas de vencimiento y estado, para que siempre sepa qué hacer a continuación. Incluye una lista de tareas continua y un planificador semanal de tareas que puede imprimir.

Qué incluye

  • Una lista de tareas continua con casilla de verificación, categoría, prioridad, fecha de vencimiento, tiempo, estado y notas
  • Un planificador semanal de tareas
  • Lista de verificación de tareas imprimible en PDF
  • Lista de tareas: ¿Hecho?, Tarea, Categoría, Prioridad, Fecha de vencimiento, Tiempo estimado, Estado, Notas
  • Planificador semanal: Día, 3 prioridades principales, Otras tareas, Hecho

Cómo usar la plantilla de lista de tareas

  1. Anote todas las tareas y empiece cada una con un verbo.
  2. Fije una prioridad y una fecha de vencimiento; añada una estimación de tiempo para las tareas más grandes.
  3. Cada mañana, elija sus tres tareas principales de la lista (o use el planificador semanal).
  4. Marque las tareas a medida que las termine.
  5. Revise la lista cada semana: elimine, delegue o reprograme los elementos antiguos.

Consejos para aprovecharla al máximo

  • Divida las tareas grandes en pasos que pueda terminar en menos de una hora.
  • Haga primero la tarea de alta prioridad más difícil.
  • Mantenga una sola lista, no varias.
  • Para el trabajo compartido, use una plantilla de seguimiento de proyectos.

Preguntas frecuentes

¿Qué es una plantilla de lista de tareas?

Una plantilla de lista de tareas es una lista ya preparada para registrar tareas con prioridades, fechas de vencimiento y estado, de modo que pueda planificar y dar seguimiento a su trabajo.

¿Es gratuita esta plantilla de lista de tareas?

Sí. La plantilla de lista de tareas es gratuita en Google Sheets, Excel y PDF.

¿Hay una plantilla de lista de tareas semanal?

Sí. La pestaña Planificador semanal es una plantilla de lista de tareas semanal con las tres prioridades principales de cada día.

¿Puedo usar la plantilla de lista de tareas como lista diaria?

Sí. Filtre por la fecha de vencimiento de hoy o use el planificador semanal como lista de tareas diaria.

¿Puedo imprimir la plantilla de lista de tareas?

Sí. Descargue el PDF para obtener una plantilla de lista de verificación de tareas imprimible.

¿Cómo priorizo las tareas en la plantilla de lista de tareas?

Asigne una prioridad Alta, Media o Baja y ordene la lista de tareas por prioridad y, después, por fecha de vencimiento.

¿Hay una plantilla de lista de tareas en Excel?

Sí. Descargue la plantilla de lista de tareas en .xlsx con listas desplegables y filtros.

¿Puedo usar la plantilla de lista de tareas de Google Sheets en mi teléfono?

Sí. Haga una copia de la plantilla de lista de tareas de Google Sheets y use la aplicación de Sheets.

¿Cuál es la diferencia entre una plantilla de lista de tareas personal y una de tareas de equipo?

Es la misma idea; una plantilla de lista de tareas de equipo puede añadir responsables para su uso en grupo, como en nuestra plantilla de seguimiento de proyectos.

¿Pueden los equipos compartir una plantilla de lista de tareas?

Sí. Añada una columna Responsable o use, de forma compartida, una plantilla de tablero Kanban.

¿Cuál es la diferencia entre las plantillas de lista de tareas para principiantes, avanzada y para expertos?

La plantilla de lista de tareas para principiantes conserva solo las columnas esenciales en una pestaña; la versión avanzada es la plantilla completa con todas las pestañas, listas desplegables y fórmulas; la versión para expertos añade instrucciones, un panel que resume sus datos automáticamente, colores de estado y un historial de revisiones.
