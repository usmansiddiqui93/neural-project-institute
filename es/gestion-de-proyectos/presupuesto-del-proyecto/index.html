Presupuesto del proyecto: cómo crearlo, con un ejemplo

El presupuesto de un proyecto es la financiación total aprobada para un proyecto, desglosada por trabajo y por tiempo. Se elabora a partir de las estimaciones de costos, más reservas para contingencias para los riesgos conocidos y una reserva de gestión para los desconocidos.

  • Publicado 28 de septiembre de 2026
  • 3 min de lectura

Puntos clave

  • El presupuesto se compone de las estimaciones del trabajo, la contingencia y la reserva de gestión.
  • La línea base de costos (BAC) es aquello con lo que se compara el desempeño.
  • Distribuya el presupuesto en el tiempo para poder hacer el seguimiento del flujo de caja y del avance.
  • Modifique la línea base solo mediante el control formal de cambios.

Qué incluye el presupuesto de un proyecto

  • Mano de obra: tiempo del personal interno y contratistas.
  • Materiales, equipos, software y licencias.
  • Instalaciones, viajes y formación.
  • Costos de proveedores y subcontratas; consulte adquisiciones.
  • Costos indirectos o gastos generales, si la organización los imputa.
  • Reserva para contingencias para los riesgos identificados.
  • Reserva de gestión para trabajo imprevisto dentro del alcance.

Cómo se compone el presupuesto

NivelQué contieneQuién lo controla
Estimaciones de las actividadesCosto de cada actividadTeam
Estimaciones de los paquetes de trabajoActividades consolidadasResponsable de la cuenta de control
Reserva para contingenciasDinero para los riesgos identificados (incógnitas conocidas)Director del proyecto
Línea base de costosPaquetes de trabajo + contingencia, distribuidos en el tiempoDirector del proyecto
Reserva de gestiónDinero para las incógnitas desconocidasPatrocinador
Presupuesto del proyectoLínea base de costos + reserva de gestiónPatrocinador / organización

La línea base de costos es también el presupuesto hasta la conclusión que se utiliza en el valor ganado.

Cómo elaborar el presupuesto de un proyecto

  1. Parta de una alcance y estructura de desglose del trabajo.
  2. Estime el costo de cada paquete de trabajo; consulte estimación de costos.
  3. Añada contingencia en función del análisis de riesgos.
  4. Distribuya los costos en el tiempo según el cronograma para crear una línea base distribuida en el tiempo y una curva S.
  5. Añada la reserva de gestión y compruebe los límites de financiación y el flujo de caja.
  6. Consiga la aprobación del presupuesto y establezca su línea base.
  7. Haga un seguimiento de los costos reales frente a ella y modifíquela solo mediante el control de cambios.

Ejemplo resuelto

ElementoImporte
Paquetes de trabajo (diseño, construcción, pruebas, implantación)$180,000
Reserva para contingencias para los riesgos identificados$20,000
Línea base de costos (BAC)$200,000
Reserva de gestión$15,000
Presupuesto total del proyecto$215,000

Si se produce un riesgo identificado, el director del proyecto recurre a la contingencia de $20,000. Si aparece trabajo imprevisto dentro del alcance, el patrocinador puede liberar reserva de gestión, que entonces aumenta la línea base de costos mediante una solicitud de cambio.

Consejos para gestionar un presupuesto

  • Revise los costos reales cada semana, no solo a final de mes.
  • Use la valor ganado, y no solo el gasto, para evaluar el desempeño.
  • Acuerde umbrales de control; por ejemplo, un CPI inferior a 0.95 desencadena una revisión.
  • Registre por qué se utilizaron las reservas, para las lecciones aprendidas.
  • Compruebe el calendario de financiación para que el dinero esté disponible cuando se necesite.

Preguntas frecuentes

¿Qué es el presupuesto de un proyecto?

La financiación total aprobada para un proyecto, elaborada a partir de las estimaciones de costos más las reservas para contingencias y de gestión, y distribuida en el tiempo.

¿Cuál es la diferencia entre la línea base de costos y el presupuesto del proyecto?

La línea base de costos incluye las estimaciones del trabajo y la reserva para contingencias. El presupuesto del proyecto añade además la reserva de gestión.

¿Qué es la reserva para contingencias en el presupuesto de un proyecto?

Dinero reservado para los riesgos identificados, que forma parte de la línea base de costos y que normalmente controla el director del proyecto.

¿Qué es la reserva de gestión en el presupuesto de un proyecto?

Dinero para trabajo imprevisto dentro del alcance. Queda fuera de la línea base de costos y lo controla el patrocinador o la dirección.

¿Cómo se elabora el presupuesto de un proyecto?

Estime cada paquete de trabajo, añada la contingencia, distribúyala en el tiempo según el cronograma, añada la reserva de gestión y consiga su aprobación.

¿Cuánta contingencia debe tener el presupuesto de un proyecto?

Debe derivarse del análisis de riesgos y no de una regla fija. Los proyectos más arriesgados y peor definidos necesitan más.

¿Qué es un presupuesto del proyecto distribuido en el tiempo?

Un presupuesto que muestra cuánto está previsto gastar en cada periodo. Representado de forma acumulada, forma una curva S.

¿Quién aprueba el presupuesto del proyecto?

Normalmente el patrocinador del proyecto o un comité de gobernanza, de acuerdo con los niveles de autoridad financiera de la organización.

¿Puede cambiar el presupuesto de un proyecto?

Sí, pero solo mediante un control de cambios, actualizando la línea base una vez aprobado el cambio.

¿Qué es el presupuesto hasta la conclusión en el presupuesto de un proyecto?

La línea base de costos total del trabajo, que se escribe BAC. Excluye la reserva de gestión.

¿Qué herramientas ayudan a gestionar el presupuesto de un proyecto?

Las hojas de cálculo sirven para proyectos pequeños; los más grandes utilizan software de gestión de proyectos o sistemas financieros con partes de horas y seguimiento del presupuesto.
