敏捷项目组合管理：使战略与交付保持一致

敏捷项目组合管理将敏捷和精益思维应用于“组织应该投资什么”这一问题。它将战略与敏捷团队的工作联系起来，让资金跟随实证流动，而不是在年度计划中一成不变。

作者Neural Project Institute项目管理编辑团队

  • 阅读时长 3 分钟

要点总结

  • 敏捷项目组合管理为价值流提供资金，并根据实证调整投资。
  • 项目组合 Kanban 和 WIP 限制可防止同时启动过多工作。
  • WSJF 按延迟成本除以作业规模来排定优先级。

关键实践

  • 精益预算： 为长期存在的价值流或团队提供资金，并让它们在护栏内自行决定如何使用。
  • 项目组合 Kanban： 大型举措（史诗）依次经过“漏斗”“审查”“分析”“就绪”“实施”和“完成”等阶段，并设有 WIP 限制。
  • 精益商业论证： 包含假设、最小可行产品和可衡量成果的简短文档。
  • 参与式预算： 相关方共同决定如何分配资金。
  • 定期的项目组合审查： 通常每季度一次，以根据成果调整投资。

使用 WSJF 排定优先级

加权最短作业优先（WSJF）优先处理能最快交付最多价值的工作：

WSJF = 延迟成本 ÷ 作业规模

在 SAFe 中，延迟成本综合了用户和业务价值、时间紧迫性以及风险降低或机会促成，每一项都采用相对评分。WSJF 得分最高的条目优先处理。

入门

  1. 将所有当前举措放在一个项目组合看板上可视化。
  2. 限制同时开展的大型举措数量。
  3. 确定几个战略主题和可衡量的成果。
  4. 引入季度项目组合审查。
  5. 逐步从项目资助转向为稳定的团队提供资金。

常见问题

敏捷项目组合管理与精益项目组合管理是一回事吗？

精益项目组合管理是 SAFe 对敏捷项目组合管理的特定版本。

由谁负责敏捷项目组合管理？

通常由业务、技术和财务领导者组成的小组负责，往往由以下职能提供支持： 敏捷 PMO.

什么是敏捷项目组合管理？

一种运用敏捷和精益理念来选择、资助和审查举措的方式：为价值流或团队提供资金，持续排定优先级，并根据成果调整投资。

敏捷项目组合管理与传统 PPM 有何不同？

传统 PPM 按范围每年为项目提供资金，并通过阶段关口进行治理；敏捷项目组合管理在一段时期内为团队或价值流提供资金，并定期（通常每季度）审查优先级。

敏捷项目组合管理中的 WSJF 是什么？

加权最短作业优先：延迟成本除以作业规模。得分最高的条目能最快交付最多价值，应优先处理。

敏捷项目组合管理中的项目组合 Kanban 是什么？

一种看板，大型举措在其中依次经过“漏斗”“审查”“分析”“就绪”“实施”和“完成”等阶段，并通过 WIP 限制避免同时启动过多举措。

敏捷项目组合管理中的精益商业论证是什么？

一份简短的文档，阐明假设、最小可行产品和可衡量的成果，用于取代冗长的传统商业论证。

敏捷项目组合管理中的精益预算是什么？

为长期存在的价值流或团队提供资金，并让它们在商定的护栏内自行决定如何使用，而不是逐个项目审批预算。

敏捷项目组合管理审查应多久进行一次？

通常每季度一次，以便将投资转向行之有效的方向，撤出效果不佳的领域。

敏捷项目组合管理中的参与式预算是什么？

一种做法：相关方共同决定如何在各项举措之间分配资金，通常在有引导的会议中进行。

如何开始敏捷项目组合管理？

将所有举措放在一个看板上可视化，限制同时开展的大型举措数量，确定几个战略主题，并引入定期的项目组合审查。参见 项目组合管理.
