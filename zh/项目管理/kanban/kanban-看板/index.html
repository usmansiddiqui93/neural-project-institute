Kanban 看板：如何设计和使用

Kanban 看板是 Kanban 的可视化核心。它展示每一项工作、所处位置以及卡在何处，让整个团队可以共同管理流动。

作者Neural Project Institute项目管理编辑团队

  • 阅读时长 3 分钟

要点总结

  • Kanban 看板展示工作项、阶段、WIP 限制和策略。
  • 根据真实流程进行设计，包括等待阶段。
  • WIP 限制让看板成为管理流动的工具。

Kanban 看板的组成部分

  • 列 对应工作流的每个阶段，例如待办、进行中、评审和已完成。
  • 卡片 对应单个工作项。
  • WIP 限制 显示在活动列的顶部。
  • 承诺点： 团队承诺完成某个工作项的位置。
  • 交付点： 工作项交付给客户的位置。
  • 泳道 用于区分不同类型或服务类别的工作。
  • 策略： 关于工作项进入和离开每列的简短规则。

如何设计您的看板

  1. 回顾近期一个工作项从提出请求到完成的实际流转过程。
  2. 将每个真实阶段转化为一列，包括等待阶段。
  3. 将繁忙的阶段拆分为“进行中”和“已完成”，以显示队列。
  4. 标出承诺点和交付点。
  5. 为活动列添加 WIP 限制。
  6. 为每列编写一句话策略。
  7. 只有当泳道能回答实际问题时才添加。

常见的看板错误

  • 设计理想流程而非真实流程。
  • 列太多，导致看板难以阅读。
  • 没有 WIP 限制，看板只是一份待办清单。
  • 卡片过大，数周都无法移动。
  • 不更新看板，导致没人信任它。

常见问题

Kanban 看板应该有多少列？

只需足以显示真实阶段的列数，通常为四到八列。

Kanban 看板与 Scrum 看板有什么区别？

Scrum 看板每个冲刺都会重置，只显示冲刺内的工作；Kanban 看板显示持续流动，并为每列设置 WIP 限制。

什么是 Kanban 看板？

Kanban 看板是工作的可视化展示，工作流的每个阶段对应一列，每个工作项对应一张卡片。它显示哪些工作正在进行、工作在哪里等待以及在哪里受阻。

Kanban 看板的基本列有哪些？

最简单的看板包含待办、进行中和已完成三列。大多数团队会根据实际流程加以扩展，例如待办事项列表、就绪、进行中、评审、测试和已完成。

Kanban 看板应该包含哪些内容？

每个阶段一列，每个工作项一张卡片，活动列设置 WIP 限制，明确的承诺点和交付点，以及说明工作何时可以移动的简短策略。泳道为可选项。

我应该在 Kanban 看板上添加等待列吗？

应该。将阶段拆分为“进行中”和“已完成”子列，或添加“待测试”等队列，可以显示工作在哪里等待，而这里往往隐藏着大部分延误。

实体看板还是数字看板：哪个更好？

实体看板启动快，对集中办公的团队非常直观。数字看板适合远程团队，并能自动收集指标；参见 项目管理工具.

如何在 Kanban 看板上设置 WIP 限制？

在每个活动列上方写明限制，起始值通常约等于负责该阶段的人数，然后根据观察进行调整。参见 WIP 限制.

谁负责 Kanban 看板？

由执行工作的团队负责并保持更新。任何人都可以查看，但对看板设计或策略的更改应共同商定。

Kanban 看板应该多久更新一次？

随着工作进展随时更新，使看板始终反映真实状态。至少，团队应在每日 Kanban 会议上检查并更正看板。
