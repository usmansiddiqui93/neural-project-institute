完工预算（BAC）：定义、公式与示例

完工预算（BAC）是项目、控制账户或工作包中所有工作的计划总预算。它等于成本基准，是衡量挣值、预测和偏差的依据。

要点总结

  • BAC 是成本基准：工作的计划总预算。
  • 它包括应急储备，但不包括管理储备。
  • EV、EAC、VAC 和 TCPI 都是根据 BAC 计算的。
  • BAC 只能通过正式的变更控制进行变更。

BAC 的计算方法

BAC 是所有工作包的预算加上应急储备的总和。它 不 包括管理储备。

组成部分金额
设计$40,000
构建$90,000
测试$30,000
部署与培训$20,000
应急储备$20,000
BAC（成本基准）$200,000
管理储备（不包括在内）$15,000
项目总预算$215,000

BAC 的用途

  • 挣值： EV = 完成百分比 x BAC。完成 35% 时，EV = 0.35 x 200,000 = $70,000。
  • 预测： EAC = BAC / CPI。CPI 为 0.8235 时，EAC = $242,857。
  • 完工偏差： VAC = BAC - EAC = 200,000 - 242,857 = -$42,857。
  • TCPI： (BAC - EV) / (BAC - AC) 显示在 BAC 范围内完工所需的效率。
  • 支出百分比： AC / BAC = 85,000 / 200,000 = 42.5%，而完成度为 35%。

BAC 何时变更

BAC 是一个基准，因此只应通过以下方式变更： 变更控制：例如，当增加了已批准的范围，或为新的范围内工作释放管理储备时。仅仅因为成本偏高就更改 BAC，会掩盖真实的绩效。

技巧

  • 确保各控制账户预算之和等于 BAC。
  • 在批准的变更之间保持 BAC 不变，这样趋势才有意义。
  • 将 BAC 和 EAC 并列报告，使预测差距一目了然。
  • 记录每次基准变更及其原因和日期。

常见问题

什么是完工预算？

为项目所有工作计划的总预算，等于成本基准。缩写为 BAC。

如何计算 BAC？

将所有工作包的预算与应急储备相加。管理储备不包括在内。

BAC 包括管理储备吗？

不包括。管理储备不在成本基准之内；将其加到 BAC 上，得到的是项目总预算。

BAC 和 EAC 有什么区别？

BAC 是工作的计划成本。EAC 是对实际成本的当前预测。

BAC 在项目期间可以变更吗？

只能通过批准的变更，例如增加范围。不应仅仅为了掩盖超支而更改它。

如何使用 BAC 计算挣值？

EV = 工作完成百分比 x BAC。如果 BAC 为 $200,000，工作完成了 35%，则 EV 为 $70,000。

如何使用 BAC 计算 VAC？

完工偏差，即 BAC - EAC。负值表示预计在完工时的超支额。

BAC 与项目预算相同吗？

不完全相同。BAC 是成本基准；项目预算还要加上管理储备。

BAC 包括应急储备吗？

是的。针对已识别风险的应急储备是成本基准的一部分，因此也是 BAC 的一部分。

可以为项目的一部分计算 BAC 吗？

可以。每个控制账户和工作包都有自己的 BAC，它们加起来就是项目的 BAC。
