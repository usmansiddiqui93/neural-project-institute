进度偏差（SV）：公式、示例与局限性

进度偏差（SV）衡量项目在给定日期完成的工作比计划多还是少，以金额表示。其计算公式为 SV = EV - PV；结果为负表示项目进度落后。

作者Neural Project Institute项目管理编辑团队
  • 发布于 2026 年 9 月 29 日
  • 阅读时长 3 分钟

要点总结

  • SV = EV - PV；为负表示进度落后。
  • SV 以金额表示，并在项目完成时回归为零。
  • 在得出结论之前，要检查关键路径，而不仅仅是 SV。
  • 挣得进度将 SV 转换为时间单位。

公式

公式含义
SV = EV - PV以金额表示的进度偏差
SV% = SV / PV进度偏差占计划工作的百分比
SPI = EV / PV进度绩效指数
结果含义
SV > 0进度超前
SV = 0符合进度
SV < 0进度落后

计算示例

在第四个月，PV = $80,000，EV = $70,000。

  • SV = 70,000 - 80,000 = -$10,000.
  • SV% = -10,000 / 80,000 = -12.5%.
  • SPI = 70,000 / 80,000 = 0.875：团队已完成截至目前计划工作的 87.5%。

SV 的局限性

  • 它以金额而非时间表示。 -$10,000 并不能告诉您延误了多少天。
  • 它在项目结束时会回归为零。 当所有工作完成时，EV = PV = BAC，因此即使项目晚了几个月才完成，SV 也等于 0。
  • 它忽略了关键路径。 非关键任务上超前完成的工作可能会掩盖关键任务的延误；参见 关键路径法.

挣得进度：以时间单位表示的 SV

挣得进度（ES）找出当前 EV 本应挣得的时间点。根据第三个月的累计 PV $50,000 和第四个月的累计 PV $80,000，$70,000 的 EV 原计划在以下时间挣得：

  • ES = 3 + (70,000 - 50,000) / (80,000 - 50,000) = 3 + 0.67 = 3.67 个月.
  • 实际时间（AT）= 4 个月，因此 SV(t) = 3.67 - 4 = -0.33 个月 （落后约三分之一个月）。
  • SPI(t) = 3.67 / 4 = 0.92.

如何应对负的 SV

  1. 检查延误的工作是否位于关键路径上。
  2. 找出原因：资源、依赖关系、范围、供应商延误。
  3. 可考虑 进度压缩: 快速跟进或赶工.
  4. 重新排序或重新分配工作，可采用 资源平衡.
  5. 更新预测完工日期并告知相关方。

常见问题

什么是进度偏差？

挣值与计划价值之差，SV = EV - PV，表明已完成的工作比计划多还是少。

负的进度偏差意味着什么？

截至该日期完成的工作少于计划，因此项目进度落后。

为什么进度偏差以金额衡量？

因为挣值以预算金额来衡量工作。挣得进度则将其转换为时间。

如何计算 SV 百分比？

SV% = SV / PV x 100。若 SV 为 -$10,000，PV 为 $80,000，则为 -12.5%。

为什么 SV 在项目结束时会变为零？

当所有工作完成时，EV 等于 BAC，PV 也等于 BAC，因此无论延误多久，SV 都为零。

SV 和 SPI 有什么区别？

SV 是以金额表示的差值（EV - PV）；SPI 是比率（EV / PV）。

项目的 SV 为正，仍然可能延误吗？

可能。如果在非关键任务上完成了额外工作，而关键路径上的任务却出现延误，就会出现这种情况。

挣得进度如何改进进度偏差？

挣得进度是 EVM 的一种扩展，它通过找出当前 EV 原计划在何时挣得，以时间而非金额来衡量进度绩效。与 SV 不同，它不会在项目接近完成时回归为零。

进度偏差与成本偏差有何不同？

SV = EV - PV 比较的是已完成工作与计划工作。CV = EV - AC 比较的是已完成工作与其实际成本。

如何纠正负的进度偏差？

聚焦关键路径，消除障碍，并考虑快速跟进、赶工或重新规划，然后更新预测。
