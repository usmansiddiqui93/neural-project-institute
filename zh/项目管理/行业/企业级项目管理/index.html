企业级项目管理（EPM）：阶段、角色与工具

企业项目管理（EPM）是将组织的所有项目作为一个协调统一的系统来管理的实践，采用共同的治理、标准方法、通用工具以及项目组合及其资源的统一视图。它位于单个项目管理之上：问题不仅是“这个项目是否按计划推进？”，还包括“我们是否在做正确的项目，我们是否有能力交付它们？”

要点总结

  • 企业项目管理将所有项目视为一个项目组合，采用共同的治理、方法和工具。
  • 考虑产能的优先级排序是最有价值的 EPM 决策。
  • 对治理进行分级，以免小项目被淹没在流程中。
  • 一个集需求受理、资源和报告于一体的平台使 EPM 切实可行。

什么是企业项目管理及其独特之处

在大型组织中，数百个项目同时在各部门和各国家开展，争夺相同的预算、专家和管理层关注。EPM 将它们纳入统一的框架。它与项目组合管理有所重叠，通常由企业级 PMO；参见 项目集、项目与项目组合管理对比 ，了解各层级之间的关系。

  • 规模与复杂性。 跨业务单元存在大量项目、项目集和依赖关系。
  • 标准化。 统一的生命周期、模板、报告和术语，使项目之间可以比较。
  • 项目组合决策。 依据战略和可用产能选择、排序、暂停和终止项目。
  • 企业资源管理。 在整个组织范围内掌握稀缺技能的需求和产能；参见 产能规划.
  • 治理与合规。 明确的审批阈值、审计追踪和控制措施，通常由法规或上市公司要求驱动。
  • 方法混杂。 敏捷产品团队、瀑布式资本项目和混合型项目集都必须汇报到同一个视图中。

企业项目管理生命周期

EPM 在每个项目的生命周期之外增加了一个项目组合生命周期：

阶段主要工作由谁决策
1. 战略与规划确定战略目标和投资主题；商定年度或季度预算额度高管团队
2. 需求受理通过标准表单收集想法和请求，并进行粗略的规模评估PMO 初筛
3. 评估与优先级排序根据价值、风险、一致性和资源需求对商业论证进行评分项目组合委员会或投资委员会
4. 审批与资源配置为选定项目提供资金和人员；对照其他承诺核查产能项目组合委员会、资源经理
5. 交付与阶段关口项目按各自选定的方法运行，并通过标准仪表板进行报告；关口用于检查项目是否仍然可行项目委员会和 PMO
6. 项目组合监控与再平衡定期评审健康状况、支出和产能；对项目进行加速、暂停或终止项目组合委员会
7. 收尾与效益跟踪项目收尾，衡量效益，将经验教训反馈到标准中效益负责人和 PMO

敏捷组织采用精益项目组合实践运行类似的周期；参见 敏捷项目组合管理 和 规模化敏捷框架.

关键角色

角色职责
高管团队 / 项目组合委员会制定战略，批准投资，在项目组合层面进行权衡
企业 PMO（EPMO）总监负责 EPM 框架、项目组合报告和治理
项目组合经理管理某个业务单元或投资主题的项目组合
项目集经理协调相关项目以交付共同效益；参见 项目经理与项目集经理对比
项目经理在企业标准范围内交付单个项目
资源经理在各项目之间分配人员，平衡需求与产能
财务合作伙伴跟踪整个项目组合的资本支出和运营支出
效益负责人在交付后负责实现效益的业务领导者

适用的方法论和框架

方法最适合说明
阶段关口治理全企业范围的投资控制所有项目统一采用具有明确标准的关口
PMBOK 或 PRINCE2 作为基础方法一致的项目层面实践根据项目规模进行裁剪；避免对小项目强加繁重的流程

提示

对治理进行分级。为期两周的内部改进项目和为期多年的转型项目，不应填写同一份二十页的模板。

必备文档与模板

  • EPM 框架或操作手册： 生命周期、关口、角色、分级和报告标准。
  • 需求受理表单： 标准的 工作申请模板 ，用于新需求。
  • 商业论证模板: 统一的结构，使各项投资可以相互比较。
  • 项目章程模板: 对已批准项目的标准授权。
  • 标准状态报告： 整个项目组合中一致的健康指标；参见 项目状态报告.
  • RAID 日志模板: 用于记录风险、假设、问题和依赖关系（包括跨项目依赖关系）的共同格式。
  • 项目跟踪表模板: 项目组合层面的项目清单，包括负责人、所处阶段和健康状况。
  • 技能矩阵: 支持企业资源规划。
  • 经验教训模板: 为未来项目提供参考的中央知识库。

常见挑战及应对方法

  • 项目过多。 在确定优先级时将产能作为硬性约束；少启动一些项目，通常能完成更多项目。
  • 官僚作风。 对治理进行分级，删除不影响决策的步骤。
  • 数据不一致。 对少量必填字段进行标准化，并从工具中自动生成报告，而不是收集电子表格。
  • 依赖关系不透明。 在项目组合层面明确跟踪跨项目依赖关系。
  • 敏捷团队和传统团队处于同一个项目组合中。 报告成果和交付的价值，并让每个团队保留自己的交付方法。
  • PMO 被视为管理负担。 通过更快的决策、更好的资源可见性以及防止重复失败的经验教训来体现价值。

常见问题

什么是企业项目管理？

企业项目管理是将组织的所有项目作为一个协调统一的系统来管理，采用共同的治理、标准方法、通用工具和统一的项目组合视图。

企业项目管理和项目组合管理有什么区别？

项目组合管理侧重于项目的选择与平衡；企业项目管理的范围更广，还涵盖适用于每个项目的标准方法、工具、资源和治理。

企业项目管理办公室做什么？

EPMO 制定项目标准，负责项目组合治理和报告，支持资源规划，并建设项目管理能力；参见 PMO.

企业项目管理有哪些好处？

使项目与战略更加一致、资源可见性更清晰、报告更一致、更早发现失败项目，以及作出更好的投资决策。

什么是企业项目管理软件？

EPM 软件为所有项目提供项目组合视图、资源管理、需求受理和审批工作流以及企业级报告；Wrike 是一款强大的一体化代表产品。

企业项目管理有哪些阶段？

战略与规划、需求受理、评估与优先级排序、审批与资源配置、通过阶段关口进行交付、项目组合监控，以及包含效益跟踪的收尾。

企业项目管理使用哪种方法论？

通常是一个阶段关口治理框架，项目层面采用 PMBOK 或 PRINCE2，产品团队则采用 SAFe 等规模化敏捷方法。

企业项目管理使用哪些 KPI？

战略一致性、项目组合健康度、已实现效益、资源利用率、进度和成本绩效以及审批耗时。

敏捷如何融入企业项目管理？

敏捷团队保留各自的交付方法，而项目组合为价值流或产品提供资金并跟踪成果；参见 敏捷项目组合管理.

企业项目管理中常见的挑战有哪些？

项目过多、官僚作风严重、数据不一致、依赖关系不透明，以及对集中标准的抵触。

如何实施企业项目管理？

从简单的项目组合清单、标准化的需求受理和状态报告以及单一工具开始，然后分阶段增加分级治理和资源管理。
