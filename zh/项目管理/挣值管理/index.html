挣值管理（EVM）：公式与计算示例

挣值管理（EVM）是一种通过比较计划工作的价值、实际完成工作的价值以及该工作的实际成本来衡量项目绩效的技术。它能客观地反映成本和进度绩效，并为预测最终成本提供依据。

作者Neural Project Institute项目管理编辑团队
  • 发布于 2026 年 9 月 28 日
  • 阅读时长 4 分钟

要点总结

  • EVM 通过比较 PV、EV 和 AC 来衡量成本和进度绩效。
  • CV 和 CPI 衡量成本；SV 和 SPI 衡量进度。
  • EAC、ETC、VAC 和 TCPI 预测项目的最终完成情况。
  • 可靠的基准和客观的进度衡量规则是 EVM 可靠的前提。

三个核心度量

度量又称含义
计划价值（PV）BCWS截至目前计划完成工作的预算成本
挣值（EV）BCWP截至目前实际完成工作的预算成本
实际成本（AC）ACWP已完成工作的实际花费
完工预算（BAC）全部工作的总预算；请参阅 BAC

挣值 = 完成百分比 × BAC（或已完成工作的预算之和）。

关键公式

公式计算解读
成本偏差（CV）EV - AC负值 = 超支
进度偏差（SV）EV - PV负值 = 进度落后
成本绩效指数（CPI）EV / AC小于 1 = 超支
进度绩效指数（SPI）EV / PV小于 1 = 进度落后
完工估算（EAC）BAC / CPI（典型偏差）预测最终成本
EAC（非典型偏差）AC + (BAC - EV)过去的偏差不会再次发生
EAC（同时考虑成本和进度）AC + (BAC - EV) / (CPI x SPI)两个指数都会影响剩余工作
EAC（重新估算）AC + 自下而上的 ETC原计划已不再有效
完工尚需估算（ETC）EAC - AC仍需投入的资金
完工偏差（VAC）BAC - EAC负值 = 预计超支
TCPI（以 BAC 为目标）(BAC - EV) / (BAC - AC)按预算完工所需的效率
TCPI（以 EAC 为目标）(BAC - EV) / (EAC - AC)达到 EAC 所需的效率

计算示例

某项目工期八个月，BAC = $200,000。第四个月末：PV = $80,000，EV = $70,000（完成 35%），AC = $85,000。

度量计算结果
CV70,000 - 85,000-$15,000
SV70,000 - 80,000-$10,000
CPI70,000 / 85,0000.82
SPI70,000 / 80,0000.88 (0.875)
EAC（典型）200,000 / 0.8235$242,857
EAC（非典型）85,000 + 130,000$215,000
EAC（CPI x SPI）85,000 + 130,000 / 0.7206$265,408
ETC（典型）242,857 - 85,000$157,857
VAC200,000 - 242,857-$42,857
TCPI（以 BAC 为目标）130,000 / 115,0001.13

解读：项目已超支且进度落后。如果当前的成本效率持续下去，项目完工时将超支约 $42,857。要按预算完工，剩余工作的 CPI 需达到 1.13，远高于目前实现的 0.82。

如何建立 EVM

  1. 定义范围，借助 工作分解结构.
  2. 安排工作进度并分配预算，形成按时间分布的基准（即 S 曲线).
  3. 商定进度计量规则，例如 0/100、50/50 或加权里程碑法。
  4. 每个周期按工作包收集实际成本。
  5. 计算 PV、EV 和 AC，然后计算偏差和指数。
  6. 预测 EAC，审查原因并采取行动。
  7. 报告趋势，而不仅仅是单次读数。

优势与局限

优势局限
客观、整合地反映范围、时间和成本需要良好的基准和准确的实际成本
早期预警：CPI 往往在早期就趋于稳定SV 无法反映 关键路径
标准公式被广泛理解即使项目延期，SV 在结束时也会回归为零
支持预测进度计量可能被操纵或带有主观性

技巧

  • 对短期任务使用简单的进度计量规则，避免主观的完成百分比。
  • 跟踪 CPI 和 SPI 在多个周期内的趋势。
  • 将 SPI 与关键路径分析或挣得进度结合使用。
  • 在报告中用通俗的语言解释结果；大多数相关方并不了解这些缩写。

常见问题

什么是挣值管理？

一种通过比较计划价值、挣值和实际成本来评估成本和进度绩效、衡量项目绩效的方法。

挣值管理中的 PV、EV 和 AC 有什么区别？

PV 是截至目前计划完成工作的预算价值，EV 是实际完成工作的预算价值，AC 是这些工作的实际成本。

如何计算挣值？

将工作完成百分比乘以完工预算，或将已完成工作包的预算相加。

成本偏差的挣值公式是什么？

CV = EV - AC。负值表示项目超支。

进度偏差的挣值公式是什么？

SV = EV - PV。负值表示完成的工作少于计划。

在挣值管理中，CPI 为 0.8 意味着什么？

每花费 1 美元，项目只获得价值 80 美分的计划工作，因此项目处于超支状态。

在挣值管理中应该使用哪个 EAC 公式？

如果预计当前绩效会持续，使用 BAC / CPI；如果偏差是一次性的，使用 AC + (BAC - EV)；如果原计划已不再有效，则使用 AC + 新的 ETC。

挣值管理中的 TCPI 是什么？

完工尚需绩效指数：为在 BAC 或新的 EAC 范围内完工，剩余工作所需达到的 CPI。

挣值管理中的 BCWS 和 BCWP 是什么意思？

PV（计划工作的预算成本）和 EV（已完成工作的预算成本）的旧称。ACWP 是已完成工作的实际成本。

敏捷项目中会使用 EVM 吗？

会，但采用调整后的形式。敏捷 EVM 通常将每次发布已完成的故事点与计划故事点进行比较来计算 EV。

PMP 考试会考挣值吗？

会，挣值计算是 PMP 备考中广为人知的内容；请参阅 PMP 认证.

EVM 中的挣得进度是什么？

EVM 的一种扩展方法，以时间单位而非金额衡量进度绩效，避免了 SV 在项目结束时回归为零的问题。
