成本偏差（CV）：公式、计算与示例

成本偏差（CV）是已完成工作的价值与其实际成本之间的差额。在挣值管理中，其计算公式为 CV = EV - AC；结果为负表示就迄今已完成的工作而言，项目超出了预算。

要点总结

  • CV = EV - AC；负值表示超出预算。
  • CV% = CV / EV 让您能够比较不同规模的项目。
  • 将成本与挣得的工作价值进行比较，而不是与计划支出比较。
  • 当 CV 较大时，调查原因并更新 EAC。

公式

公式含义
CV = EV - AC以货币表示的成本偏差
CV% = CV / EV成本偏差占已完成工作价值的百分比
VAC = BAC - EAC完工时的预期成本偏差
结果含义
CV > 0就已完成的工作而言低于预算
CV = 0符合预算
CV < 0就已完成的工作而言超出预算

计算示例

BAC = $200,000。第四个月时，EV = $70,000，AC = $85,000。

  • CV = 70,000 - 85,000 = -$15,000.
  • CV% = -15,000 / 70,000 = -21.4%.
  • 因此，迄今已完成工作的成本比预算高出 21.4%。

第二个示例：EV = $50,000，AC = $46,000，得出 CV = +$4,000（低于预算 8%）。

为什么与 EV 而不是 PV 比较

一个常见的错误是将实际成本与计划支出（PV）进行比较。在本例中，PV 为 $80,000，AC 为 $85,000，看起来只超支了 $5,000。但团队只完成了价值 $70,000 的工作，因此就已完成的工作而言，真实的超支额是 $15,000。与 EV 比较可以将成本绩效与进度绩效区分开来；参见 进度偏差.

CV 为负的常见原因

  • 乐观 估算 或遗漏项。
  • 人工费率或材料价格高于计划。
  • 缺陷或需求不明确导致的返工。
  • 范围蔓延 在没有变更请求的情况下被吸收。
  • 生产率低、工作被打断或人员缺乏经验。

应对措施

  1. 检查数据：实际成本和进展是否记录正确？
  2. 找出是哪些控制账户或工作包导致了偏差。
  3. 找出根本原因，并判断其是否会持续。
  4. 更新 EAC 并检查 CPI 趋势。
  5. 商定纠正措施或变更请求，并记录决定。

常见问题

项目管理中的成本偏差是什么？

挣值与实际成本之间的差额，CV = EV - AC，显示已完成工作的成本是高于还是低于预算。

负的成本偏差意味着什么？

迄今已完成工作的成本超出了其预算：项目超出预算。

正的成本偏差意味着什么？

已完成工作的成本低于预算：就已完成的工作而言，项目低于预算。

如何计算成本偏差百分比？

CV% = CV / EV x 100。CV 为 -$15,000、EV 为 $70,000 时，CV% 为 -21.4%。

成本偏差和进度偏差有什么区别？

CV = EV - AC 衡量成本；SV = EV - PV 衡量进度。两者都使用 EV。

为什么成本偏差不将实际成本与计划价值进行比较？

因为 PV 反映的是工作的计划时间安排，而不是实际完成的工作。混用两者会把进度影响和成本影响混在一起。

成本偏差与预算偏差相同吗？

在日常财务中，预算偏差通常比较实际支出与预算。在 EVM 中，CV 比较的是实际成本与已完成工作的挣值。

多大的成本偏差可以接受？

这取决于以下文件中商定的阈值： 成本管理计划；许多项目会对超过设定百分比的偏差展开调查。

完工偏差与成本偏差有什么关系？

完工偏差（VAC = BAC - EAC）是项目结束时预期的成本偏差。

成本偏差与 CPI 有什么关系？

两者都使用 EV 和 AC。CV 是差值（EV - AC），CPI 是比率（EV / AC）。

项目陷入困境时，成本偏差可能为正吗？

是的。项目可能低于预算但进度严重落后，因此务必同时查看 SV 和 SPI。
