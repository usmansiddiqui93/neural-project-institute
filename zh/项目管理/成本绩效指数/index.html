成本绩效指数（CPI）：公式与解读

成本绩效指数（CPI）衡量成本效率：每花费一单位资金挣得多少工作价值。其计算公式为 CPI = EV / AC，因此 CPI 低于 1 意味着就已完成的工作而言，项目超出了预算。

要点总结

  • CPI = EV / AC；低于 1 表示超出预算，高于 1 表示低于预算。
  • EAC = BAC / CPI 是标准的成本预测公式。
  • 跟踪累计 CPI 和当期 CPI 的趋势。
  • 将 CPI 与 SPI 结合起来解读，才能了解全貌。

公式与解读

CPI = EV / AC

CPI含义示例
高于 1低于预算：挣得的工作价值多于花费的资金1.10 = 每花费 $1 获得 $1.10 的工作价值
1恰好符合预算
低于 1超出预算：挣得的工作价值少于花费的资金0.82 = 每花费 $1 获得 82 美分的工作价值

计算示例

EV = $70,000，AC = $85,000。

  • CPI = 70,000 / 85,000 = 0.82.
  • 预测 EAC = BAC / CPI = 200,000 / 0.8235 = $242,857.
  • 与以下指标进行比较： 进度绩效指数 SPI = EV / PV = 70,000 / 80,000 = 0.875。

累计 CPI 显示整体效率，用于预测。当期 CPI 显示近期效率是否在改善。本例中两者都稳定在 0.82 左右，因此超支是系统性的，而非偶发的。

CPI 与 SPI 结合分析

SPI 大于 1SPI 低于 1
CPI 大于 1进度超前，成本节约进度落后，成本节约
CPI 低于 1进度超前，成本超支进度落后，成本超支

技巧

  • 观察多个周期的趋势，而不是单次读数。
  • CPI 远高于 1 时也要像低于 1 时一样展开调查；这可能表明估算被注水或有工作被跳过。
  • 报告 CPI 时附上通俗易懂的解释。
  • 使用 TCPI ，以判断能否切实挽回。

常见问题

什么是成本绩效指数？

挣值管理中衡量成本效率的指标：CPI = EV / AC。

CPI 等于 1 意味着什么？

就已完成的工作而言，项目恰好符合预算。

CPI 低于 1 意味着什么？

项目为已完成的工作花费的资金多于计划，因此超出了预算。

CPI 大于 1 意味着什么？

项目每花费一美元完成的工作多于计划，因此低于预算。

如何使用 CPI 预测成本？

典型的预测公式是 EAC = BAC / CPI。BAC 为 $200,000、CPI 为 0.8235 时，EAC 约为 $242,857。

CPI 和 SPI 有什么区别？

CPI = EV / AC 衡量成本效率。SPI = EV / PV 衡量进度效率。

多少 CPI 算好？

CPI 接近 1 就是好的。组织通常会设定阈值，例如对低于 0.95 或高于 1.10 的数值展开调查。

CPI 和 CV 有什么区别？

CV = EV - AC 是以货币表示的偏差；CPI = EV / AC 是一个比率，便于在项目之间进行比较。

累计 CPI 和当期 CPI 哪个更好？

使用累计 CPI 进行预测，使用当期 CPI 发现近期效率的变化。

什么是 TCPI？

完工尚需绩效指数：为按目标预算完工，剩余工作所需达到的 CPI。

CPI 在项目后期还能恢复吗？

随着项目推进，这会变得越来越难，因为大部分成本已经花掉了，所以要尽早采取行动。
