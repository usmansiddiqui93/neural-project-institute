成本绩效指数（CPI）：公式、示例与含义

成本绩效指数（CPI）衡量项目的成本效率：您每花一单位资金能获得多少预算工作。其计算公式为 CPI = EV / AC，因此 CPI 为 0.90 意味着每花一美元只换来 90 美分的计划工作。本指南介绍该公式、如何解读结果、累计 CPI 与当期 CPI、用 CPI 进行预测，以及一个看似健康的项目 CPI 掩盖了真实问题的实例。

要点总结

  • CPI = EV / AC。低于 1 表示就已完成的工作而言超出预算；高于 1 表示低于预算。
  • CPI 为 0.85 意味着每单位工作的成本比计划高出约 18%（1 / 0.85），而不是 15%。
  • 项目 CPI 按总 EV 除以总 AC 计算。切勿对各工作包的 CPI 取平均值。
  • 关注当期 CPI 以快速发现变化；使用累计 CPI 进行预测，例如 EAC = BAC / CPI。
  • 良好的项目 CPI 可能掩盖表现不佳的工作包，因此请按工作包和成本类型检查 CPI。
  • 将 CPI 与 TCPI 进行比较，以判断预算是否仍可实现。

什么是成本绩效指数（CPI）？

​ 成本绩效指数（CPI） 是衡量成本效率的挣值管理指标。它用已完成工作的挣值（EV）除以该工作的实际成本（AC）。CPI 为 1.0 表示工作成本与预算完全相同；低于 1.0 表示成本高于预算，高于 1.0 表示成本低于预算。

CPI 是以下体系的核心指标之一： 挣值管理（EVM），以及 成本偏差, 进度偏差 和进度绩效指数（SPI）。由于它是比率而不是金额，因此可以用来比较规模差异很大的工作包和项目的效率。

在较早的 EVM 资料和许多政府合同中，这些输入有不同的名称。挣值是 已完成工作的预算成本（BCWP） ，实际成本为 已完成工作的实际成本（ACWP），因此您也会看到该公式写作 CPI = BCWP / ACWP。

提示

项目的成本绩效指数与消费者价格指数毫无关系，后者是同样缩写为 CPI 的通货膨胀指标。如果报告中同时涉及通货膨胀和成本效率，请写出两者的全称。

CPI 公式

公式展示内容
CPI = EV / AC截至目前已完成工作的成本效率
EV = 完成百分比 x BAC挣值：实际完成工作的预算
累计 CPI = 截至目前的总 EV / 截至目前的总 AC项目开始以来的效率；用于预测
当期 CPI = 本期 EV / 本期 AC一个月或一个 Sprint 内的效率；显示近期变化
项目 CPI = 各工作包 EV 之和 / 各工作包 AC 之和汇总工作包数据的正确方法
1 / CPI每单位计划成本对应的实际成本，例如 1 / 0.85 = 1.18

BAC 是 完工预算，即该工作的批准预算总额。 AC 必须与 EV 涵盖相同的工作和相同的期间，包括已完成但尚未开票工作的应计费用。

如何逐步计算 CPI

  1. 选择状态日期 ，并同时用于进度和成本。
  2. 取 BAC ，针对每个 工作包 ，基于当前已批准的 成本基准，包括已批准的变更，但不包括管理储备。
  3. 衡量完成百分比 ，使用商定的规则（0/100、50/50、加权里程碑或已完成单位），而不是个人判断。
  4. 计算 EV ，针对每个工作包：完成百分比 x BAC。
  5. 收集 AC ，针对每个工作包，包括应计的人工成本和供应商成本。
  6. 用 EV 除以 AC ，针对每个工作包得出工作包 CPI。
  7. 汇总 EV 和 AC ，汇总所有工作包，并用总计相除得出项目 CPI。
  8. 与上一期比较 并与您的阈值进行比较，记下任何影响总计的工作包。

简单示例。 某网站重建项目的 BAC 为 $120,000。已完成 40%，因此 EV = 0.40 x 120,000 = $48,000。截至目前的实际成本为 $54,000。CPI = 48,000 / 54,000 = 0.89。团队每花一美元约换来 89 美分的计划工作。

将 CPI 换算为超支百分比

一种常见的简便理解是把 0.85 的 CPI 解读为“超支 15%”。这并不完全正确。CPI 为 0.85 意味着每单位资金只换来 0.85 单位的计划工作，因此每单位计划工作的成本为 1 / 0.85 = 1.176，超支 17.6%。CPI 越低，差距越大。下表显示了如果每个 CPI 一直保持到项目结束，对 $500,000 预算的影响：

实例：包装线升级

一家食品制造商正在升级一条包装线。BAC 为 $500,000 ，涵盖五个工作包。第六个月末，计划价值（PV）为 $345,000。状态如下：

项目层面的解读

  • CPI = 318,000 / 329,000 = 0.97。 单独来看，这似乎与计划接近。
  • SPI = 318,000 / 345,000 = 0.92。 项目进度略有落后。
  • EAC = BAC / CPI = 500,000 / 0.967 = 约 $517,300，预测超支约 $17,300（3.5%）。

只看标题数字的发起人会得出结论：项目略微超出预算，仅此而已。

各工作包揭示了什么

良好的 CPI 来自设计和设备采购，这些工作基本已完成，且主要由固定价格采购构成。仍在前方的工作以人工为主：安装（CPI 0.75）和控制软件（CPI 0.77），再加上使用同一批安装人员的调试工作。早期高效的工作包美化了总体数字。

提示

当剩余工作与已完成工作性质不同时，应按工作包或成本类型（人工、材料、分包）进行预测，而不是使用单一的项目 CPI。

为什么绝不能对工作包 CPI 取平均值

四个工作包 CPI 的简单平均值为 (1.05 + 1.03 + 0.75 + 0.77) / 4 = 0.90。正确的项目 CPI 是总 EV 除以总 AC：318,000 / 329,000 = 0.97。简单平均会让控制软件这样的小工作包与设备采购这样的大工作包具有相同的权重。务必先汇总 EV 和 AC，然后再相除。将项目汇总到项目集或项目组合时，同样适用这一规则。

累计 CPI 与当期 CPI 对比

累计 CPI 包含项目开始以来的所有数据。当期 CPI 则单独看某一个月。以下是包装线项目的两项数据：

月份本月 EV本月 AC当期 CPI累计 EV累计 AC累计 CPI

安装工作于第五个月开始。当期 CPI 先降至 0.88，随后降至 0.75，而第五个月的累计 CPI 仍高于 1.0。只看累计数值的人会在这个月看到“略低于预算”，下个月看到“略超预算”，却忽略了当前工作恶化得有多快。

  • 使用当期 CPI 以便及早发现变化，并检查纠正措施是否奏效。
  • 使用累计 CPI 用于预测，因为单个月份的数据很容易被一张大额发票或一笔延迟的应计费用扭曲。
  • 同时绘制两者，或将累计 EV 和 AC 绘制为 S 曲线，两条线之间不断扩大的差距显示的也是同样的情况。

用 CPI 预测最终成本

CPI 是以下内容的主要输入： 完工估算（EAC）。使用哪个公式取决于您对未来绩效的判断。

EAC 公式包装线结果适用情况
EAC = BAC / CPI500,000 / 0.967 = $517,300预计当前的成本效率将持续
EAC = AC + (BAC - EV)329,000 + 182,000 = $511,000迄今为止的偏差是一次性的；其余部分将按计划进行
EAC = AC + (BAC - EV) / (CPI x SPI)329,000 + 182,000 / 0.891 = $533,300进度压力也会推高成本
按工作包自下而上$544,750剩余工作与已完成工作不同，如本例所示

当各种方法得出的结果不一致时，给出一个范围而不是单一数字，并解释您相信哪一个以及原因。我们的指南 项目预测 介绍了如何向发起人展示预测。

CPI 与完工尚需绩效指数（TCPI）

​ TCPI 是剩余工作要实现目标所需达到的成本效率：TCPI = (BAC - EV) / (BAC - AC)。对于包装线，(500,000 - 318,000) / (500,000 - 329,000) = 182,000 / 171,000 = 1.06.

要在预算内完成，剩余工作的 CPI 需要达到 1.06，而进行中的工作目前约为 0.75。除非发生根本性的变化，否则原预算无法实现，发起人现在就应该知道这一点。我们的工作规则是：只要 TCPI 明显高于当前的累计 CPI（高出 0.05 或以上），报告就应说明哪些措施将使剩余工作更有效率，否则就应重新审视目标。

CPI 与 SPI 结合分析

CPI 反映的是成本；进度绩效指数（SPI = EV / PV）反映的是进度。请将两者结合起来解读。

SPI 大于 1SPI 低于 1
CPI 大于 1进度超前且低于预算。请检查数据是否正确低于预算但进度落后。工作是被推迟了，而不是以更低成本完成了吗？
CPI 低于 1进度超前但超出预算。您是在为速度买单吗？进度落后且超出预算。这是最严重的情况：挽回时间通常需要付出更多成本

有些组织将两者相乘： CPI x SPI，有时称为关键比率。对于包装线，0.967 x 0.922 = 0.89。数值远低于 1 表明成本和进度都面临压力，它也是上述第三个 EAC 公式中的除数。

请记住，基于金额的 SPI 在项目末期会回落到 1.0 附近，无论项目是否延误，因为所有计划工作最终都会获得挣值。CPI 则没有这个问题。

CPI 与成本偏差、SPI 和 TCPI 的对比

度量公式类型回答的问题
成本绩效指数（CPI）EV / AC比率，截至目前我们的支出效率如何？
成本偏差（CV）EV - AC金额，截至目前已完成的工作超出或低于预算多少？
进度绩效指数（SPI）EV / PV比率，截至目前我们对照计划推进的效率如何？
完工尚需绩效指数（TCPI）(BAC - EV) / (BAC - AC)比率，面向未来其余工作的效率必须达到多少？
完工估算（EAC）例如 BAC / CPI金额，面向未来项目总共将花费多少？

CPI 和 CV 始终指向同一方向：CV 为负意味着 CPI 低于 1。两者都要报告。CV 显示涉及的金额，CPI 显示效率，更便于在项目之间进行比较。

多少 CPI 算好？

目标是 CPI 接近 1.0。可接受限值没有通用标准；它们取决于估算准确度、合同类型和组织的风险偏好，并应在以下文件中设定： 成本管理计划。作为 示意 仅限：

状态CPI 范围示例典型应对
绿色0.95 至 1.05照常报告
琥珀色0.90 至 0.95，或 1.05 至 1.10解释偏差并制定行动计划
红色低于 0.90，或高于 1.10升级、修订 EAC 并考虑提出变更请求

无论您选择什么区间，都要在每份以下报告中显示 CPI 趋势和一句话说明： 项目状态报告，让读者既看到数字，也看到方向。

注意上限区间。CPI 远高于 1 并不自动意味着好消息。这可能意味着发票或工时表缺失、进度被夸大、估算虚高，或者先完成了便宜的工作而昂贵的工作还在后面。持续偏高的 CPI 还会占用整个项目组合本可使用的预算。

CPI 会早早稳定下来吗？20% 法则

您可能听说过“项目完成 20% 后，CPI 就不会有太大变化”。这一说法来自对美国大型国防合同的研究。Christensen 和 Heise（1993）研究了 155 份美国国防部合同，得出结论：在大多数合同中，累计 CPI 从完成 20% 起就保持稳定，此处的稳定是指 CPI 的变动范围小于 0.20。在他们的数据中，155 份合同中有 134 份在完成 20% 时满足这一检验。在 CPI 确实发生变化的情况下，它往往是变差而不是变好。

此后，这一规则被广泛地过度套用。后来的评论，例如 Mosaic Projects 关于“CPI 稳定性神话”的论文（引用了 Henderson 和 Zwikael，2008），认为不能依赖这种稳定性，尤其是在较小的商业项目中。部分效应还源于算术本身：随着完成的工作越来越多，每个新月份对累计比率的影响就越小。

实践经验如下：

  • 早期的低 CPI 是严重警告。 不要以为它会自行恢复。
  • 尽早行动。 项目进展越深入，任何行动对累计 CPI 的影响就越小。
  • 不要在 20% 之后就停止管理。 CPI 趋势的变化通常意味着项目中有某些情况发生了变化。
  • 使用 TCPI 来判断恢复是否现实，而不是寄希望于 CPI 自行回升。

如何改善偏低的 CPI

  1. 验证数据。 核查进度声明，确保 AC 包含应计费用且不含其他项目的成本。
  2. 找出影响结果的工作包和成本类型。 详细的 工作分解结构 使这成为可能。查看各工作包的 CPI，并在可能时比较人工、材料和分包的情况。
  3. 区分价格与数量。 您是每小时或每单位支付得更多，还是使用的工时或单位多于计划？
  4. 找出根本原因 ，与执行工作的人一起。 鱼骨图 在原因复杂交织时很有帮助。
  5. 判断原因是否会持续， ，并据此更新 EAC。
  6. 针对剩余工作采取行动： 调整工作顺序并减少返工，改变资源组合，重新协商费率，或进行价值工程。
  7. 提出变更请求 如果范围或基准必须变更，则通过 变更控制.
  8. 关注当期 CPI 在接下来的一两个周期内，确认这些行动正在奏效。

关于围绕这些步骤的完整月度例程，请参阅我们的指南： 成本控制.

敏捷项目中的 CPI

敏捷团队可以在版本层面计算 CPI。将版本预算作为 BAC，将已完成的计划故事点比例作为完成百分比，将团队截至目前的成本作为 AC。

示例。 一个团队每个 Sprint 的成本为 $25,000，一个包含 12 个 Sprint 的版本预算为 $300,000，共 240 个故事点。五个 Sprint 后，团队完成了 110 点，花费了 $125,000。

  • EV = 110 / 240 x 300,000 = $137,500.
  • CPI = 137,500 / 125,000 = 1.10：团队每花一美元交付的点数多于计划。
  • 现在，产品负责人在不改变预算的情况下新增了 30 点范围。完成百分比变为 110 / 270，因此 EV 降至 $122,222，CPI 降至 0.98，尽管团队的效率没有任何变化。

经验在于：在敏捷中，对待办事项列表的范围变更必须同时就版本预算做出决定，否则 CPI 就不再能衡量效率。请将其与速度结合使用；参见我们的指南： Scrum 速度 和 敏捷指标与 KPI.

常见的 CPI 错误

  • 对工作包 CPI 取平均值 ，而不是用总 EV 除以总 AC。
  • 数据不匹配：EV 取自一个状态日期，而 AC 取自另一个状态日期，或者 AC 缺少应计费用。
  • 主观的完成百分比，从而虚增 EV，并随之虚增 CPI。
  • 解读 1：把 CPI 当作超支幅度。 请改用 1 / CPI - 1。
  • 依赖单个月份的数据。 观察几个时期的趋势。
  • 轻信良好的项目 CPI ，而不检查工作包和成本类型。
  • 忽视承付成本，例如会使目前 CPI 状况良好的工作包超支的采购订单。
  • 将管理储备计入 BAC，这会模糊对照基准衡量绩效的结果。

常见问题

什么是成本绩效指数？

成本绩效指数（CPI）是衡量成本效率的挣值指标。它将已完成工作的预算价值与该工作的实际成本进行比较：CPI = EV / AC。

CPI 的公式是什么？

CPI = EV / AC，其中 EV 是挣值（完成百分比 x 完工预算），AC 是已完成工作的实际成本。用旧术语表示，CPI = BCWP / ACWP。

CPI 等于 1 意味着什么？

已完成工作的成本与其预算完全相同，因此就已完成的工作而言，项目符合预算。

CPI 低于 1 意味着什么？

已完成工作的成本高于其预算。例如，CPI 为 0.90 意味着项目每花一美元只换来 90 美分的计划工作。

CPI 为 0.8 意味着什么？

每花一美元只换来 80 美分的计划工作，因此每单位工作的成本是其预算的 1 / 0.8 = 1.25 倍。如果这种情况持续下去，项目最终将超出预算 25%：$500,000 的预算将变成 $625,000。

CPI 高于 1 总是好事吗？

不一定。它可能意味着真正的高效率，但也可能意味着成本遗漏、进度夸大、估算虚高，或者昂贵的工作还在后面。对偏高和偏低的 CPI 都要进行调查。

多少 CPI 算好？

CPI 接近 1.0。各组织在成本管理计划中设定自己的限值，例如将 0.95 至 1.05 视为可接受，低于 0.90 则升级。没有通用标准。

CPI 和 SPI 有什么区别？

CPI = EV / AC 衡量成本效率。SPI = EV / PV 衡量进度效率：已完成多少计划工作。两者都使用挣值，应结合起来解读。

CPI 与成本偏差有什么区别？

两者都使用 EV 和 AC。成本偏差是金额上的差值（EV - AC）；CPI 是比率（EV / AC）。成本偏差为负总是意味着 CPI 低于 1。

如何使用 CPI 预测 EAC？

最常用的公式是 EAC = BAC / CPI，它假设当前的成本效率将持续下去。BAC 为 $500,000、CPI 为 0.967 时，EAC 约为 $517,300。其他公式使用 CPI x SPI 或自下而上的重新估算。

应该使用累计 CPI 还是当期 CPI？

两者都用。累计 CPI 更稳定，用于预测。当期 CPI 显示近期绩效，能更早地揭示问题或改进。

什么是 TCPI？它与 CPI 有何不同？

CPI 回顾的是迄今已实现的效率。TCPI 着眼未来：剩余工作为实现目标所需的效率，TCPI = (BAC - EV) / (BAC - AC)。如果 TCPI 远高于 CPI，目标就不太可能实现。

CPI 在完成 20% 后会稳定下来吗？

对美国大型国防合同的研究（Christensen 和 Heise，1993）发现，累计 CPI 通常从完成约 20% 起就保持稳定。后来的研究质疑这一结论在多大程度上适用于其他项目，因此应将其视为及早行动的警示，而不是保证。

成本绩效指数与消费者价格指数是一回事吗？

不是。两者的缩写都是 CPI，但消费者价格指数衡量的是经济中的通货膨胀，而成本绩效指数衡量的是项目的成本效率。
