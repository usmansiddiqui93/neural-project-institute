项目成本效益分析：步骤与示例

成本效益分析（CBA）将项目的预期总成本与预期总收益进行比较，以决定项目是否值得开展，或在多个方案中哪一个最佳。好的 CBA 会为各时期的成本和收益赋予货币价值，并将未来金额折现为当前价值。

要点总结

  • CBA 以货币形式比较所有成本和收益。
  • 对未来金额进行折现，并纳入“不采取行动”方案。
  • NPV 大于零且 BCR 大于 1，表明项目值得开展。
  • 使用敏感性分析检验关键假设。

何时使用成本效益分析

  • 构建商业论证或 可行性研究.
  • 在备选解决方案或供应商之间进行选择。
  • 决定是否批准一项重大的 变更请求.
  • 对组合中的项目进行优先级排序。

应纳入的成本和收益

成本优势
初始投资：人工、硬件、软件、费用额外收入
运行成本：支持、许可证、维护成本节约
培训和变革管理避免的成本，例如罚款或停机损失
变革期间的业务中断更快的交付或更好的质量
退役处置无形收益：满意度、声誉、士气

如何进行成本效益分析

  1. 明确决策和各个方案，包括不采取行动。
  2. 在商定的期间内列出每个方案的所有成本和收益。
  3. 为每一项赋予货币价值，并单独注明无形收益。
  4. 使用商定的折现率对未来金额进行折现；参见 净现值.
  5. 计算净收益（收益现值 - 成本现值）和效益成本比（收益现值 / 成本现值）。
  6. 检验关键假设，使用 敏感性分析.
  7. 推荐一个方案，并说明假设和风险。

计算示例

一套新的预订系统前期成本为 $120,000，另加每年 $10,000 的运行成本。它每年可节省 $60,000。分析采用三年期限和 8% 的折现率（三年期年金系数为 2.5771）。

未折现现值
成本120,000 + 3 x 10,000 = $150,000120,000 + 10,000 x 2.5771 = $145,771
优势3 x 60,000 = $180,00060,000 x 2.5771 = $154,626
净收益（NPV）$30,000$8,855
效益成本比1.20154,626 / 145,771 = 1.06

该项目值得开展，因为 BCR 大于 1 且 NPV 为正，但折现后的盈余很薄，因此必须对节约估算进行敏感性测试。

度量接受条件

投资回收期短于允许的最长期限

常见陷阱

  • 计入了无论如何都会发生的收益。
  • 遗漏运行、培训或业务中断成本。
  • 在多年期间忽略货币的时间价值。
  • 以不同名称重复计算同一项收益。
  • 只给出一个数字，却不检验其假设。

常见问题

什么是成本效益分析？

以货币形式比较项目的预期总成本与预期总收益，以决定项目是否值得开展。

成本效益分析中的效益成本比是什么？

收益现值除以成本现值。比率大于 1 表示收益超过成本。

在成本效益分析中如何计算净收益？

净收益 = 总收益 - 总成本，最好使用现值计算，由此得到 NPV。

为什么要在成本效益分析中对未来的成本和收益进行折现？

未来收到的钱不如今天的钱值钱，因此通过折现可以使不同时间点的金额具有可比性。

在成本效益分析中应使用什么折现率？

通常使用财务团队设定的折现率，一般以组织的资本成本或要求的回报率为基础。

在成本效益分析中如何处理无形收益？

在合理的情况下估算其货币价值，否则单独列出，并在数字旁边清楚地加以描述。

成本效益分析和 ROI 有什么区别？

CBA 权衡所有成本和收益，通常以 NPV 或 BCR 表示。ROI 则将净收益表示为成本的百分比。

成本效益分析应该包含“不采取行动”方案吗？

应该。它提供了一个基准，而且什么都不做往往也有其自身的成本。

谁来编制成本效益分析？

通常由项目经理或业务分析师与财务部门共同编制，交由发起人审阅。

CBA 在项目中处于什么位置？

在商业论证和可行性研究阶段使用，在考虑重大变更时再次使用。

成本效益分析有哪些局限性？

它在很大程度上依赖对未来收益的估算，而这些估算可能不确定或过于乐观。
