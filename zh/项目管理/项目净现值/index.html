净现值（NPV）：公式、示例与用途

净现值（NPV）是项目在整个生命周期内预期支出和收入的全部现金按今天币值计算的价值。您按要求的回报率对每笔未来现金流进行折现并相加：如果总和为正，则预期该项目的收益将高于该回报率并创造价值。本指南通过一个完整的实例、对竞争项目的比较以及需要避免的电子表格陷阱，逐步向您展示如何计算 NPV。

要点总结

  • NPV = 每期现金流除以 (1 + r)^t 之和，其中第 0 年投资按面值计入。
  • NPV 为正意味着项目超过了要求的回报率；在互斥方案之间，NPV 较高者通常胜出。
  • 折现率是一项业务决策：从财务部门获取，并在所比较的所有项目中保持一致。
  • NPV、IRR、投资回收期和 ROI 对同一组项目的排序可能不同；NPV 是衡量所创造价值最可靠的指标。
  • 务必测试敏感性：显示收益能下降多少或成本能上升多少，NPV 才会转为负值。
  • 在 Excel 和 Google Sheets 中，=NPV() 假定第一个值发生在一年后，因此请单独加上第 0 年的现金流。

什么是净现值（NPV）？

净现值（NPV） 是项目未来现金流入和流出（每笔都折现到今天的价值）之和减去初始投资。折现使用要求的回报率，即折现率。NPV 为正意味着预期项目的回报高于该折现率；NPV 为负意味着预期回报低于该折现率。

NPV 背后的理念是 货币的时间价值。今天的 $1 比三年后的 $1 更值钱，原因有三：

  • 机会成本。 您现在拥有的钱可以投资到其他地方并获得回报。
  • 通货膨胀。 价格往往上涨，因此未来的钱通常能买到的东西更少。
  • 风险。 承诺的未来收益可能无法全额实现，甚至完全无法实现。

折现是复利的逆运算。如果按 8% 投资 $7,938，三年后会增长到 $10,000（7,938 x 1.08^3），那么三年后收到的 $10,000 大约相当于 今天的 $7,938 （按 8% 的折现率）。NPV 将这一逻辑应用于项目的每一年，并把结果汇总为一个数值。

在项目工作中，NPV 通常出现在 商业论证 以及在 项目选择。它帮助发起人或投资组合委员会回答一个问题：在考虑了时间和资金成本之后，这项投资的价值是否高于其成本？它与我们的指南中介绍的其他评估指标并列： 成本效益分析 和 投资回报率.

NPV 公式

NPV = CF0 + CF1 / (1 + r)^1 + CF2 / (1 + r)^2 + ... + CFn / (1 + r)^n

或者写成求和形式： NPV = CFt / (1 + r)^t 之和，t = 0 至 n.

符号含义示例
CFt第 t 期的净现金流（流入减去流出）第 0 年 -$250,000；第 2 年 +$80,000
CF0当前的现金流，通常为初始投资（负值）-$250,000
r每期折现率，以小数表示9% = 0.09
t期数；0 为今天，1 为第一年年末0, 1, 2 ... n
n评估中的期数5 年

您经常会看到该公式写成“折现现金流之和减去初始投资”。这是同一种计算：第 0 年的现金流不折现，因为 (1 + r)^0 = 1。

标准公式假设每笔现金流发生在 结束 （每期期末）。如果收益在全年中平稳到达，期末惯例会略微低估收益。对于商业论证而言这通常可以接受，但应说明这一假设；当时间确实很重要时，请使用按月划分的期间或带日期的现金流（XNPV）。

如何逐步计算 NPV

  1. 定义方案。 纳入“什么都不做”或“最低限度”的基准方案。NPV 衡量的是项目带来的差异，因此您需要一个比较对象。
  2. 选择评估期。 使用资产或解决方案的使用寿命，业务变革和 IT 项目通常为三到十年。基础设施则更长。
  3. 列出每一期的现金流。 包括资本成本、实施成本、运营成本、节约、新增收入以及任何残值。请使用您的 成本估算 ，用于成本部分。
  4. 按期计算净额。 第 0 年、第 1 年、第 2 年等各年的流入减去流出。
  5. 与财务部门商定折现率。 使用组织的最低预期收益率或资本成本，并检查它是实际折现率还是名义折现率（见下文）。
  6. 计算每一期的折现系数： 1 / (1 + r)^t.
  7. 将每笔净现金流乘以其系数 ，即可得到其现值。
  8. 将现值相加。 总和即为 NPV。
  9. 测试敏感性。 分别按更高和更低的折现率、更低的收益和更高的成本以及延迟启动重新计算。
  10. 记录假设 ，以便评审人员提出质疑，并可在每个阶段关口再次核查数值。

现金流中应包含哪些内容

大多数 NPV 错误来自现金流中纳入了什么，而不是算术。请使用 增量现金 （因项目而发生变化的现金），而不是会计利润。

包括排除
资本支出：设备、软件、建设成本已花费的沉没成本，例如去年的可行性研究
实施：人工、承包商、培训、数据迁移折旧和摊销（非现金项目；应计入购置支出）
运营成本：许可证、维护、支持、额外人员贷款利息等融资成本（折现率已反映资金成本）
节约：人工、材料、避免的成本、停用的系统无论如何都要支付的间接费用
新增收入或利润无法与项目关联的收益
机会成本，例如使用一栋本可以出租的建筑重复计算的收益（同一项节约被两个项目申报）
残值或转售价值，以及寿命终结或退役成本

税务影响（资本减免带来的税收优惠、额外利润的税负）属于完整的企业评估范畴。如果不确定如何处理，请咨询财务部门，而不是悄悄将其排除。

实例：仓库自动化项目

一家分销公司正在考虑一个仓库自动化项目。财务部门设定的折现率为 9% ，适用于此类风险的项目。

  • 第 0 年： $250,000，用于设备、软件、安装和培训。
  • 第 1 年： 净现金流 $45,000。在团队爬坡期间，人工和差错节约较少，再扣除维护和许可证费用。
  • 第 2 至 4 年： 系统全面投入使用后，净现金流分别为 $80,000、$85,000 和 $85,000。
  • 第 5 年： $85,000 的净节约，外加 残值 $20,000 （设备的），即 $105,000。

​ NPV 约为 $52,713。所有未来净现金流的现值为 $302,713，高于 $250,000 的投资额。该项目的预期年回报率超过 9%，并按今天的币值计算增加约 $52,700 的价值。

该表还告诉您什么

  • 未折现收益： 总净现金为 $400,000，而支出为 $250,000，盈余 $150,000，简单 ROI 为 60%。折现后收益降至约 $52,700，这表明在五年期间时间因素有多么重要。
  • 投资回收期： 累计未折现现金在第四年内转为正值，约在 3.5 年 (3 + 40,000 / 85,000).
  • 折现投资回收期： 累计现值在第五年内转为正值，约在 4.2 年 （4 + 15,529 / 68,243）。项目直到最后一年才超过 9% 的最低预期收益率，因此残值和第五年的节约至关重要。
  • IRR： 使 NPV 等于零的折现率约为 15.9%，远高于 9% 的最低预期收益率。
提示

请注意，如果没有 $20,000 的残值，NPV 会降至约 $39,700。残值往往是猜测。请同时显示包含和不包含残值的 NPV，让决策者看到结果在多大程度上取决于这一假设。

解读结果

NPV含义典型决策
正数回报超过要求的回报率；项目创造价值接受，但需考虑风险、战略和资金
零回报恰好等于要求的回报率财务上中性；根据非财务因素做出决策
负数回报低于要求的回报率以财务理由否决，除非存在强制性、监管或战略方面的原因

NPV 为负并不总是意味着“不要做”。合规项目、安全工作和替换不再受支持的系统，NPV 往往为负，但仍然是必要的。在这种情况下，NPV 帮助您选择 成本最低的 满足需求的方式：比较各方案，选择 NPV 最高（负值最小）的方案。

多少 NPV 才算好？

从项目超过最低预期收益率的意义上说，任何正 NPV 都是好的。但数值的大小取决于项目的规模。对于 $100,000 的投资，$50,000 的 NPV 非常出色；对于 $500 万的投资，则只是勉强过关。有两种方法可以为其提供参照：

  • 盈利指数（PI） = 未来现金流现值 / 初始投资。在本例中，PI = 302,713 / 250,000 = 1.21：每投资 $1，按今天的币值可收回 $1.21。PI 大于 1 意味着 NPV 为正。
  • 余量： 关键假设能变动多少，NPV 才会降至零。收益下降 20% 后 NPV 仍为正的项目，比下降 5% 就转为负值的项目更稳健。

应信任哪个指标

  • 互斥方案 （只能选择其一，例如替换同一系统的三种方式）：选择 NPV 最高，此处为 B。当项目在规模或时间上存在差异时，IRR 可能产生误导，因为小额投资的高百分比回报，其价值可能低于大额投资的较低百分比回报。
  • 预算有限，有多个独立项目 （资本限额）：按以下指标排序 盈利指数 ，并沿着列表依次拨款，直至预算用完。这样可以使每一美元可用资金的总 NPV 最大化。
  • 资金受限或高度不确定的情况： 投资回收期是一项有用的辅助检查。项目 B 的收益严重依赖第四年和第五年，因此要问一问您对这些收益有多大把握。在 15% 的折现率下，B 的 NPV 仍约为 $13,400，而 A 的降至约 $2,000，因此 B 是两者中更稳健的一个。

在投资组合中确定优先级还涉及战略、风险和产能，而不仅仅是 NPV。

NPV 与 IRR、ROI 和投资回收期的比较

度量反映的信息考虑货币的时间价值？主要优势主要弱点
NPV按今天币值计算的所创造价值有直接衡量价值；可跨项目相加需要折现率；对部分受众而言不够直观
IRR使 NPV = 0 的回报率有易于与最低预期收益率比较在规模和时间上可能产生误导；当现金流不止一次改变符号时可能得出多个结果

投资回收期收回投资所需的时间否（折现投资回收期：是）显示流动性和风险敞口忽略回收期之后的一切
盈利指数每投资 $1 的收益现值有在预算限制下对项目排序在只能选择一个项目时可能偏向小项目

合理的商业论证以 NPV 作为主要指标，并以 IRR、投资回收期和简单 ROI 作为辅助数据，供偏好这些指标的读者参考。我们的 投资回报率指南 展示了如何计算项目的 ROI 和折现 ROI。

NPV 和 IRR 详解

IRR 是使 NPV 恰好为零的折现率。在仓库示例中，NPV 在 9% 和 15% 时为正，在略高于 15.9% 时转为负。如果最低预期收益率低于 IRR，NPV 为正；如果高于 IRR，NPV 为负。对于单个常规项目（先流出、后流入），NPV 和 IRR 总是给出相同的接受或拒绝结论。只有在对规模或时间不同的项目进行排序时（如上面的比较），两者才会冲突。

选择折现率

折现率对 NPV 的影响几乎超过其他任何输入，而且这不是项目经理一个人能决定的。在大多数组织中，它由财务部门提供。典型来源：

  • 资本成本。 企业通常以加权平均资本成本（WACC），即债务和股权的综合成本，作为起点。
  • 最低预期收益率。 许多组织会设定高于资本成本的最低要求回报率，有时对新产品或新市场等风险较高的类别采用更高的折现率。
  • 风险调整折现率。 风险较高的项目采用较高的折现率。不要再因同一风险削减现金流，否则会重复计算。
  • 公共部门折现率。 各国政府会公布用于评估公共支出的折现率。HM Treasury 的《绿皮书》在前 30 年采用 3.5% 的实际折现率，更长期限则逐步降低。2026 年 6 月发布的一项独立审查建议采用 3%（核查于 2026 年 10 月 25 日）。在使用任何一个数值之前，请查阅现行的《绿皮书》指南。

实际或名义：保持一致

A 名义 折现率包含通胀； 实际 折现率则不包含通胀。名义现金流（已计入预期的价格上涨）应使用名义折现率，按当前价格计算的现金流应使用实际折现率。混用两者是常见错误。作为近似值，名义折现率 9%、通胀率 2.5% 时，实际折现率约为 6.3%（1.09 / 1.025 - 1）。

按月或按季度划分期间

如果按月对现金流建模，请换算年折现率，而不是直接除以 12。年利率 9% 对应的月利率为 (1.09)^(1/12) - 1 = 每月 0.72%，而不是 0.75%。

如何在 Excel 和 Google Sheets 中计算 NPV

Excel 和 Google Sheets 都有语法相同的 NPV 函数： =NPV(rate, value1, [value2], ...)。问题在于，它将 将第一个值视为一期之后到达。它用于第 1 至 n 年，而不是第 0 年。

假设仓库示例位于单元格 B2:B7 中，第 0 年在 B2，折现率（9%）在 E1。

公式结果是否正确？
=NPV(E1, B3:B7) + B2$52,713是：第 1-5 年折现，第 0 年按面值加入
=NPV(E1, B2:B7)$48,361否：每笔现金流都多折现了一年
=IRR(B2:B7)15.9%是：IRR 使用包括第 0 年在内的完整区域

错误的做法会使 NPV 恰好少算一年的折现（$52,713 / 1.09）。这是商业论证中最常见的电子表格错误，因此每当审查他人的模型时都要检查这一点。

不规则日期：XNPV 和 XIRR

如果现金流发生在特定日期而非规整的期间，请使用 =XNPV(rate, values, dates) 和 =XIRR(values, dates)。XNPV 以一年 365 天、从第一个日期开始对每个值进行折现，第一个值不折现，因此应将第 0 年纳入范围。这两个函数在 Excel 和 Google Sheets 中都可用。

NPV 的优点和局限

优势

  • 与简单 ROI 和投资回收期不同，它考虑了货币的时间价值。
  • 给出一个显示所创造价值的单一金额。
  • 独立项目的 NPV 可以相加，这有助于投资组合规划。
  • 使用评估期内的每一笔现金流，而不仅仅是回收期之前的现金流。
  • 适用于任何现金流模式，包括中间出现负值的年份。

局限

  • 对折现率敏感，而折现率是一种判断。
  • 依赖可能过于乐观的现金流预测，尤其是收益预测。
  • 可能看起来比输入数据所能支撑的更精确；务必给出一个区间。
  • 无法体现难以定价的收益，例如客户体验、员工福祉或战略选择权。应将这些与 NPV 一并说明，而不是强行量化。
  • 可能对收益在多年后才实现的长期项目不利。
  • 本身不能显示投资规模，因此应与 PI 或初始成本搭配使用。

NPV 的常见错误

  • 对第 0 年的投资进行折现，或在电子表格中对整个区域使用 =NPV()。
  • 使用利润而不是现金流，这会引入折旧和时间差异。
  • 计入沉没成本 ，无论您做出何种决定都不会改变。
  • 重复计算融资成本，既在现金流中作为利息计入，又在折现率中再次计入。
  • 混用实际和名义 数据和费率。
  • 对月度现金流使用年折现率，或将年折现率除以 12。
  • 遗漏运营、升级或退役成本，这些往往在上线之后才出现。
  • 收益中的乐观偏差：假设从第一天起就获得全部收益，而没有爬坡期。
  • 比较寿命不同的方案 而不做调整。请使用相同的期限或等值年金。
  • 按 IRR 在互斥方案之间做选择 ，而不是 NPV。
  • 只给出一个数字 ，而没有敏感性分析、情景或关键假设。

常见问题

简单来说，什么是净现值？

它是项目未来现金在今天的价值减去项目成本。每笔未来金额都会被缩减（折现），以反映现在的钱比将来的钱更值钱这一事实。如果结果为正，则预期该项目在所选回报率下能够创造价值。

NPV 为正意味着什么？

项目的折现现金流入超过其折现现金流出，因此预期收益将高于折现率。它能创造价值，但您仍需权衡风险、战略和可用资金。

NPV 为负意味着什么？

预期该项目无法达到要求的回报率。出于监管、安全或战略原因，它仍可能继续推进；此时 NPV 可帮助您选择成本最低的方案。

多少 NPV 才算好？

任何大于零的 NPV 都超过了最低预期收益率。要判断其好坏，可使用盈利指数将其与投资规模进行比较，并检查假设能变化多少，NPV 才会降至零。

NPV 应使用什么折现率？

使用财务团队设定的折现率，通常以组织的资本成本或最低预期收益率为基础，有时会根据风险进行调整。公共部门项目使用公开发布的折现率，例如英国 HM Treasury《绿皮书》（Green Book）规定的折现率。对所比较的所有方案使用相同的折现率。

NPV 和 IRR 有什么区别？

NPV 是给定折现率下的货币价值。IRR 是使 NPV 等于零的折现率。对于单个常规项目，两者会给出相同的接受或拒绝决策；但在对规模或时间不同的互斥项目进行排序时，应以 NPV 为准。

NPV 和 ROI 有什么区别？

简单 ROI 用净收益除以成本，忽略了收益何时到来。NPV 按时间对每笔现金流进行折现，因此能区分第一年收回投资的项目与第五年才收回投资的项目。

为什么 NPV 优于投资回收期？

投资回收期忽略了货币的时间价值以及回收点之后的所有现金流。NPV 计入评估期内的所有现金流并进行折现。投资回收期仍可作为检查流动性和风险敞口的辅助指标。

如何在 Excel 中计算 NPV？

输入 =NPV(折现率, 第 1 年至第 n 年的现金流)，并单独加上第 0 年的现金流，例如 =NPV(9%, B3:B7) + B2。对于带日期的现金流，请使用 =XNPV(rate, values, dates)，它会将第一个值不折现地计入。

NPV 可以用于非营利或公共部门项目吗？

可以。公共机构经常使用 NPV；当其中包含以货币计量的非现金收益时，有时称为净现值社会价值（net present social value）。它们使用公开发布的社会折现率，例如英国的《绿皮书》折现率。

NPV 中应该考虑通胀吗？

应该，但要保持一致。要么在现金流预测中考虑通胀并使用名义折现率，要么使用当前价格并采用实际折现率。不要混用两者。

沉没成本是否计入 NPV？

不计入。无论您做出何种决定，已花费的钱都无法收回，因此应排除在外。只有取决于该决策的未来增量现金流才应纳入计算。

PMP 考试会考 NPV 吗？

NPV、IRR、投资回收期和效益成本比等项目选择指标常见于 PMP 和 CAPM 备考资料中，通常停留在概念层面：选择哪个方案，而不是冗长的计算。具体范围请查阅 PMI 现行的考试内容大纲。

什么是盈利指数？

未来现金流的现值除以初始投资。PI 大于 1 意味着 NPV 为正。当预算无法为所有独立项目提供资金时，它可用于对这些项目进行排序。
