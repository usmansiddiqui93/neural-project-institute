项目净现值（NPV）：公式与示例

净现值（NPV）是指一个项目未来所有现金流入和流出按今天的货币计算的总价值。未来现金流按选定的比率进行折现；如果结果为正，则预计该项目创造的价值将超过其成本。

  • 阅读时长 3 分钟

要点总结

  • NPV 将未来现金流折现为今天的货币价值。
  • 折现系数 = 1 / (1 + r)^t。
  • 接受 NPV 为正的项目；在备选方案之间优先选择 NPV 较高者。
  • 始终要测试结果对折现率和现金流估算的敏感性。

公式

NPV = [第 t 年现金流 / (1 + r)^t] 之和 - 初始投资

  • r 是每期的折现率，例如 8%（0.08）。
  • t 是期数，第一年年末为 1。
  • ​ 折现系数 第 t 年的折现系数为 1 / (1 + r)^t。

计算示例

某项目当前成本为 $100,000，在接下来三年中每年年末回报 $40,000。折现率为 8%。

决策规则

NPV决定
正数接受：项目收益高于要求的回报率
零在要求的回报率下实现盈亏平衡
负数出于财务原因拒绝，除非有充分的非财务理由

在比较互斥项目时，假设风险相近，应优先选择 NPV 较高的项目。

NPV 与 IRR

内部收益率（IRR）是使 NPV 等于零的折现率。在本例中，IRR 约为 9.7%：高于 8% 的要求回报率（因此 NPV 为正），但低于 10%（因此 NPV 为负）。可以将 IRR 与 NPV 结合使用，但在互斥方案的选择上两者结论不一致时，应以 NPV 为准。

如何逐步计算 NPV

  1. 列出每一期的现金流，包括初始投资。
  2. 与财务部门商定折现率。
  3. 计算每一期的折现系数：1 / (1 + r)^t。
  4. 将每笔现金流乘以其折现系数。
  5. 将各现值相加。
  6. 检查结果对折现率和现金流的敏感性；参见 敏感性分析.

常见错误

  • 对第 0 年的投资进行折现。
  • 使用利润而不是现金流。
  • 忽略运营成本或报废成本。
  • 使用不一致的期间（按月的现金流配以年利率）。
  • 请注意，Excel 的 NPV 函数假定第一个值位于第一期期末，因此需要单独加上第 0 年的现金流出。

常见问题

什么是净现值？

项目未来现金流折现到当前价值后的总和减去初始投资。

NPV 为正意味着什么？

预计该项目的收益将高于要求的回报率，因此它能增加价值。

NPV 为负意味着什么？

按选定的折现率计算，项目以今天货币计算的回报无法覆盖其成本。

如何计算 NPV 的折现系数？

折现系数 = 1 / (1 + r)^t。折现率为 8% 时，第二年的折现系数为 1 / 1.1664 = 0.85734。

NPV 应使用什么折现率？

通常是由财务部门设定的比率，一般基于资本成本或要求的回报率，有时会根据风险进行调整。

NPV 和 IRR 有什么区别？

NPV 是在给定折现率下的货币价值。IRR 是使 NPV 等于零的折现率。

NPV 和 ROI 有什么区别？

NPV 考虑了现金流的时间；简单 ROI 则不考虑。参见 投资回报率.

如何在 Excel 中计算 NPV？

使用 =NPV(rate, 第 1 年至第 n 年的现金流)，然后加上第 0 年的现金流（通常为负数）。

NPV 是否用于项目选择？

是的，它是商业论证和组合决策中最常用的财务指标之一。

为什么在净现值中未来的钱价值更低？

因为今天的钱可以用于投资并获得回报，同时还存在通货膨胀和风险因素。

PMP 考试会考 NPV 吗？

NPV、IRR 和投资回收期等项目选择方法通常会在 PMP 备考资料中以概念层面进行介绍。
