完工估算（EAC）：公式、示例与技巧

完工估算（EAC）是对所有工作完成时项目总成本的预测。它将已经花费的金额与剩余工作的成本估算结合在一起。

作者Neural Project Institute项目管理编辑团队
  • 发布于 2026 年 9 月 29 日
  • 阅读时长 3 分钟

要点总结

  • EAC 预测完工时的总成本。
  • 选择与偏差原因相匹配的公式。
  • ETC = EAC - AC；VAC = BAC - EAC；TCPI 显示所需的效率。
  • 报告 EAC 的区间，而不是单一数字。

四个 EAC 公式

公式适用情况
EAC = BAC / CPI预计当前的成本绩效将持续下去（典型偏差）
EAC = AC + (BAC - EV)过去的偏差是一次性的；剩余工作将按计划进行（非典型偏差）
EAC = AC + (BAC - EV) / (CPI x SPI)成本绩效和进度绩效都会影响剩余工作，例如有固定的结束日期
EAC = AC + 自下而上的 ETC原计划已不再有效，需要重新估算剩余工作

相关预测

  • 完工尚需估算（ETC） = EAC - AC：仍需投入的资金。
  • 完工偏差（VAC） = BAC - EAC：预期的节约或超支。
  • TCPI（以 BAC 为目标） = (BAC - EV) / (BAC - AC)：按预算完工所需的效率。
  • TCPI（以 EAC 为目标） = (BAC - EV) / (EAC - AC)：实现预测所需的效率。

计算示例

BAC = $200,000，PV = $80,000，EV = $70,000，AC = $85,000。因此 CPI = 0.8235，SPI = 0.875。剩余工作 = BAC - EV = $130,000。

公式计算EACVAC
BAC / CPI200,000 / 0.8235$242,857-$42,857
AC + (BAC - EV)85,000 + 130,000$215,000-$15,000
AC + (BAC - EV) / (CPI x SPI)85,000 + 130,000 / 0.7206$265,408-$65,408
AC + 自下而上的 ETC85,000 + 140,000$225,000-$25,000

使用典型公式，ETC = 242,857 - 85,000 = $157,857。实现 BAC 所需的 TCPI = 130,000 / 115,000 = 1.13，而实现 $242,857 这一 EAC 所需的 TCPI = 130,000 / 157,857 = 0.82，恰好与当前的 CPI 相同。

选择合适的 EAC

  1. 找出偏差发生的原因。
  2. 如果原因持续存在（例如费率高于计划），请使用 BAC / CPI。
  3. 如果是一次性的（例如某个供应商的单次失误），请使用 AC + (BAC - EV)。
  4. 如果必须按固定日期完成且进度已经落后，请考虑使用 CPI x SPI 公式。
  5. 如果假设发生了重大变化，请自下而上地重新估算剩余工作。
  6. 报告一个区间：将各公式结合起来，可以得出从最好到最坏的有用范围。

常见错误

  • 以为超支会神奇地自行恢复（默认使用 AC + (BAC - EV)）。
  • 只使用早期的单次 CPI 读数；应等待趋势形成。
  • 忽略尚未开具发票的已承诺成本。
  • 将 EAC 与 BAC 或资金上限混为一谈。

常见问题

什么是完工估算？

所有工作完成时项目的预测总成本，缩写为 EAC。

最常用的 EAC 公式是什么？

EAC = BAC / CPI，假设当前的成本效率将持续下去。

EAC 和 ETC 有什么区别？

EAC 是预测的总成本；ETC 是剩余工作的预测成本。EAC = AC + ETC。

什么时候应该使用 EAC = AC + (BAC - EV)？

当过去的偏差是一次性的，并且您预计剩余工作将按计划进行时。

什么时候应该使用 CPI x SPI 的 EAC 公式？

当进度压力可能影响成本时，例如固定截止日期意味着需要额外投入来追赶进度。

如何使用 EAC 计算 VAC？

完工偏差 = BAC - EAC。VAC 为负表示预测的超支额。

以 EAC 为目标时，TCPI 大于 1 意味着什么？

剩余工作必须比计划更高效地完成，才能实现目标。远大于 1 的数值往往不切实际。

EAC 应多久更新一次？

每个报告期更新，与其他挣值指标一并更新。

EAC 可以低于 BAC 吗？

可以。如果 CPI 大于 1，则预测项目完工时将低于预算。

自下而上的 EAC 比公式更好吗？

当计划发生重大变化时，通常是这样，因为它反映了当前的认识。公式则更快捷，可作为交叉核对的工具。

EAC 与项目预测有何不同？

EAC 是以下内容中的成本部分： 项目预测，后者还涵盖完工日期和收益。
