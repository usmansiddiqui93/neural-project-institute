完工估算（EAC）：公式与示例

完工估算（EAC）是对项目在全部工作完成后总成本的预测。它等于迄今为止的实际成本加上剩余工作的估算成本，最常用的简便公式是 EAC = BAC / CPI。

要点总结

  • EAC 是项目的预测总成本：EAC = AC + ETC。
  • 共有四个标准公式；请选择与偏差原因相符的公式。
  • BAC / CPI 假设当前的成本效率将保持不变；AC + (BAC - EV) 假设剩余工作将按计划进行。
  • VAC = BAC - EAC 显示预期超支；TCPI 显示达到目标所需的效率。
  • 报告一个 EAC 区间并说明您首选数字的理由，而不是只给出一个数字。
  • 每个报告期都更新 EAC，并在其偏离预算时尽早采取行动。

什么是完工估算（EAC）？

完工估算（EAC） 是项目（或某个工作包或控制账户）在全部工作完成时的预期总成本。其计算方法是迄今为止的实际成本加上完工尚需估算（EAC = AC + ETC）。将 EAC 与完工预算（BAC）进行比较，可以显示项目是将会超支还是结余。

EAC 是以下领域中的预测指标之一： 挣值管理。其他指标告诉您项目目前所处的状态： 成本绩效指数 显示成本效率，而 成本偏差 和 进度偏差 显示您与计划的差距。EAC 则将这些历史数据转化为对最终账单的预测。

关键的区别在于 EAC 与 BAC。 完工预算 是全部工作的批准预算，只能通过正式的变更控制进行调整。EAC 是您当前的最佳预测，每个报告期都可能变化。当 EAC 偏高于 BAC 时，这一差距就是一个需要做出决策的警示，而不只是报告中的一条备注。

在 PMI 的《PMBOK 指南》中，预测属于成本控制的范畴。在第八版（2025 年底发布）中，成本工作归入 财务 绩效域，其过程包括监控财务。这些公式本身是 PMI 各项标准和大多数项目控制指南中沿用已久的挣值公式。

所需的输入数据

每个 EAC 公式都由少数几个挣值数据构成。请先确保这些数据正确；把精确的公式应用于质量不佳的数据，只会得到一个看似精确的错误答案。

术语含义计算方法
BAC：完工预算该工作的批准预算总额成本基准的总和
PV：计划价值截至目前计划工作的预算成本来自分时段的基准
EV：挣值实际已完成工作的预算成本完成百分比 x BAC
AC：实际成本已完成工作的真实花费来自工时表、发票和应计费用
CPI：成本绩效指数迄今为止的成本效率EV / AC
SPI：进度绩效指数迄今为止的进度效率EV / PV
ETC：完工尚需估算剩余工作的预期成本EAC - AC，或重新估算

有两个数据点最为重要。 EV 取决于如实的进展测量：如果任务连续数周被报告为完成 80%，EV 就会虚高，每一项预测都会显得比实际更好。请在 工作包 层面商定客观的规则，例如短任务采用 0/100 或 50/50 法则，较长任务采用里程碑法。 AC 必须包括已发生但尚未开票的成本，例如应计的承包商工时，否则项目看起来会比实际更省钱。

PV 背后的分时段基准通常绘制为 S 曲线.

四个 EAC 公式

PMI 的挣值指南介绍了预测 EAC 的四种标准方法。每种方法对剩余工作的绩效表现做出不同的假设。

公式假设条件典型应用
EAC = BAC / CPI当前的成本效率将持续下去偏差原因持续存在（典型偏差）
EAC = AC + (BAC - EV)剩余工作将按预算费率完成偏差是一次性的（非典型偏差）
EAC = AC + (BAC - EV) / (CPI x SPI)成本和进度绩效都会影响剩余工作进度落后，但仍必须满足固定日期
EAC = AC + 自下而上的 ETC原有估算已不再有效范围、费率或方法发生了重大变化

1. EAC = BAC / CPI（典型偏差）

这是最常用的公式，也是许多工具的默认公式。它假设项目在剩余的生命周期内将以相同的效率支出。如果团队每花费 1 美元只交付 82 美分的价值，该公式就假设这种情况会持续下去。它在数学上等同于 EAC = AC + (BAC - EV) / CPI。

当超支原因是结构性的时使用它：人工费率高于计划、生产率低于估算，或某种复杂性影响到所有剩余工作。一旦完成了相当比例的工作，累计 CPI 的变化往往很慢，因为每个新周期对总量的影响都很小。正因如此，许多项目控制人员将这个公式视为现实的基准预测。

2. EAC = AC + (BAC - EV)（非典型偏差）

这个公式将剩余工作的原始预算与已花费的金额相加。它假设过去的偏差是一次性的，不会再次发生：例如供应商违约、一次返工或一次性的价格上涨。

当项目超出预算时，它是四个公式中最乐观的一个，因此只有在您能解释原因为何已经消除时才使用它。因为它得出的数字最小就默认使用它，是最常见的预测错误之一。

3. EAC = AC + (BAC - EV) / (CPI x SPI)

这个版本同时根据成本绩效和进度绩效调整剩余工作。它适用于进度落后且结束日期固定的项目，在这种情况下，追赶进度意味着加班、增加人手或加急交付，而这些都会增加成本。

由于项目延误时 CPI x SPI 小于 CPI，因此在两个指数都低于 1 时，这个公式通常得出最高的 EAC。有些组织会使用 加权版本，例如 AC + (BAC - EV) / (0.8 x CPI + 0.2 x SPI)，让进度压力产生一定影响但又不起主导作用。权重属于组织内部惯例，而非标准，因此请在您的以下文件中加以说明： 成本管理计划.

4. EAC = AC + 自下而上的 ETC

这种方法不使用指数，而是根据当前对范围、费率和风险的了解，逐项任务自下而上地重新估算剩余工作。它最费工夫，但在计划发生变化时往往最可信，例如重新设计、更换供应商、已批准的范围变更或交付方式发生根本改变。

自下而上的 ETC 使用与原始估算相同的技术；参见 成本估算 和 工作量估算.

如何分步计算 EAC

  1. 确认 BAC。 使用当前已批准的预算，包括所有已批准的变更。不包括管理储备，因为它位于绩效基准之外。
  2. 测量 EV。 对每个工作包应用商定的完成百分比规则，然后加总。
  3. 收集 AC。 包括已完成工作所发生的全部成本，包括与已完成工作相关的应计费用和已承诺成本。
  4. 找出 PV。 从基准中读取截至状态日期的计划价值。
  5. 计算 CPI 和 SPI。 CPI = EV / AC；SPI = EV / PV。
  6. 用公式计算 EAC。 计算全部三个基于指数的公式；一旦获得输入数据，只需几秒钟。
  7. 查明偏差发生的原因。 这决定了哪个公式最符合实际。
  8. 如果计划已发生变化，请编制自下而上的 ETC ，或在各公式结果差异很大时这样做。
  9. 推导 ETC、VAC 和 TCPI ，依据您选定的 EAC。
  10. 报告 首选 EAC、区间、理由以及您建议的行动。
提示

在您管理成本的层面计算 EAC，通常是控制账户或工作包，然后向上汇总。一个健康的项目总数可能掩盖某个严重超支的工作包。

计算示例：超出预算的项目

一个网站重建项目的预算为 $200,000 ，工期八个月。在第四个月末：

  • 计划价值（PV）= $80,000
  • 挣值（EV）= $70,000（已完成 35% 的工作）
  • 实际成本（AC）= $85,000

因此 CPI = 70,000 / 85,000 = 0.8235, SPI = 70,000 / 80,000 = 0.875，剩余工作的预算价值为 BAC - EV = $130,000。该项目既超出预算，又落后于进度。

公式计算EACVAC（BAC - EAC）
BAC / CPI200,000 / 0.8235$242,857-$42,857
AC + (BAC - EV)85,000 + 130,000$215,000-$15,000
AC + (BAC - EV) / (CPI x SPI)85,000 + 130,000 / 0.7206$265,408-$65,408
加权 0.8 CPI / 0.2 SPI85,000 + 130,000 / 0.8338$240,908-$40,908
AC + 自下而上的 ETC85,000 + 140,000$225,000-$25,000

预测值从 $215,000 到 $265,408 不等。报告哪一个取决于原因。假设调查显示，主要原因是一名高级开发人员的日费率比估算高 15%，且这名开发人员会一直留到项目结束。原因持续存在，因此 BAC / CPI = $242,857 是最站得住脚的预测。自下而上得出的 $225,000 则需要可信地解释效率为何会提高。

根据选定的 EAC：

  • ETC = EAC - AC = 242,857 - 85,000 = $157,857 仍需投入。
  • VAC = BAC - EAC = -$42,857，预测超支约 21%。
  • 实现 BAC 所需的 TCPI = (BAC - EV) / (BAC - AC) = 130,000 / 115,000 = 1.13。剩余工作的效率需要比计划高 13%，而团队目前的效率比计划低 18%。如果不改变范围或方法，这是不现实的。
  • 为达到 EAC 所需的 TCPI = (BAC - EV) / (EAC - AC) = 130,000 / 157,857 = 0.82，与当前 CPI 相等，这正是该公式应有的结果。

我们在以下指南中使用了相同的项目数据： 挣值管理, CPI 和 成本偏差，因此您可以在所有这些指南中追踪这些数字。

计算示例：低于预算的项目

EAC 也可能低于 BAC。一个小型办公室搬迁项目的预算为 $50,000。在状态日期，PV = $22,000，EV = $20,000，AC = $18,000。

  • CPI = 20,000 / 18,000 = 1.11 （低于预算）
  • SPI = 20,000 / 22,000 = 0.91 （略落后于进度）
  • BAC - EV = $30,000 的剩余工作
公式EACVAC
BAC / CPI$45,000+$5,000
AC + (BAC - EV)$48,000+$2,000
AC + (BAC - EV) / (CPI x SPI)$47,700+$2,300

在这里，BAC / CPI 是最乐观的数字。谨慎的项目经理可能会报告 $48,000，因为早期的节约往往来自较容易的任务，未必会持续。正的 VAC 是好消息，但也可能意味着原始估算留有余量；请在您的以下文件中记录原因： 经验教训 ，以便改进未来的估算。

EAC、ETC、VAC 和 TCPI 对比

这四个预测指标紧密相关，也常被混淆，在考试题目中尤其如此。

度量回答的问题公式良好结果
EAC整个项目将花费多少？AC + ETC（或四个公式之一）等于或低于 BAC
ETC我们还要花多少钱？EAC - AC，或自下而上的估算在剩余预算（BAC - AC）之内
VAC项目完成时将超出或低于预算多少？BAC - EAC零或正值
TCPI剩余工作的效率必须达到多少？(BAC - EV) / (BAC - AC) 或 (BAC - EV) / (EAC - AC)接近或低于当前 CPI

解读 TCPI

完工尚需绩效指数是对任何目标的现实检验。如果为达到 BAC 所需的 TCPI 为 1.13，而当前 CPI 为 0.82，那么仅靠更加努力工作几乎不可能守住预算。作为粗略的经验法则（这是我们的建议，而非正式标准）：

  • TCPI 低于或接近当前 CPI： 按当前绩效即可实现目标。
  • TCPI 略高于 CPI（最多约 0.05 至 0.10）： 只有采取具体的改进措施才能实现。
  • TCPI 远高于 CPI： 不现实；需要重新规划、变更范围或调整预算。

在项目后期，TCPI 会急剧上升，因为可用于挽回的剩余工作越来越少。如果实际成本已超过 BAC，基于 BAC 的 TCPI 就会失去意义或变为负值，只有基于 EAC 的版本才有用。

应该使用哪个 EAC 公式？

正确的公式取决于绩效偏离计划的原因，而不是哪个答案看起来最好。请以此为起点：

情境首选 EAC原因
费率、生产率或复杂程度比估算的更差，并将持续如此BAC / CPI原因影响所有剩余工作
超支由单一事件造成，且该事件已解决AC + (BAC - EV)剩余工作应能按计划进行
进度落后，且必须满足固定的结束日期AC + (BAC - EV) / (CPI x SPI)追赶进度将产生额外成本
范围、设计、供应商或方法发生了变化AC + 自下而上的 ETC原有估算已不再适用
项目早期（完成度低于约 15% 至 20%）自下而上的 ETC，并以公式作交叉检查早期指数波动较大
各公式结果差距很大自下而上的 ETC 加上一个区间需要让不确定性清晰可见

独立 EAC 与管理层 EAC

在正式的挣值系统中，您会看到两种预测。 独立 EAC（IEAC） 根据公式计算，不掺杂任何人的判断，起到统计检验的作用。 管理层 EAC （有时称为记录在案的完工估算）是项目经理自己的预测，通常自下而上编制。如果管理层 EAC 远低于独立 EAC，发起人会期望得到清晰的解释，说明哪些情况将会改变。

报告一个区间，而不是一个点

展示最佳情况（AC + (BAC - EV)）、最可能情况和最差情况（CPI x SPI），能让决策者获得符合实际的全貌。对于不确定性高的项目，对剩余工作进行 蒙特卡洛模拟 可以得出基于概率的区间，例如 80% 置信度的 EAC。

在电子表格中计算 EAC

您不需要专业软件。将 BAC 放在 B1 单元格、PV 放在 B2、EV 放在 B3、AC 放在 B4，以下公式即可在 Excel 和 Google Sheets 中使用：

单元格度量公式
B5CPI=B3/B4
B6SPI=B3/B2
B7EAC（典型）=B1/B5
B8EAC（非典型）=B4+(B1-B3)
B9EAC（CPI x SPI）=B4+(B1-B3)/(B5*B6)
B10ETC=B7-B4
B11VAC=B1-B7
B12为达到 BAC 所需的 TCPI=(B1-B3)/(B1-B4)

每个周期按状态日期逐行记录这些数值，以便绘制趋势图。一条不断上升的 EAC 曲线比任何单个数值都更能说明问题。我们的免费 预算模板 和 项目成本估算模板 为 BAC 和自下而上的估算提供了结构。

大多数具备预算功能的项目管理工具都会记录计划成本和实际成本；请确认您的工具能够导出所需的数据。我们的 项目管理软件 评测介绍了哪些工具包含预算和财务跟踪功能。

向发起人报告 EAC

单独给出一个 EAC 会引来“那又怎样？”的疑问。在以下报告中，一个有用的预测 项目状态报告 应包括：

  • ​ 首选 EAC 以及其他方法得出的区间。
  • VAC ，以金额和占 BAC 的百分比表示。
  • ​ 趋势：EAC 在最近几个周期中的变化情况。
  • ​ 主要原因 ，即偏差的主要原因以及它们是否会持续。
  • TCPI ，以表明预算是否仍可实现。
  • 建议的行动：纠正措施、动用应急储备，或提交变更请求以重新确定基准。

事先商定阈值，例如当 VAC 超过 BAC 的 5% 或 10% 时上报，这样预测的超支就会触发决策而不是争论。如果超支无法消化，则需通过 变更控制 申请修订预算。每个周期都让 EAC 清晰可见，是以下工作的核心习惯之一： 成本控制.

如需全面了解如何预测完成日期、收益以及成本，请阅读 项目预测.

常见错误

  • 默认使用 AC + (BAC - EV) ，只因为它得出的超支最小，却没有证据表明原因已经消除。
  • 依赖早期的单次 CPI 读数。 等待趋势形成；早期指数波动很大。
  • 使用质量不佳的进展数据。 主观的完成百分比会抬高 EV，让每一项预测都显得过于乐观。
  • 遗漏应计费用和已承诺成本，导致 AC 和 EAC 被低估。
  • 将 EAC 与 BAC 或资金上限混为一谈。 EAC 是预测；BAC 是批准的预算；资金可能包括管理储备。
  • 将管理储备计入 BAC。 储备位于绩效测量基准之外。
  • 只在项目层面进行预测，这会掩盖超支的工作包。
  • 只报告一个数字而不说明理由，这会让预测难以令人信服，也难以接受质询。
  • 在变更获批后不更新 BAC，导致偏差中包含了已正式增加的范围。

PMP 考试中的 EAC

EAC 题目经常出现在 PMP 和 CAPM 备考资料中。以下几个惯例会有所帮助：

  • 如果题目说偏差是 典型的 或者绩效将会 持续，使用 BAC / CPI。
  • 如果题目说偏差是 非典型的, a 一次性的 或者 不会再次发生，使用 AC + (BAC - EV)。
  • 如果题目提到成本和进度都会影响剩余工作，或者存在 硬性截止日期，使用 AC + (BAC - EV) / (CPI x SPI)。
  • 如果题目说 原始估算存在缺陷 或者已经做出新的估算，使用 AC + ETC。
  • 请记住 ETC = EAC - AC，VAC = BAC - EAC；VAC 为负值表示超出预算。
  • TCPI 大于 1 表示剩余工作的效率必须高于计划。

常见问题

项目管理中的完工估算是什么？

完工估算（EAC）是项目在全部工作完成时的预测总成本。它等于迄今为止的实际成本加上剩余工作的估算成本，并与完工预算进行比较，以显示预期的超支或结余。

EAC 的公式是什么？

共有四个标准公式：BAC / CPI；AC + (BAC - EV)；AC + (BAC - EV) / (CPI x SPI)；以及 AC + 自下而上的完工尚需估算。一般关系始终是 EAC = AC + ETC。

最常用的 EAC 公式是哪个？

EAC = BAC / CPI。它假设当前的成本效率将会持续，这在项目进展到相当程度后往往符合实际，它也是许多工具和考试题目的默认公式。

EAC 和 ETC 有什么区别？

EAC 是项目的预测总成本。ETC（完工尚需估算）是剩余工作的预测成本。EAC = AC + ETC，因此 ETC = EAC - AC。

EAC 和 BAC 有什么区别？

BAC 是全部工作的批准预算，只能通过变更控制进行调整。EAC 是当前对最终成本的预测，每个报告期都可能变化。VAC = BAC - EAC 显示两者的差距。

什么时候应该使用 EAC = AC + (BAC - EV)？

当迄今为止的偏差是由一次性事件造成且该事件已经解决，因而预计剩余工作将按预算费率完成时使用。对于超出预算的项目，它是最乐观的公式。

什么时候应使用 CPI x SPI 公式？

当项目进度落后且仍必须满足固定日期，因而追赶进度会因加班、增加资源或加急而增加成本时使用。在两个指数都低于 1 时，它通常得出最高的 EAC。

EAC 可以低于 BAC 吗？

可以。如果 CPI 大于 1，项目在已完成工作上的支出就少于预算，EAC 将低于 BAC。此时 VAC 为正值，表示预测会有结余。

VAC 为负值意味着什么？

完工偏差 = BAC - EAC。VAC 为负值意味着预测项目完成时将超出预算该金额。例如，BAC 为 $200,000、EAC 为 $242,857，则 VAC 为 -$42,857。

什么是 TCPI，它与 EAC 有什么关系？

完工尚需绩效指数是剩余工作为实现目标必须达到的成本效率。为达到 BAC 所需的 TCPI = (BAC - EV) / (BAC - AC)；为达到 EAC 所需的 TCPI = (BAC - EV) / (EAC - AC)。TCPI 远高于当前 CPI 意味着目标不现实。

EAC 应多久更新一次？

每个报告期都应更新，通常是每月一次或在每个冲刺或阶段结束时，与其他挣值指标一同更新。在发生已批准的变更或重大风险等重要事件后，也应更新。

自下而上的 EAC 比公式更好吗？

当计划发生重大变化时，它通常更可信，因为它反映了当前的范围、费率和风险。公式计算更快，很适合用作对自下而上数字的独立交叉检查。

什么是独立 EAC？

独立 EAC（IEAC）是纯粹根据挣值公式计算的预测，不含管理层的判断。它用于检验项目经理自己的预测；两者差距较大时需要做出解释。

EAC 和项目预测是一回事吗？

EAC 是项目预测中的成本部分。完整的预测还包括预期完成日期，通常还包括收益。参见我们关于以下内容的指南： 项目预测.
