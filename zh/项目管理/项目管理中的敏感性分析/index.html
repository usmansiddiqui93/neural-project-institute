项目管理中的敏感性分析：指南与示例

敏感性分析检验在其他输入保持不变的情况下，某一输入的变化会使项目结果（如成本、利润、净现值或完工日期）发生多大变化。它显示哪些假设最重要，使您知道应将估算工作和风险应对的重点放在哪里。

要点总结

  • 敏感性分析每次只改变一个输入，以观察其影响。
  • 按波动幅度对输入排序，并在龙卷风图中展示。
  • 将其与盈亏平衡点结合使用，以检验商业论证的余量。
  • 当变量之间相互作用时，使用情景分析或蒙特卡洛模拟。

项目经理为什么使用敏感性分析

  • 识别造成成本、收益或进度大部分不确定性的少数几个变量。
  • 检验 商业论证 在关键假设出错时是否仍然成立。
  • 找出盈亏平衡点，例如产品仍能盈利的最低价格。
  • 在以下过程中为应对规划排定风险优先级： 项目风险管理.
  • 使用龙卷风图向发起人清晰地呈现不确定性。

如何分步进行敏感性分析

  1. 为结果（例如利润）建立一个简单模型， 净现值 或总成本。
  2. 使用您的最佳估算计算基准情形。
  3. 列出不确定的输入变量。
  4. 为每个变量选择切合实际的低值和高值，例如上下浮动 10%，或采用专家给出的范围。
  5. 每次只将一个变量改为其低值和高值，其他变量都保持基准值，并记录结果。
  6. 计算每个变量的波动幅度（高值结果减去低值结果）。
  7. 按波动幅度对变量排序，并绘制龙卷风图，将最大的条形放在顶部。
  8. 将估算工作和风险应对的重点放在排名靠前的变量上。

计算示例：产品利润的龙卷风图

某项目将推出一款产品。基准情形模型为 利润 = 销量 x（价格 - 可变成本）- 固定成本。基准值：销量 10,000 件，价格 $50，单位可变成本 $30，固定成本 $120,000。基准利润 = 10,000 x ($50 - $30) - $120,000 = $80,000.

每个输入在两个方向上各变动 10%，其他输入保持基准值。

变量（-10% / +10%）低值时的利润高值时的利润波动幅度
价格（$45 / $55）$30,000$130,000$100,000
可变成本（$27 / $33）$110,000$50,000$60,000
销量（9,000 / 11,000）$60,000$100,000$40,000
固定成本（$108,000 / $132,000）$92,000$68,000$24,000

绘制成龙卷风图后，价格是位于顶部最宽的条形，其次是可变成本、销量和固定成本。价格最为重要：10% 的变化会使利润上下浮动 $50,000。盈亏平衡价格为 $120,000 / 10,000 + $30 = $42，因此价格可以下降 16% 而项目仍不亏损。团队应把精力放在验证价格假设和管理单位成本上，而不是进一步细化固定成本估算。

敏感性分析与其他技术对比

技巧有何变化产出最适合
敏感性分析每次一个变量变量排序；龙卷风图找出最重要的因素
情景分析在定义的情形中同时考虑多个变量最佳、基准和最差情形的结果阐述可能出现的未来情形
盈亏平衡分析调整一个变量，直到结果降为零一个临界值检验商业论证的余量
蒙特卡洛模拟所有变量同时随机变化，重复多次结果的概率分布成本和日期的置信水平

进度计划中的敏感性

同样的思路也适用于时间。依次延长每项关键活动，可以看出哪些活动对结束日期的推迟影响最大。在蒙特卡洛进度工具中，敏感性或关键性报告会按活动对完工日期的影响程度进行排序，有助于有针对性地制定 进度压缩 和风险应对措施。

局限性与技巧

  • 每次只改变一个变量会忽略相互作用；如果变量会同时变动，应补充进行情景分析。
  • 如果有更好的数据，应为每个变量设定切合实际的范围，而不是对所有变量都采用相同的百分比。
  • 模型的好坏取决于其结构；在信任排序结果之前，先检查公式。
  • 记录所用的范围及其来源，以便他人审查。
  • 当关键假设发生变化时，重复进行分析。
提示

将龙卷风图和盈亏平衡点一起展示给发起人。这样在一张视图中就能同时回答“什么最重要？”和“在项目失败之前，我们的估计最多能偏差多少？”这两个问题。

常见问题

什么是项目管理中的敏感性分析？

一种每次只改变一个输入的技术，用于观察其对成本、利润、NPV 或完工日期等结果的影响程度，从而揭示哪些假设最为重要。

敏感性分析中的龙卷风图是什么？

一种按变量对结果影响程度进行排序的条形图，最宽的条形位于顶部，因此看起来像龙卷风。

如何进行简单的敏感性分析？

先计算基准情形，然后每次将一个不确定输入调整为低值和高值，记录结果，并按变化幅度对输入进行排序。

敏感性分析与情景分析有什么区别？

敏感性分析每次改变一个变量；情景分析则同时改变多个变量，以描述最佳、基准或最差情形。

敏感性分析与蒙特卡洛模拟有什么关系？

蒙特卡洛模拟会将所有输入同时变化多次以得出概率；其敏感性输出随后会显示哪些输入对结果的影响最大。

敏感性分析是定性的还是定量的？

定量的。它是定量风险分析和财务评估中的一种标准技术。

敏感性分析应使用什么范围？

根据数据或专家判断为每个变量设定切合实际的范围；在没有更好依据时，上下浮动 10% 或 20% 是一个简单的起点。

敏感性分析中的盈亏平衡分析是什么？

找出使结果为零时某变量的值，例如利润为零时的价格。

应该在什么时候进行敏感性分析？

在编制商业论证时、在风险分析期间，以及在主要假设发生变化时再次进行。

可以在 Excel 中进行敏感性分析吗？

可以。一个使用数据表或逐一手动修改的简单模型就足够了，再按波动幅度排序绘制条形图，即可得到龙卷风图。

敏感性分析有哪些局限性？

它忽略了变量之间的相互作用，并且取决于模型和所选范围是否切合实际。
