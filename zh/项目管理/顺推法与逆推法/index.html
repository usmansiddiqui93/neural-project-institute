顺推法与逆推法：分步计算示例

顺推和逆推是以下方法核心的两项计算： 关键路径法。顺推从起点到终点进行，求出每项活动的最早日期；逆推从终点到起点进行，求出最晚日期。将两者进行比较即可得出浮动时间。

作者Neural Project Institute项目管理编辑团队
  • 发布于 2026 年 9 月 24 日
  • 阅读时长 4 分钟

要点总结

  • 顺推：EF = ES + 工期，在汇合点取最大的 EF。
  • 逆推：LS = LF - 工期，在分支点取最小的 LS。
  • 总浮动时间 = LS - ES；浮动时间为零即标志着关键路径。
  • 自由浮动时间显示一项活动在不影响其紧后活动的情况下可以延误多少。

公式

推算公式存在多个连接时的规则
顺推EF = ES + 工期ES = 所有紧前活动的 最大 EF 值
逆推LS = LF - 工期LF = 所有紧后活动的 最小 LS 值
浮动时间总浮动时间 = LS - ES = LF - EF自由浮动时间 = 紧后活动中最早的 ES - EF

本指南采用第 0 天惯例：第一项活动从 0 开始，紧后活动从其紧前活动的 EF 开始。有些教材采用第 1 天惯例，即 ES = 前一项活动的 EF + 1；得出的浮动时间和关键路径是相同的。

第 1 步：顺推

  1. A：ES = 0，EF = 0 + 3 = 3。
  2. B：ES = 3（A 的 EF），EF = 3 + 4 = 7。
  3. C：ES = 3，EF = 3 + 2 = 5。
  4. D：ES = 7，EF = 7 + 5 = 12。
  5. E：ES = 5，EF = 5 + 3 = 8。
  6. F：有两项紧前活动，D（EF 12）和 E（EF 8）。取最大值：ES = 12，EF = 12 + 2 = 14。
  7. 项目工期 = 14 天。

第 2 步：逆推

  1. F：LF = 14（项目完工），LS = 14 - 2 = 12。
  2. D：LF = 12（F 的 LS），LS = 12 - 5 = 7。
  3. E：LF = 12，LS = 12 - 3 = 9。
  4. B：LF = 7（D 的 LS），LS = 7 - 4 = 3。
  5. C：LF = 9（E 的 LS），LS = 9 - 2 = 7。
  6. A：有两项紧后活动，B（LS 3）和 C（LS 7）。取最小值：LF = 3，LS = 3 - 3 = 0。

总浮动时间为零的活动 A-B-D-F，构成关键路径。C 有 4 天的总浮动时间，但没有自由浮动时间：如果 C 延误，E 就会推迟开始。E 的总浮动时间和自由浮动时间都是 4 天，因为 F 直到第 12 天才需要它。参见 浮动时间与松弛时间.

常见错误

  • 在顺推的汇合点取最小的 EF，而不是最大的 EF。
  • 在逆推的分支点取最大的 LS，而不是最小的 LS。
  • 在同一次计算中混用第 0 天和第 1 天惯例。
  • 忘记加上滞后量：对于 FS+2，紧后活动的 ES = 紧前活动的 EF + 2；参见 提前量与滞后量.

常见问题

什么是顺推？

从网络图起点到终点进行的计算，用于求出每项活动的最早开始时间和最早完成时间。

什么是逆推？

从网络图终点到起点进行的计算，用于求出每项活动的最晚完成时间和最晚开始时间。

为什么在顺推中要取最大的 EF？

因为一项活动必须等到其所有紧前活动都完成后才能开始，所以最晚完成的那项紧前活动决定了它的开始时间。

为什么在逆推中要取最小的 LS？

因为一项活动必须及时完成，以满足最早需要它的紧后活动，否则该紧后活动就会被推迟。

如何根据顺推和逆推计算浮动时间？

总浮动时间 = LS - ES，或 LF - EF。两者的结果相同。

顺推和逆推之后，总浮动时间和自由浮动时间有什么区别？

总浮动时间是在不推迟项目完工的情况下所允许的延误；自由浮动时间是在不推迟任何紧后活动的情况下所允许的延误。

顺推应该从第 0 天还是第 1 天开始？

只要保持一致，两种都可以。第 0 天计算起来更简单；第 1 天则更自然地对应日历日期。

如果要求的完工日期早于顺推得出的完工日期怎么办？

从要求的日期开始逆推。这样一些活动就会出现负浮动时间，显示必须挽回多少时间。

我需要手工进行顺推和逆推吗？

进度计划软件会自动完成计算，但手工计算一个小示例有助于您理解和核对结果。这也是一个常见的考试主题。

PMP 考试会考顺推和逆推吗？

浮动时间和关键路径等网络图计算是 PMP 备考的常见内容；参见 PMP 认证.
