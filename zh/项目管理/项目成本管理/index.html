项目成本管理：过程、工具与示例

项目成本管理是对成本进行规划、估算、预算和控制的工作，使项目在批准的预算内完成。它将范围和进度转化为资金，设定基准，然后对照基准跟踪实际支出，以便及早发现问题。

要点总结

  • 成本管理涵盖成本的规划、估算、预算和控制。
  • 成本基准是用于衡量绩效的按时间分配的预算。
  • 挣值显示所花的钱是否换来了计划的工作量。
  • 尽早并经常进行预测，以便在超支还很小时就发现它。

成本管理在实践中如何运作

  1. 在成本管理计划中商定如何估算、衡量和报告成本。
  2. 使用以下工具分解工作： 工作分解结构 ，并估算每个工作包。
  3. 为已知风险加上应急储备，并将各项估算汇总为按时间分配的成本基准。
  4. 落实资金，包括由发起人掌管的管理储备。
  5. 在工作进行时记录实际成本，并使用以下方法将其与计划进行比较： 挣值管理.
  6. 预测最终成本，采取纠正措施，并在基准必须更改时提出变更请求。

计算示例

某网站重建项目的成本基准为 $200,000，分布在八个月内。第四个月末，计划显示应完成价值 $80,000 的工作（计划价值）。团队已完成价值 $70,000 的工作（挣值），但花费了 $85,000（实际成本）。

  • 成本偏差 = EV - AC = 70,000 - 85,000 = -$15,000 （超出预算）。
  • 成本绩效指数 = EV / AC = 70,000 / 85,000 = 0.82：每花费一美元，只产出约 82 美分的计划工作量。
  • 完工估算 = BAC / CPI = 200,000 / 0.8235 = 约 $242,857 （如果这一效率持续下去）。

项目经理现在获得了一个清晰、及早的信号，可以在超支扩大之前查找原因。

常见错误

  • 在范围明确之前就进行估算，然后将估算视为承诺。
  • 遗漏间接成本、许可证、培训或内部员工的成本。
  • 只跟踪支出，而不衡量这些支出换来了多少工作。
  • 将应急储备隐藏在各项估算中，而不是公开列示。
  • 等待月末的财务报告，而不是每周跟踪成本。

常见问题

什么是项目成本管理？

它是用于规划、估算、预算和控制项目成本的一组过程，使项目在批准的预算内完成。

项目成本管理的四个过程是什么？

在 PMBOK 第 6 版中，它们是规划成本管理、估算成本、制定预算和控制成本。

为什么项目成本管理很重要？

没有成本管理，超支往往发现得太晚而无法纠正。良好的成本管理能提供及早预警，并支持在范围和优先级方面做出更好的决策。

项目成本管理中的成本基准是什么？

经批准的、按时间分配的项目工作预算，包括应急储备，但不包括管理储备。绩效以此为基准进行衡量。

在项目成本管理中，预算和估算有什么区别？

估算是对工作成本的预测。预算是经批准的资金数额，由估算加上储备构成。

项目成本管理中的直接成本和间接成本是什么？

直接成本可以追溯到项目，例如承包商费用。间接成本是分摊到项目的共享管理费用，例如办公场地。

谁负责项目成本管理？

项目经理负责日常成本管理，而发起人批准预算并掌管管理储备。

挣值管理如何支持项目成本管理？

它比较计划价值、挣值和实际成本，以衡量成本和进度绩效；参见 挣值管理.

作为项目成本管理的一部分，如何控制成本？

定期对照基准跟踪实际成本，分析偏差，预测最终成本，并尽早采取纠正措施或提出变更请求。

敏捷项目会使用项目成本管理吗？

会。敏捷团队通常固定每个冲刺或发布的成本而让范围变化，跟踪资金消耗率和交付的价值，而不是详细的任务预算。

项目成本管理中的成本超支是什么？

支出超过批准的预算。常见原因包括范围不明确、估算过于乐观、范围蔓延和跟踪不力。
