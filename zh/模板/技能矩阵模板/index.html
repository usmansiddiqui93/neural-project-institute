什么是技能矩阵？

A 技能矩阵 是一张表格，一侧列出团队成员，顶部列出团队所需的技能，每个单元格中都有熟练度评分。它能让人一眼看出谁能做什么、做得多好，团队的强项在哪里，哪些技能薄弱，以及谁依赖于某一位专家，从而帮助经理规划培训、人员配置和招聘。

您还会看到它被称为 技能矩阵, a 能力网格 或 交叉培训矩阵。无论叫什么名称，它都用团队共同认可的整体图景取代了对谁擅长什么的主观感觉。

项目经理使用技能矩阵为项目配备人员并发现交付风险；团队负责人用它安排交叉培训和人员替补；人力资源和学习团队用它确定培训预算的投放方向。我们关于 项目管理技能 列出了常作为项目经理团队技能矩阵列的硬技能和软技能。

每个技能单元格填写 0 到 4 之间的数字。在任何人自评之前，请与团队商定以下描述或您自己的版本。

如何逐步创建技能矩阵

对于小团队，您可以在一小时内填完模板。大部分工作量和价值都在于就技能和评分定义达成一致。

  1. 确定矩阵的用途。 为项目配备人员、规划培训和降低关键人员风险需要不同的技能清单。用一句话写明目的并设定范围：一个团队、一个项目或一个部门。
  2. 选择六到十二项技能。 从工作本身出发，而不是从职位名称出发：您的项目计划、角色描述和即将开展的项目。技能要具体到可以评分（用“预算预测”而不是“财务”），并相应地重命名模板中的六个技能列。如需更多技能，请在“平均值”之前插入额外的列。
  3. 商定评分定义。 使用上述 0 到 4 分的评分标准，对于重要技能，再补充一个 3 分水平的示例，例如“无需帮助即可制定和维护资源加载的进度计划”。
  4. 请每个人进行自我评估。 请他们为任何 3 分或 4 分的评分记下一条证据。
  5. 校准评分。 经理通过简短的对话评审每个人的评分，必要时询问与其共事过的同事。目的是使整个团队的评分保持一致，而不是压低评分。
  6. 输入商定的评分。 用您的团队替换示例行。示例行的个人平均值和团队平均值行会自动计算；添加更多人员时，请参阅下面的电子表格技巧。
  7. 分析结果。 查看团队平均值找出薄弱技能，统计每项技能中评分为 3 或以上的人数以找出单点故障，并记下谁评分为 4、可以指导他人。下面的示例展示了具体做法。
  8. 采取行动并记录行动项。 将每项发现转化为有负责人和日期的具体行动：培训、结对、人员调整或招聘决策。将培训记录在 培训计划模板 ，更广泛的改进记录在 行动计划模板.

电子表格技巧

  • 增加人手： 团队平均值公式覆盖四个示例行（例如 =AVERAGE(C6:C9)）。请在第一个和最后一个示例行之间插入新行，使范围自动扩展，或者编辑范围以包含每个人。
  • 向下复制平均值公式： 示例下方的空白行不包含个人平均值公式，因此请从示例行复制到每个新行中。
  • 添加覆盖人数统计： 在“团队平均值”行下方，添加一行名为“3 分及以上人数”，并在每个技能列中使用诸如 =COUNTIF(C6:C9,">=3") 的公式。任何显示 0 或 1 的技能都需要关注。
  • 制作热力图： 选中评分单元格并应用色阶（在 Google Sheets 中：格式 > 条件格式 > 色阶；在 Excel 中：开始 > 条件格式 > 色阶）。由红到绿的配色能让差距一目了然。
  • 区分空白和零： 空白表示尚未评分；0 表示不具备该技能。AVERAGE 会忽略空白但会计入零，因此请在查看平均值之前填好每个单元格。

示例说明了什么

  • 两项关键人员风险。 只有 Ana 能独立完成风险管理和预算编制。如果她休假或离职，团队会同时失去这两项能力。这是一个值得记录在项目 风险登记册.
  • 两项明显优势。 进度计划以及数据和报告各有三名胜任人员，因此团队在这两方面能够承受人员缺席。
  • 内部教练。 Ana（进度计划、相关方管理）、Ben（敏捷 / Scrum）和 Chen（数据和报告）的评分都是 4，因此大部分能力培养可以通过结对而不是付费课程来完成。
  • 个人平均值需要结合背景解读。 Ana 的平均分为 3.00，Ben 为 2.83，Chen 为 2.33，Dana 为 2.17。这并不意味着 Dana 是团队中最弱的成员：协调员不需要在预算编制方面达到项目经理的水平。应将人员与其角色的需求进行比较，而不是相互比较。

如何在项目管理中使用技能矩阵

当您将技能矩阵与您已经在做的关于人员、风险和时间的决策联系起来时，它最有用。

为项目配备人员和分配资源

分配工作时，将每个工作包所需的技能与评分为 3 或 4 的人员进行匹配，并在有时间进行能力培养时，有意让一名 4 分人员与一名 1 分或 2 分人员结对。我们关于 资源分配 解释了如何在任务和项目之间分配人员，而 项目资源 涵盖人员、设备和预算等更广泛的组合。

产能规划

技能矩阵告诉您谁能完成工作；产能规划告诉您他们是否有时间。即使团队有空余工时，如果唯一会做预算的人已经排满，工作仍然可能受阻。请阅读 项目管理中的产能规划，或 敏捷产能规划 （如果您按冲刺进行规划）。如果某位关键人员超负荷， 资源平衡 可以重新平衡进度计划。

管理关键人员风险

单点故障与其他项目风险一样。请记录其原因、负责人和应对措施，例如交叉培训、编写文档或备用供应商。

组建跨职能敏捷团队

敏捷团队的目标是具备交付所需的全部技能，许多团队鼓励培养 T 型人才，即在某一领域有深度，同时对其他领域有实用的了解。技能矩阵显示谁接下来应该学习什么。我们关于 什么是敏捷团队 和 Scrum 团队角色 解释了这些结构。

规划培训和招聘

结对无法弥补的差距会转化为培训或招聘需求。请按个人现有评分与岗位所需评分之间的差距确定优先级。对于项目经理，我们的 项目管理认证 指南介绍了提高评分的正式途径。

技能矩阵、能力矩阵与 RACI 矩阵

这些文件很容易混淆，因为其中几种都是以人员为一个维度的表格。每种文件回答不同的问题：

文档回答的问题行和列适用情况
技能矩阵谁能做什么？做得多好？人员与技能的对照，附熟练度评分人员配置、交叉培训、关键人员风险
能力矩阵每个人是否达到其角色的预期标准？角色或人员与能力（技能、知识和行为）及期望水平的对照职业发展框架、绩效和晋升
RACI 矩阵在这个项目中谁负责什么？任务或可交付成果与人员或角色的对照，标记为 R、A、C 或 I明确责任归属和决策
培训计划谁将学习什么、如何学、何时学完、花费多少？学员与培训活动、日期和费用的对照针对技能矩阵发现的差距采取行动

常见的顺序是：建立技能矩阵，为项目配备人员，然后在以下文件中记录谁做什么： RACI 矩阵模板正式授权项目。我们的 RACI 矩阵指南 详细说明了职责分配。对于跨流程或工具的更广泛的能力差距， 差距分析模板 更为合适。

常见的技能矩阵错误

  • 技能过多。 四十列的矩阵没有人会更新。只保留影响交付的技能，必要时将团队拆分为多个矩阵。
  • 技能含糊。 “沟通”很难一致地评分；“主持指导委员会会议”则很容易。
  • 没有统一的定义。 如果没有这些描述，自信的人会给自己打高分，谦虚的人会打低分，矩阵衡量的就是性格而不是技能。
  • 将其用作绩效评分。 如果评分直接与薪酬或绩效考核挂钩，人们就会虚报评分。请事先说明该矩阵是一个规划工具。
  • 只构建一次。 每完成一个项目和一门课程，技能都会发生变化。一年前的矩阵只是猜测。
  • 没有行动。 没有附带培训计划、人员调整或招聘决策的矩阵只是一张图表。

保持评分准确和公平的技巧

  • 要求提供证据。 对于任何 3 分或 4 分，请对方提供一个近期的例子：他们制定的进度计划、主持的风险评审、负责的报告。
  • 考虑增加一个意愿列。 有些团队会额外添加一个简单的“是”或“否”，表示此人是否希望发展某项技能。这有助于您挑选培训对象；它是可选的附加内容，不是模板的一部分。
  • 注意隐私。 评分属于个人信息。只与需要的人分享完整矩阵；如果符合您的组织文化，团队视图只显示平均值和覆盖情况。请查阅您所在组织的人力资源政策。
  • 每年更新两次， 以及在重要培训、重组或项目的 经验教训 评审。专家版的“修订历史”工作表用于记录每次更新。

常见问题

什么是技能矩阵模板？

技能矩阵模板是一张现成的表格，将团队成员与团队所需的技能相对照，每个单元格中都有熟练度评分。本模板采用 0 到 4 分的评分标准，并计算每个人的平均分以及每项技能的团队平均分。

这个技能矩阵模板免费吗？

是的。技能矩阵模板可免费下载 Google Sheets、Excel 和 PDF 版本，提供初级、高级和专家三个级别，无需注册。

如何在 Excel 或 Google Sheets 中创建技能矩阵？

在第一列列出团队成员，在顶部列出技能，商定评分标准，为每个人的每项技能输入评分，然后为每个人和每项技能添加 AVERAGE 公式。模板已具备这一结构，因此您只需重命名技能并输入团队成员即可。

技能矩阵应使用什么评分标准？

使用四到五个定义清晰的等级。本模板使用 0 = 不具备、1 = 学习中、2 = 在帮助下能完成、3 = 能独立完成、4 = 能教导他人。确切的等级划分不如每个人都使用相同的定义重要。

技能矩阵与能力矩阵有什么区别？

技能矩阵记录人员执行特定技能的熟练程度。能力矩阵通常范围更广，涵盖技能、知识和行为，并对照每个角色所要求的水平。

什么是技能差距矩阵？

技能差距矩阵将每个人或每个角色所需的评分与其当前评分进行比较。您可以通过为每项技能添加目标评分并与实际评分比较，将本模板用作技能差距矩阵。

应由谁填写技能矩阵？

团队成员先进行自我评估，然后由经理与他们一起评审评分，最好还能参考一位同事的意见。

技能矩阵应多久更新一次？

大约每六个月一次，以及在重要培训、团队变动或大型项目结束之后。

如何在技能矩阵中找出单点故障？

统计每个技能列中评分为 3 或 4 的人数，例如使用 COUNTIF 公式。任何只有一个人（或没有人）能独立完成的技能都是关键人员风险，需要交叉培训或后备人员。

我可以使用技能矩阵模板来为项目配备人员吗？

可以。将每项任务所需的技能与评分为 3 或 4 的人员进行匹配，并通过以下方式确认其可用性： 资源分配 和产能规划。

技能矩阵和 RACI 矩阵是一回事吗？

不是。技能矩阵展示的是能力：谁能完成工作。 RACI 矩阵 展示职责：谁执行工作、谁负责，以及应咨询谁或通知谁。

初级、高级和专家版技能矩阵模板有什么区别？

初级版有一个工作表，包含四个技能列和一行团队平均值。高级版包含全部六项技能以及个人和团队平均值。专家版增加了“说明”工作表和“修订历史”工作表。
