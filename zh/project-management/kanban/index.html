Kanban 基础

什么是 Kanban、其原则，以及看板、卡片、泳道和节奏如何运作。

  1. 什么是 Kanban？Kanban 方法完全指南什么是 Kanban、它的起源、核心实践、Kanban 系统如何运作，以及如何从今天开始在团队中使用 Kanban。
  2. Kanban 原则与实践详解Kanban 方法的原则和六项核心实践、每项在日常工作中的含义，以及如何将它们应用到您的团队。
  3. Kanban 看板：如何设计和使用什么是 Kanban 看板、其关键组成部分（列、卡片、WIP 限制、泳道）、不同团队的看板示例以及分步设计技巧。
  4. Kanban 卡片：应写什么及为什么什么是 Kanban 卡片、每张卡片应显示的信息、如何确定工作项大小、阻塞标记，以及设计良好的卡片示例。
  5. Kanban 泳道：类型、用途与最佳实践什么是 Kanban 泳道、常见用法（服务类别、工作类型、团队），以及如何避免看板杂乱。
  6. 个人 Kanban：用两条简单规则管理自己的工作如何使用个人 Kanban 管理自己的任务：两条规则、简单的看板设置、个人 WIP 限制以及让习惯坚持下去的技巧。
  7. Kanban 会议与节奏：您需要哪些Kanban 节奏详解：每日 Kanban 会议、补充会议、交付计划会议、服务交付评审、运营评审、风险评审和战略评审。
  8. Kanban 计划：如何在没有冲刺的情况下计划和预测Kanban 中的计划如何运作：补充、承诺点、服务水平预期，以及基于吞吐量和周期时间的概率预测。

Kanban 对比

Kanban 与敏捷、Scrum、Scrumban 和瀑布的关系。

  1. Kanban 与 Scrum：区别及如何选择Kanban 与 Scrum 对比：节奏、角色、计划、变更、指标和看板，以及何时选择其一或将两者结合的指导。
  2. Kanban 与 Scrumban：有什么区别？Kanban 与 Scrumban 的区别、Scrumban 从 Scrum 和 Kanban 中借鉴了什么，以及团队何时应选择其中之一。
  3. Kanban 与敏捷：Kanban 如何融入敏捷Kanban 属于敏捷吗？Kanban 与敏捷宣言的关系、它与其他敏捷框架的区别，以及其精益根源如何塑造了它。
  4. Kanban 与瀑布：主要区别及各自的适用场景Kanban 与瀑布对比：计划、流动、变更、交付和可见性，以及各自适合哪些项目和如何将两者结合的指导。

流动与指标

WIP 限制以及 Kanban 团队用于预测和改进的指标。

  1. Kanban 中的 WIP 限制：如何设定和使用什么是在制品（WIP）限制、它为何能加快交付、如何设定首个限制，以及达到限制时该怎么做。
  2. Kanban 指标：真正重要的流动度量必备的 Kanban 指标：WIP、周期时间、前置时间、吞吐量、工作项年龄和流动效率，以及展示这些指标的图表。
  3. Kanban 中的周期时间：定义、计算及如何缩短什么是周期时间、如何计算、如何解读周期时间散点图、设定服务水平预期，以及缩短周期时间的实用方法。
  4. 周期时间与前置时间：有什么区别？通过示例讲解周期时间与前置时间：各自的起点和终点、两者为何都很重要、它们与利特尔法则的关系以及如何改进。
  5. Kanban 中的吞吐量：如何衡量和使用吞吐量在 Kanban 中的含义、如何衡量、如何利用吞吐量和蒙特卡洛模拟预测交付日期，以及如何提升吞吐量。
  6. 累积流图（CFD）：如何解读和使用如何解读累积流图：色带、斜率和间隙，如何发现瓶颈和不断增长的 WIP，以及如何从中估算周期时间。
  7. 流动效率：前置时间中有多少是真正的工作？什么是流动效率、如何计算、为何它通常低得惊人，以及减少等待时间、提升流动效率的实用方法。
  8. WIP 老化图：在延误之前发现停滞的工作什么是 WIP 老化图、如何结合周期时间百分位数解读，以及如何在每日 Kanban 会议中利用工作项年龄防止延误。
  9. 阻塞聚类：找出延误的根本原因Kanban 中的阻塞聚类如何运作：记录阻塞、按原因分组、衡量其成本，并解决最拖慢团队的问题。

精益基础

Kanban 背后的精益与流动理念：JIT、拉动、制约因素、价值流和 DevOps。

  1. 精益 Kanban：精益思想如何塑造 Kanban 方法精益原则如何支撑 Kanban：价值、流动、拉动和持续改进，精益 Kanban 的历史，以及如何将两者结合应用。
  2. 精益生产：原则、浪费与工具精益生产详解：丰田起源、七种浪费、5S、看板、JIT 和改善等关键工具，以及对项目团队的启示。
  3. 准时制（JIT）：运作方式、优势与风险什么是准时制生产、看板信号如何使其运作、其优势、在供应链中断时的风险，以及 JIT 理念如何应用于项目。
  4. 约束理论（TOC）：五个聚焦步骤Eliyahu Goldratt 约束理论详解：瓶颈、五个聚焦步骤、鼓-缓冲-绳，以及如何将 TOC 与 Kanban 结合应用。
  5. 拉动系统与推动系统：区别与示例拉动系统与推动系统对比：各自如何运作、制造业和知识工作中的示例、优缺点，以及为什么 Kanban 是拉动系统。
  6. Kanban 库存管理：双箱系统及其他Kanban 库存管理如何运作：双箱系统、看板卡、计算看板数量、优势，以及何时适合您的业务。
  7. 目视化管理：让工作和问题一目了然什么是目视化管理、其精益根源、看板、安灯和 5S 等工具、项目团队示例，以及有效目视化展示的技巧。
  8. 价值流图：如何绘制并改进您的流程价值流图分步指南：现状图和未来状态图、处理时间和前置时间等关键指标，以及如何发现浪费。
  9. 持续交付：原则、流水线与优势什么是持续交付、部署流水线如何运作、它与持续集成和持续部署的区别，以及它如何支持 Kanban 流动。
  10. 什么是 DevOps？文化、实践与指标DevOps 详解：起源、CALMS 模型、三步工作法、关键实践、DORA 指标，以及 DevOps 与精益、敏捷和 Kanban 的联系。
