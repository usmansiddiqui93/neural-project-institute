Come usare il modello di project charter

  1. Concorda scopo e obiettivi con lo sponsor prima di scrivere qualsiasi altra cosa.
  2. Compila l'ambito e, cosa altrettanto importante, ciò che è escluso dall'ambito.
  3. Aggiungi milestone, budget, rischi principali, assunzioni e vincoli.
  4. Indica lo sponsor e il project manager e specifica l'autorità del project manager.
  5. Rivedilo con gli stakeholder chiave, poi ottieni la firma dello sponsor.
  6. Conserva il project charter firmato insieme al piano di project management e rivedilo alle milestone principali.

Consigli per sfruttarlo al meglio

  • Limitalo a due pagine; i dettagli vanno nel piano di progetto.
  • Scrivi obiettivi che puoi misurare alla fine.
  • Elenca le esclusioni per prevenire lo scope creep.
  • Non iniziare la pianificazione di dettaglio finché non è firmato.

Domande frequenti

Che cos'è un modello di project charter?

Un modello di project charter è uno schema già pronto per il documento che autorizza formalmente un progetto e ne indica sponsor, project manager, obiettivi e ambito.

Cosa dovrebbe includere un modello di project charter?

Scopo, obiettivi SMART, ambito ed esclusioni, deliverable, milestone, budget, rischi, assunzioni, stakeholder, ruoli e una sezione di approvazione.

Questo modello di project charter è gratuito?

Sì. Scarica gratuitamente il modello di project charter come foglio Google Sheets, file Excel o PDF.

Chi compila il modello di project charter?

Di solito il project manager o lo sponsor redige il project charter; lo sponsor lo approva e lo firma.

Quanto dovrebbe essere lungo un modello di project charter compilato?

Da una a quattro pagine. Se il tuo project charter è più lungo, sposta i dettagli nel piano di progetto.

Posso usare il modello di project charter per i progetti Agile?

Sì. I team Agile usano spesso un project charter leggero per concordare visione, obiettivi, confini e ruoli.

Qual è la differenza tra un modello di project charter e un modello di piano di progetto?

Il project charter autorizza il progetto ad alto livello; il modello di piano di progetto spiega come verrà realizzato.

Quando usare il modello di project charter?

Usa il modello di project charter all'inizio dell'avvio, prima della pianificazione di dettaglio.

Un modello di project charter richiede una firma?

Sì. Un project charter firmato dimostra l'autorizzazione formale e l'impegno dello sponsor.

Posso modificare il project charter dopo l'approvazione?

Solo per cambiamenti importanti di scopo o ambito, e il project charter rivisto deve essere riapprovato dallo sponsor.

Qual è la differenza tra il modello di project charter principiante, avanzato ed esperto?

Il modello di project charter principiante contiene solo le colonne essenziali in una scheda; la versione avanzata è il modello completo con tutte le schede, i menu a discesa e le formule; la versione esperta aggiunge istruzioni, una dashboard che riepiloga automaticamente i dati, colori di stato e una cronologia delle revisioni.
