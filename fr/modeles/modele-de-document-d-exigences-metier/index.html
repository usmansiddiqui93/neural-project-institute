Les lignes d'exemple sont indicatives : remplacez-les par les vôtres.

Contenu

  • Vue d'ensemble du BRD en dix sections
  • Registre des exigences avec type, justification, priorité MoSCoW, source, critères d'acceptation et statut
  • Vue d'ensemble du BRD : Section, Conseils, Votre contenu
  • Exigences : ID, Exigence, Type, Justification, Priorité (MoSCoW), Source, Critères d'acceptation, Statut

Comment utiliser le modèle de document d'exigences métier

  1. Remplissez la vue d'ensemble : objectifs, périmètre et parties prenantes.
  2. Organisez des ateliers et des entretiens pour recueillir les exigences.
  3. Rédigez chaque exigence sous la forme d'un énoncé clair et testable, avec sa justification et sa source.
  4. Priorisez avec la méthode MoSCoW et ajoutez des critères d'acceptation.
  5. Faites une revue avec les parties prenantes et obtenez la validation avant le début de la conception.

Conseils pour en tirer le meilleur parti

  • Décrivez ce qui est nécessaire, pas la manière de le réaliser.
  • Une exigence par ligne.
  • Rattachez chaque exigence à un objectif.
  • Maîtrisez les changements au moyen de la demandes de modification.

Questions fréquentes

Qu'est-ce qu'un modèle de document d'exigences métier ?

Un modèle de document d'exigences métier est une structure permettant de consigner les objectifs métier, le périmètre, les parties prenantes et les exigences d'un projet avec leurs critères d'acceptation.

Ce modèle de document d'exigences métier est-il gratuit ?

Oui. Le modèle de document d'exigences métier est gratuit dans Google Sheets, Excel et PDF.

Qu'est-ce qu'un modèle de BRD ?

Un modèle de BRD est la même chose : un modèle de document d'exigences métier.

Que doit contenir un modèle de document d'exigences métier ?

Synthèse, objectifs, situation actuelle, périmètre, parties prenantes, hypothèses, contraintes, exigences, critères de réussite et validation.

Qui rédige le modèle de document d'exigences métier ?

Généralement un business analyst, en collaboration avec les parties prenantes et le chef de projet.

Quelle est la différence entre un modèle de document d'exigences métier et une spécification fonctionnelle ?

Un BRD énonce ce dont l'entreprise a besoin ; une spécification fonctionnelle décrit comment le système répondra à ces besoins.

Comment prioriser dans le modèle de document d'exigences métier ?

Utilisez la méthode MoSCoW : Must, Should, Could et Won't have.

Un modèle de document d'exigences est-il la même chose qu'un modèle de document d'exigences métier ?

Un modèle de document d'exigences général peut inclure des exigences techniques ; un BRD se concentre sur les besoins métier.

Les équipes agiles peuvent-elles utiliser un modèle de document d'exigences métier ?

Oui, à un niveau général ; le détail figure ensuite dans les user stories.

Qui valide le modèle de document d'exigences métier ?

Le sponsor et les principales parties prenantes métier valident le BRD.

Quelle est la différence entre les versions débutant, avancé et expert du modèle de document d'exigences métier ?

La version débutant du modèle de document d'exigences métier ne conserve que les colonnes essentielles sur un seul onglet ; la version avancé est le modèle complet avec tous les onglets, listes déroulantes et formules ; la version expert ajoute des instructions, un tableau de bord qui synthétise automatiquement vos données, des couleurs de statut et un historique des révisions.
